## 1. 系统概述

### 1.1 系统简介

CAUC-SEP自旋电子器件实验平台是一套完整的材料特性采集与分析系统，主要用于磁滞回线测量和磁性材料分析。本手册将指导您使用系统的核心功能。

### 1.2 主要功能

| 功能模块 | 说明 |
|----------|------|
| 设备控制 | 步进电机、电磁铁、温度控制器等设备控制 |
| 数据采集 | 实时数据采集与波形显示 |
| 多模型拟合 | 多种物理模型对比拟合 |
| 分析报告 | 自动生成分析报告并导出 |
| 历史管理 | 实验数据历史记录管理 |
| 健康监控 | 系统状态实时监控 |

### 1.3 系统要求

- **操作系统**: Windows 10/11 64位
- **硬件**: USB-RS485转换器、支持的实验设备
- **网络**: 本地服务，无需互联网连接

## 3. 多模型对比功能

### 3.1 功能概述

多模型对比功能允许您同时使用多个物理模型对磁滞回线数据进行拟合，系统会自动比较各模型的拟合效果并推荐最佳模型。

### 3.2 支持的模型

| 模型名称 | 适用场景 | 特点 |
|----------|----------|------|
| **双曲正切 (Hyperbolic)** | 简单磁滞回线 | 计算快速，适合初步分析 |
| **反正切 (Arctangent)** | 中等非线性材料 | 平滑过渡，适合一般磁性材料 |
| **Braunbeck** | 完整磁滞回线 | 考虑磁滞效应，拟合精度高 |
| **Langevin** | 超顺磁颗粒 | 适用于纳米颗粒磁性分析 |

### 3.3 操作步骤

#### 步骤一：准备数据

1. 完成磁滞回线测量实验
2. 确保数据已保存到系统中
3. 切换到"数据分析"页面

#### 步骤二：选择模型

1. 在分析页面找到"多模型拟合"区域
2. 勾选需要对比的模型（建议至少选择2个）
3. 系统默认推荐选择全部模型进行对比

#### 步骤三：执行拟合

1. 点击"开始拟合"按钮
2. 等待系统计算（通常需要1-5秒）
3. 查看拟合结果

#### 步骤四：查看结果

拟合完成后，系统将显示：

- **最佳模型推荐**: 系统自动推荐拟合效果最好的模型
- **参数对比表**: 各模型的拟合参数对比
- **拟合曲线图**: 原始数据与拟合曲线的对比图

### 3.4 结果解读

#### 拟合优度指标

| 指标 | 说明 | 判断标准 |
|------|------|----------|
| **R²** | 决定系数 | 越接近1越好，>0.95为优秀 |
| **RMSE** | 均方根误差 | 越小越好 |
| **AIC** | 信息准则 | 越小越好，用于模型比较 |

#### AIC权重解释

- ΔAIC < 2: 模型效果相近，可任选其一
- ΔAIC 2-10: 有一定优势，推荐选择更优模型
- ΔAIC > 10: 明显优势，强烈推荐选择更优模型

### 3.5 参数说明

#### 磁滞回线关键参数

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 饱和磁感应强度 | Bs | T | 高场下磁感应强度的饱和值 |
| 矫顽力 | Hc | A/m | 磁感应强度为零时的磁场强度 |
| 拟合参数 | S | - | 控制曲线陡峭程度的参数 |

### 3.6 使用技巧

1. **数据质量**: 确保测量数据覆盖完整的磁滞回线，包括饱和区
2. **模型选择**: 对于未知材料，建议选择全部模型进行对比
3. **参数验证**: 检查拟合参数是否在物理合理范围内
4. **多次测量**: 建议进行多次测量取平均值以提高可靠性

## 4. 分析报告生成与导出

### 4.1 功能概述

分析报告功能可以自动整合磁滞回线分析结果，生成包含关键参数、拟合曲线和数据分析建议的完整报告，并支持多种格式导出。

### 4.2 生成报告

#### 步骤一：准备数据

1. 完成磁滞回线测量
2. 确保数据质量良好（无异常点）

#### 步骤二：生成报告

1. 在数据分析页面点击"生成报告"按钮
2. 输入实验编号（可选）
3. 等待系统处理（通常需要3-10秒）

#### 步骤三：查看报告

报告生成后，系统将显示以下内容：

- **实验信息**: 实验编号、时间戳
- **磁滞参数**: 矫顽力、剩磁、饱和磁矩等
- **拟合结果**: 最佳模型及拟合参数
- **质量指标**: 数据点数、信噪比等
- **分析建议**: 系统自动生成的分析建议

### 4.3 报告内容说明

#### 磁滞回线参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 矫顽力 | Hc | 磁矩为零时的磁场强度 |
| 正向矫顽力 | Hc_positive | 正向扫描时的矫顽力 |
| 负向矫顽力 | Hc_negative | 负向扫描时的矫顽力 |
| 剩磁 | Mr | 磁场为零时的磁矩 |
| 饱和磁矩 | Ms | 高场下的饱和磁矩 |
| 矩形比 | Squareness | Mr/Ms的比值 |

#### 质量指标

| 指标 | 说明 |
|------|------|
| 数据点数 | 测量数据点总数 |
| 磁场范围 | 磁场强度的变化范围 |
| 磁矩范围 | 磁矩的变化范围 |
| 数据密度 | 单位磁场范围内的数据点数 |
| 信噪比 | 信号与噪声的比值 |

### 4.4 导出报告

#### 支持的导出格式

| 格式 | 文件扩展名 | 适用场景 |
|------|------------|----------|
| **JSON** | .json | 数据交换、程序处理 |
| **CSV** | .csv | Excel打开、数据分析 |

#### 导出步骤

1. 在报告页面点击"导出报告"按钮
2. 选择导出格式（JSON或CSV）
3. 选择是否包含原始数据
4. 点击"确认导出"
5. 选择保存位置并保存文件

#### JSON格式说明

JSON格式包含完整的报告结构和元数据：

```json
{
  "experiment_id": "exp_20260307_001",
  "timestamp": "2026-03-07T10:30:00.000Z",
  "hysteresis_params": {
    "Hc": 125.3,
    "Mr": 0.85,
    "Ms": 1.52,
    "squareness": 0.56
  },
  "best_model": "braunbeck",
  "fit_results": [...],
  "recommendations": [...]
}
```

#### CSV格式说明

CSV格式适合用Excel打开查看：

- 第一部分：关键参数汇总
- 第二部分：原始数据（可选）
- 第三部分：拟合曲线数据

### 4.5 使用技巧

1. **命名规范**: 使用有意义的实验编号，便于后续查找
2. **数据备份**: 定期导出重要实验数据
3. **格式选择**: 
   - 需要进一步分析处理 → 选择JSON
   - 需要人工查看或报告 → 选择CSV

## 5. 历史记录管理

### 5.1 功能概述

历史记录管理功能帮助您查看、管理和导出过去的实验数据和分析结果。

### 5.2 查看历史记录

#### 步骤一：进入历史记录页面

1. 点击侧边栏的"历史记录"或"实验管理"
2. 系统将显示实验列表

#### 步骤二：筛选记录

可按以下条件筛选：

| 筛选条件 | 说明 |
|----------|------|
| 时间范围 | 选择日期范围 |
| 实验类型 | 磁滞回线、温度扫描等 |
| 状态 | 完成、中断、错误 |

#### 步骤三：查看详情

点击实验记录可查看：

- 实验基本信息
- 测量参数配置
- 数据曲线图

### 5.3 导出历史数据

1. 选择需要导出的实验记录
2. 点击"导出"按钮
3. 选择导出格式和内容

1. 选择需要删除的记录
2. 点击"删除"按钮

> **注意**: 删除操作不可恢复，请谨慎操作！

### 5.5 数据存储位置

- **数据库**: `%APPDATA%\cauc-sep\experiments.db`
- **数据文件**: `%APPDATA%\cauc-sep\data\`

## 6. 系统健康监控

### 6.1 功能概述

系统健康监控功能帮助您实时了解系统运行状态，包括CPU、内存使用率和设备连接状态。

### 6.2 查看系统状态

#### 方法一：状态栏

界面底部状态栏显示：
- 系统状态指示灯（绿色=正常，黄色=警告，红色=异常）
- 已连接设备数量
- 当前CPU和内存使用率

#### 方法二：系统设置页面

1. 点击侧边栏的"系统设置"
2. 选择"系统状态"选项卡
3. 查看详细信息

### 6.3 状态指标说明

#### 系统资源

| 指标 | 正常范围 | 警告阈值 | 异常阈值 |
|------|----------|----------|----------|
| CPU使用率 | < 70% | 70-85% | > 85% |
| 内存使用率 | < 70% | 70-85% | > 85% |
| 磁盘使用率 | < 80% | 80-90% | > 90% |

#### 设备状态

| 状态 | 说明 |
|------|------|
| **已连接** | 设备正常工作 |
| **已断开** | 设备未连接或连接中断 |
| **忙碌** | 设备正在执行操作 |
| **错误** | 设备出现故障 |

### 6.4 健康状态判断

| 状态 | 图标颜色 | 说明 |
|------|----------|------|
| **健康** | 绿色 | 所有资源正常，设备全部连接 |
| **降级** | 黄色 | 资源使用率较高或部分设备断开 |
| **异常** | 红色 | 资源严重不足或多数设备故障 |

### 6.5 性能优化建议

当系统状态显示"降级"或"异常"时：

1. **CPU使用率高**:
   - 关闭不必要的后台程序
   - 降低数据采集频率
   - 减少同时运行的设备数量

2. **内存使用率高**:
   - 清理历史数据
   - 重启系统释放内存
   - 减少打开的页面数量

3. **磁盘空间不足**:
   - 导出并删除旧数据
   - 清理临时文件
   - 扩展存储空间

## 7. 常见问题与故障排除

### 7.1 设备连接问题

#### 问题：设备无法连接

**可能原因**:
- 串口被其他程序占用
- 设备未上电
- 串口号配置错误

**解决方法**:
1. 检查设备是否已上电
2. 在设备管理器中确认串口号
3. 关闭可能占用串口的其他程序
4. 重新插拔USB转换器

#### 问题：设备连接后无响应

**可能原因**:
- 波特率配置错误
- 设备地址错误
- 通信线路故障

**解决方法**:
1. 检查波特率设置（默认115200）
2. 确认设备地址（默认1）
3. 检查通信线缆连接

### 7.2 数据分析问题

#### 问题：拟合结果不收敛

**可能原因**:
- 数据质量差
- 初始参数估计不当
- 数据范围不足

**解决方法**:
1. 检查数据是否有异常点
2. 确保数据覆盖完整的磁滞回线
3. 尝试不同的模型进行拟合

#### 问题：R²值很低

**可能原因**:
- 模型选择不当
- 数据存在异常点
- 背景干扰严重

**解决方法**:
1. 使用多模型对比选择最佳模型
2. 检查并移除异常数据点
3. 启用背景扣除功能

### 7.3 报告导出问题

#### 问题：导出文件无法打开

**可能原因**:
- 文件损坏
- 格式不兼容
- 磁盘空间不足

**解决方法**:
1. 重新导出报告
2. 尝试其他导出格式
3. 检查磁盘空间

### 7.4 性能问题

#### 问题：系统响应缓慢

**可能原因**:
- 系统资源不足
- 数据量过大
- 后台任务过多

**解决方法**:
1. 查看系统健康状态
2. 关闭不必要的程序
3. 清理历史数据

#### 问题：数据采集中断

**可能原因**:
- 设备连接断开
- 缓冲区溢出
- 系统资源不足

**解决方法**:
1. 检查设备连接状态
2. 降低采样率
3. 增加缓冲区大小

### 7.5 错误代码参考

| 错误代码 | 说明 | 解决方法 |
|----------|------|----------|
| E1001 | 设备未初始化 | 重启系统 |
| E1002 | 设备未连接 | 检查设备连接 |
| E2001 | 参数无效 | 检查输入参数 |
| E3001 | 超出软件限位 | 调整目标位置 |
| E4001 | 操作失败 | 查看详细错误信息 |
| E5001 | 内部错误 | 联系技术支持 |
