## 版本说明

### 版本号规则

本文档集采用语义化版本号（Semantic Versioning）：

- **主版本号**: 重大结构变更或不兼容的API修改
- **次版本号**: 新增功能或文档章节，保持向后兼容
- **修订号**: 文档修正、补充和优化

### 变更类型

| 类型 | 说明 |
|------|------|
| `新增` | 新增文档或章节 |
| `修改` | 更新现有内容 |
| `修复` | 修正错误或不准确信息 |
| `删除` | 移除过时内容 |
| `重构` | 文档结构重组 |
