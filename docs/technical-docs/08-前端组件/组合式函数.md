# 组合式函数

## useWebSocket

WebSocket 连接管理组合式函数，封装连接、重连、心跳检测、推送频率控制、协议协商等逻辑。

### 文件位置

[d:\cauc-sep\frontend\src\composables\useWebSocket.js](file:///d:/cauc-sep/frontend/src/composables/useWebSocket.js)

### 功能特性

- 连接管理：建立、断开、重连 WebSocket 连接
- 心跳检测：定时发送心跳保持连接活跃
- 自动重连：支持多种重连策略（固定、线性、指数退避、斐波那契）
- 协议协商：支持 JSON 和 MessagePack 二进制协议
- 消息队列：断线时缓存消息，重连后自动发送
- 频率控制：推送频率自适应调整
- 消息去重：避免重复处理相同消息
- 高频优化：高频消息批量处理

### 参数

```javascript
/**
 * @param {Object} options - 配置选项
 * @param {string} options.url - WebSocket服务器地址
 * @param {Function} [options.onMessage] - 消息接收回调
```

```vue
    console.log('WebSocket 已断开:', event.reason)
  },

    console.error('WebSocket 错误:', error)

  onProtocolChange: (protocol) => {
    console.log('协议切换:', protocol)
  },
  
  onStateChange: (state) => {
    console.log('连接状态变更:', state)
  },
  
  preferredProtocol: ProtocolType.MSGPACK,
  reconnectStrategy: 'exponential',

})

  connect()

})

    action,
    params,
    timestamp: Date.now()

  const health = checkHealth()
  console.log('连接健康状态:', health)
  return health
}
</script>

<template>

    <p>连接状态: {{ connectionState }}</p>
    <p>当前协议: {{ currentProtocol }}</p>
    <p>连接质量: {{ connectionQuality }}分</p>

  </div>
```

### 重连策略

```javascript
export const ReconnectStrategy = {
  FIXED: 'fixed',           // 固定间隔
  LINEAR: 'linear',         // 线性递增
  EXPONENTIAL: 'exponential', // 指数退避
  FIBONACCI: 'fibonacci'    // 斐波那契
}

// 计算重连延迟
function calculateReconnectDelay(attempt) {
  let delay = 0
  
  switch (reconnectStrategy) {
    case ReconnectStrategy.FIXED:
      delay = reconnectInterval
      break
    case ReconnectStrategy.LINEAR:
      delay = reconnectInterval * attempt
      break
    case ReconnectStrategy.EXPONENTIAL:
      delay = reconnectInterval * Math.pow(2, attempt - 1)
      break
    case ReconnectStrategy.FIBONACCI:
      delay = reconnectInterval * fibonacci(attempt)
      break
  }
  
  // 添加随机抖动（±20%）
  const jitter = delay * 0.2 * (Math.random() * 2 - 1)
  delay = delay + jitter
  
  // 限制最大延迟
  return Math.min(delay, maxBackoffDelay)
}
```

```vue
    title: '更新设置',
    action: async () => {
      const oldSettings = await saveSettings(newSettings)
      return oldSettings  // 返回旧值用于撤销
    },
    undo: async (oldSettings) => {
      await saveSettings(oldSettings)
    },
    undoWindow: 10000  // 10秒内可撤销
  })
}

// 辅助函数
function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms))
}
</script>

<template>
  <div>
    <button 
      :disabled="isOperating" 
      @click="connectDevice"
    >
      连接设备
    </button>
    
    <div v-if="isOperating" class="progress-bar">
      <div class="progress" :style="{ width: progress + '%' }"></div>
    </div>
  </div>
</template>
```

```javascript
import { useDataFreshness, FRESHNESS_LEVEL } from '@/composables/useDataFreshness'

const {

  freshnessText,       // 新鲜度文本

  isExpired,           // 是否过期
  needsWarning,        // 是否需要警告
  updateTimestamp,     // 更新时间戳
  reset                // 重置
} = useDataFreshness({
  warningThreshold: 5000,   // 5秒警告
  expiredThreshold: 10000   // 10秒过期

```

### useKeyboardShortcuts

键盘快捷键管理组合式函数。

```javascript
import { useKeyboardShortcuts } from '@/composables/useKeyboardShortcuts'

const { register, unregister } = useKeyboardShortcuts()

onMounted(() => {
  register('ctrl+s', handleSave)
  register('ctrl+z', handleUndo)
  register('escape', handleEscape)
})

onUnmounted(() => {
  unregister('ctrl+s')
  unregister('ctrl+z')
  unregister('escape')
})
```

```javascript
import { useLoading } from '@/composables/useLoading'

const {
```
