# 布局组件

## 概述

布局组件提供应用的整体框架结构，采用 IDE 风格设计，参考 VS Code、PyCharm、Cursor 等主流 IDE 的布局设计。

## 布局架构

```
┌─────────────────────────────────────────────────────────────┐
│                      TopbarIDE (48px)                        │
│  [菜单] [面包屑导航]          [标题]        [搜索] [状态] [用户] │
├────────┬────────────────────────────────────────────────────┤
│        │                                                    │
│Activity │                                                    │
│  Bar    │              主内容区域                              │
│ (48px)  │                                                    │
│        │                                                    │
│ [设备]  │                                                    │
│ [实验]  │                                                    │
│ [分析]  │                                                    │
│ [设置]  │                                                    │
│        ├────────────────────────────────────────────────────┤
│        │              StatusBarIDE (24px)                    │
│        │  [健康] [设备] [WS]     [页面]     [CPU] [MEM] [时间] │
└────────┴────────────────────────────────────────────────────┘
```

## SidebarIDE 组件

IDE 风格侧边栏组件，采用 Activity Bar + Side Panel 设计。

### 文件位置

[d:\cauc-sep\frontend\src\components\layout\SidebarIDE.vue](file:///d:/cauc-sep/frontend/src/components/layout/SidebarIDE.vue)

### 功能特性

- Activity Bar：最左侧图标栏，快速切换功能模块
- Side Panel：侧边面板，显示当前模块的导航菜单
- 可折叠：支持展开/折叠状态切换
- 移动端适配：响应式设计，移动端以抽屉形式展示
- 搜索功能：支持菜单搜索过滤
- 徽章提示：显示未读通知、设备告警等

### Props

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| collapsed | `boolean` | `false` | 是否折叠 |
| mobileOpen | `boolean` | `false` | 移动端是否打开 |

### Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| update:mobileOpen | `(value: boolean)` | 移动端打开状态变更 |
| toggle | - | 切换折叠状态 |
| viewChange | `(key: string)` | 视图切换 |

### 使用示例

```vue
<template>
  <SidebarIDE
    v-model:collapsed="sidebarCollapsed"
    v-model:mobileOpen="mobileMenuOpen"
    @toggle="handleSidebarToggle"
    @viewChange="handleViewChange"
  />
</template>

<script setup>
import { ref } from 'vue'
import SidebarIDE from '@/components/layout/SidebarIDE.vue'

const sidebarCollapsed = ref(false)
const mobileMenuOpen = ref(false)

function handleSidebarToggle() {
  console.log('侧边栏状态切换')
}

function handleViewChange(key) {
  console.log('切换到视图:', key)
}
</script>
```

## TopbarIDE 组件

IDE 风格顶部导航栏组件，提供面包屑导航、全局搜索、命令面板等功能。

### 文件位置

[d:\cauc-sep\frontend\src\components\layout\TopbarIDE.vue](file:///d:/cauc-sep/frontend/src/components/layout/TopbarIDE.vue)

### 功能特性

- 面包屑导航：显示当前页面路径
- 全局搜索：快速搜索功能（Ctrl+F）
- 命令面板：快速访问命令（Ctrl+P）
- 连接状态：WebSocket 连接状态指示
- 通知中心：系统通知管理
- 用户菜单：用户信息、设置、登出

### Props

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| sidebarCollapsed | `boolean` | `false` | 侧边栏是否折叠 |

### Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| toggleSidebar | - | 切换侧边栏 |
| toggleMobileMenu | - | 切换移动端菜单 |
| openCommandPalette | - | 打开命令面板 |

### 使用示例

```vue
<template>
  <TopbarIDE
    :sidebar-collapsed="sidebarCollapsed"
    @toggleSidebar="sidebarCollapsed = !sidebarCollapsed"
    @openCommandPalette="showCommandPalette = true"
  />
</template>

<script setup>
import { ref } from 'vue'
import TopbarIDE from '@/components/layout/TopbarIDE.vue'

const sidebarCollapsed = ref(false)
const showCommandPalette = ref(false)
</script>
```

### 面包屑配置

```javascript
const breadcrumbs = computed(() => {
  const path = route.path
  const parts = path.split('/').filter(Boolean)
  const crumbs = [{ label: '首页', path: '/device/status' }]
  
  const routeMap = {
    'device': '设备管理',
    'experiment': '实验控制',
    'analysis': '数据分析',
    'settings': '系统设置',
    'motor': '电机控制',
    'electromagnet': '电磁铁控制',
    'temperature': '温度控制',
    // ... 更多路由映射
  }
  
  parts.forEach((part, index) => {
    const label = routeMap[part] || part
    const pathTo = '/' + parts.slice(0, index + 1).join('/')
    crumbs.push({ label, path: pathTo })
  })
  
  return crumbs
})
```

## StatusBarIDE 组件

IDE 风格底部状态栏组件，显示系统健康、设备状态、资源监控等信息。

### 文件位置

[d:\cauc-sep\frontend\src\components\layout\StatusBarIDE.vue](file:///d:/cauc-sep/frontend/src/components/layout/StatusBarIDE.vue)

### 功能特性

- 系统健康状态：显示系统整体健康状况
- 设备连接状态：显示已连接设备数量
- WebSocket 状态：显示 WebSocket 连接状态
- 告警提示：显示未确认告警数量
- 资源监控：CPU、内存使用率
- 实时时钟：显示当前时间

### Props

无 Props，组件从 Pinia Store 获取状态。

### 使用示例

```vue
<template>
  <StatusBarIDE />
</template>

<script setup>
import StatusBarIDE from '@/components/layout/StatusBarIDE.vue'
</script>
```

## 完整布局示例

```vue
<template>
  <div class="app-layout">
    <!-- 侧边栏 -->
    <SidebarIDE
      v-model:collapsed="sidebarCollapsed"
      v-model:mobileOpen="mobileMenuOpen"
      @toggle="sidebarCollapsed = !sidebarCollapsed"
    />
    
    <!-- 主内容区 -->
    <main class="main-content">
      <!-- 顶部栏 -->
      <TopbarIDE
        :sidebar-collapsed="sidebarCollapsed"
        @toggleSidebar="sidebarCollapsed = !sidebarCollapsed"
        @openCommandPalette="openCommandPalette"
      />
      
      <!-- 内容区域 -->
      <div class="content-wrapper">
        <router-view v-slot="{ Component }">
          <keep-alive :include="cachedViews">
            <component :is="Component" />
          </keep-alive>
        </router-view>
      </div>
      
      <!-- 状态栏 -->
      <StatusBarIDE />
    </main>
    
    <!-- 命令面板 -->
    <CommandPalette
      v-model:visible="commandPaletteVisible"
      @select="handleCommandSelect"
    />
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'
import SidebarIDE from '@/components/layout/SidebarIDE.vue'
import TopbarIDE from '@/components/layout/TopbarIDE.vue'
import StatusBarIDE from '@/components/layout/StatusBarIDE.vue'
import CommandPalette from '@/components/common/CommandPalette.vue'

// 状态
const sidebarCollapsed = ref(false)
const mobileMenuOpen = ref(false)
const commandPaletteVisible = ref(false)

// 缓存的视图
const cachedViews = ['MotorControl', 'TemperatureControl']

// 方法
function openCommandPalette() {
  commandPaletteVisible.value = true
}

function handleCommandSelect(command) {
  console.log('执行命令:', command)
  commandPaletteVisible.value = false
}
</script>

<style scoped>
.app-layout {
  display: flex;
  height: 100vh;
  overflow: hidden;
}

.main-content {
  flex: 1;
  display: flex;
  flex-direction: column;
  min-width: 0;
  margin-left: 268px; /* sidebar-width + activity-bar-width */
  transition: margin-left var(--transition-normal);
}

.main-content.sidebar-collapsed {
  margin-left: 128px; /* sidebar-collapsed-width + activity-bar-width */
}

.content-wrapper {
  flex: 1;
  overflow: auto;
  padding: var(--spacing-6);
  background-color: var(--color-bg-secondary);
}

@media (max-width: 768px) {
  .main-content {
    margin-left: 0;
  }
  
  .content-wrapper {
    padding: var(--spacing-4);
  }
}
</style>
```

## 响应式设计

### 断点定义

| 断点 | 宽度范围 | 说明 |
|------|----------|------|
| xs | < 576px | 手机竖屏 |
| sm | 576px - 767px | 手机横屏/小平板 |
| md | 768px - 991px | 平板 |
| lg | 992px - 1199px | 小屏桌面 |
| xl | >= 1200px | 大屏桌面 |

### 移动端适配

```scss
@media (max-width: 768px) {
  .ide-sidebar {
    transform: translateX(-100%);
    
    &.ide-sidebar--mobile-open {
      transform: translateX(0);
    }
  }
  
  .ide-topbar__search {
    display: none;
  }
  
  .ide-topbar__breadcrumbs {
    display: none;
  }
  
  .status-text {
    display: none;
  }
}
```
