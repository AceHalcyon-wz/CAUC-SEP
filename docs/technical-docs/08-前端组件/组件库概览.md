# 组件库概览

## 概述

CAUC-SEP 前端采用 Vue 3 Composition API + Element Plus + Ant Design Vue 组件库，按功能模块组织。UI 设计采用**科技深蓝主题**，强调数据可视化和实验仪器的专业性。

## 组件使用规范

### 1. 组件导入

推荐使用按需导入方式：

```javascript
// 推荐：从 index.js 导入
import { MotorControl, TemperatureControl } from '@/components/experiment'

// 或直接导入单个组件
import MotorControl from '@/components/experiment/motor/MotorControl.vue'
```

### 2. 组件命名

- 组件文件使用 PascalCase 命名：`MotorControl.vue`
- 在模板中使用 kebab-case：`<motor-control />`
- 组件名称应具有描述性，反映其功能

### 3. Props 定义

```typescript
// 使用 TypeScript 接口定义 Props
interface Props {
  /** 设备ID */
  deviceId: string
  /** 是否禁用控制 */
  disabled?: boolean
  /** 初始值 */
  initialValue?: number
}

// 使用 withDefaults 设置默认值
const props = withDefaults(defineProps<Props>(), {
  disabled: false,
  initialValue: 0
})
```

### 4. Events 定义

```typescript
// 使用类型化的 Emits
const emit = defineEmits<{
  (e: 'update', value: number): void
  (e: 'error', error: Error): void
  (e: 'connect', deviceId: string): void
}>()
```

### 5. 组件通信

- 父子组件：使用 Props 和 Emits
- 跨层级组件：使用 Pinia Store
- 全局状态：使用 Provide/Inject

## 性能优化建议

### 1. 组件懒加载

```javascript
// 路由级别懒加载
const MotorControl = () => import('@/views/experiment/MotorControl.vue')

// 组件级别懒加载
const HeavyChart = defineAsyncComponent(() => 
  import('@/components/analysis/HeavyChart.vue')
)
```

### 2. 虚拟列表

对于大数据量列表，使用 VirtualList 组件：

```vue
<template>
  <VirtualList
    :items="largeDataSet"
    :item-size="50"
    :buffer="10"
  >
    <template #default="{ item }">
      <DataItem :data="item" />
    </template>
  </VirtualList>
</template>
```

### 3. Keep-Alive 缓存

```vue
<template>
  <router-view v-slot="{ Component }">
    <keep-alive :include="['MotorControl', 'TemperatureControl']">
      <component :is="Component" />
    </keep-alive>
  </router-view>
</template>
```
