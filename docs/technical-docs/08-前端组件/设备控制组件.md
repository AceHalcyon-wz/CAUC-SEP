# 设备控制组件

## 概述

设备控制组件提供各类实验设备的操作界面，包括电机、电磁铁、温度控制器、压电陶瓷、皮安表等设备的控制面板。

```javascript
function startJog(direction) {
  if (!motorStore.canControl) return
  
  jogState.active = true
  jogState.direction = direction
  
  // 立即执行一次
  motorStore.jog(direction, moveForm.velocity)
  
  // 持续 JOG
  jogInterval = setInterval(() => {
    motorStore.jog(direction, moveForm.velocity)
  }, 300)
}

function stopJog() {
  if (jogInterval) {
    clearInterval(jogInterval)
    jogInterval = null
  }
  jogState.active = false
  jogState.direction = 0
}
```

#### 电流验证

```javascript
function validateCurrentInput(value) {
  currentValidation.error = ''
  currentValidation.warning = ''
  
  const absValue = Math.abs(value)
  const minLimit = electromagnetStore.currentLimits.min
  const maxLimit = electromagnetStore.currentLimits.max
  
  // 检查是否超出硬件限制
  if (value < minLimit || value > maxLimit) {
    currentValidation.error = `电流超出硬件限制范围 (${minLimit}A ~ ${maxLimit}A)`
    return false
  }
  
  // 检查是否接近最大电流限制 (10A)
  if (absValue > MAX_CURRENT_LIMIT * 0.9) {
    currentValidation.warning = `警告：电流接近最大限制 ${MAX_CURRENT_LIMIT}A`
  }
  
  return true
}
```

// 计算校准质量
function calculateCalibrationQuality() {
  const points = calibrationPoints.value
  const predicted = points.map(p => electromagnetStore.calculateField(p.current))
  const actual = points.map(p => p.field)
  
  // 计算R²
  const meanActual = actual.reduce((sum, a) => sum + a, 0) / actual.length
  const ssTotal = actual.reduce((sum, a) => sum + Math.pow(a - meanActual, 2), 0)
  const ssResidual = residuals.reduce((sum, r) => sum + r * r, 0)
  calibrationQuality.r2 = 1 - (ssResidual / ssTotal)
  
  // 计算RMSE
  calibrationQuality.rmse = Math.sqrt(ssResidual / actual.length)
}

## 通用设备控制模式

### 设备状态管理

所有设备控制组件都遵循统一的状态管理模式：

```javascript
// 使用 useDeviceBase 组合式函数
const {
  isConnected,      // 是否已连接
  isConnecting,     // 是否正在连接
  status,           // 设备状态
  alarmMessage,     // 告警消息
  canControl,       // 是否允许控制
  statusType,       // 状态类型（用于UI样式）
  statusText,       // 状态文本
  showError,        // 显示错误消息
  clearAlarm,       // 清除告警
  setLoading,       // 设置加载状态
  resetState        // 重置状态
} = useDeviceBase('MotorController')
```

所有设备控制组件都包含急停功能：

async function handleEmergencyStop() {

    const success = await deviceStore.emergencyStop()

      ElMessage.warning('急停已触发')

### 参数验证

所有设备控制组件都包含参数验证：

```javascript
// 位置验证
function validatePosition(value, minLimit, maxLimit) {
  if (value < minLimit || value > maxLimit) {
    return {
      valid: false,
      message: `位置超出范围 (${minLimit} ~ ${maxLimit})`
    }
  }
  return { valid: true }
}

// 速度验证
function validateVelocity(value, minVelocity, maxVelocity) {
  if (value < minVelocity || value > maxVelocity) {
    return {
      valid: false,
      message: `速度超出范围 (${minVelocity} ~ ${maxVelocity})`
    }
  }
  return { valid: true }
}
```
