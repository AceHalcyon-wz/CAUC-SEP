## 1. 环境要求

### 1.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 64位 | Windows 11 64位 |
| CPU | 4核心 | 8核心及以上 |
| 内存 | 8GB | 16GB及以上 |
| 硬盘 | 20GB可用空间 | SSD 50GB及以上 |

### 1.2 软件依赖

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| Python | 3.11+ | 后端运行环境 |
| Node.js | 18.x LTS | 前端构建工具 |
| Git | 2.40+ | 版本控制 |
| Visual Studio Code | 最新版 | 推荐IDE |

### 1.3 硬件接口

| 接口类型 | 用途 | 备注 |
|----------|------|------|
| RS-232/COM | 步进电机驱动器通信 | 需USB转串口适配器 |
| USB | 皮安表、温度控制器通信 | 驱动程序自动安装 |
| GPIB | 电磁铁电源通信 | 需GPIB-USB适配器 |

## 3. Python开发环境

### 3.1 环境创建

**使用venv创建虚拟环境**：

```powershell
# 进入后端目录
cd d:\cauc-sep\backend

# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境 (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# 激活虚拟环境 (Windows CMD)
.\.venv\Scripts\activate.bat
```

**使用Conda创建环境**（推荐）：

```powershell
# 创建新环境
conda create -n cauc-sep python=3.11

# 激活环境
conda activate cauc-sep
```

### 3.2 依赖安装

```powershell
# 安装开发依赖
pip install -e ".[dev]"

# 或手动安装核心依赖
pip install fastapi uvicorn pydantic sqlalchemy numpy scipy lmfit

# 安装开发工具
pip install black isort mypy ruff pytest pytest-asyncio pytest-cov
```

### 3.3 代码质量工具配置

**Black格式化配置** (`pyproject.toml`)：

```toml
[tool.black]
line-length = 100
target-version = ["py311"]
```

**isort导入排序配置**：

```toml
[tool.isort]
profile = "black"
line_length = 100
force_single_line = true
```

**MyPy类型检查配置**：

```toml
[tool.mypy]
python_version = "3.11"
explicit_package_bases = true
warn_return_any = false
disallow_untyped_defs = false
ignore_missing_imports = true
```

**Ruff代码检查配置**：

```toml
[tool.ruff]
line-length = 100
target-version = "py311"

[tool.ruff.lint]
select = ["E", "F", "W", "I", "N", "UP", "B", "C4"]
ignore = ["I001", "B008", "B904"]
```

### 3.4 运行代码检查

```powershell
# 格式化代码
black .
isort .

# 类型检查
mypy core api

# 代码检查
ruff check .

# 一键修复
ruff check . --fix
```

## 4. Node.js开发环境

### 4.1 Node.js安装

推荐使用nvm-windows管理Node.js版本：

```powershell
# 安装nvm-windows后
nvm install 18
nvm use 18

# 验证版本
node --version  # 应显示 v18.x.x
npm --version   # 应显示 9.x.x
```

### 4.2 依赖安装

```powershell
# 进入前端目录
cd d:\cauc-sep\frontend

# 安装依赖
npm install

# 或使用pnpm（更快）
npm install -g pnpm
pnpm install
```

### 4.3 代码质量工具配置

**ESLint配置** (`.eslintrc.cjs`)：

```javascript
module.exports = {
  root: true,
  env: {
    browser: true,
    es2022: true,
    node: true,
  },
  extends: [
    'eslint:recommended',
    'plugin:vue/vue3-recommended',

  parserOptions: {
    ecmaVersion: 'latest',
    sourceType: 'module',
  },
  plugins: ['vue'],
  rules: {
    'vue/multi-word-component-names': 'off',
    'vue/no-v-html': 'warn',
    'vue/require-default-prop': 'off',
    'no-console': process.env.NODE_ENV === 'production' ? 'warn' : 'off',
    'no-unused-vars': ['warn', { argsIgnorePattern: '^_' }],
    'prefer-const': 'warn',
    'no-var': 'error',
    eqeqeq: ['error', 'always'],
  },
};
```

**Prettier配置** (`.prettierrc`)：

```json
{
  "printWidth": 100,
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "vueIndentScriptAndStyle": false
}
```

### 4.4 运行代码检查

```powershell

# 检查格式
```


## 5. 调试配置

### 5.1 后端调试

**启用调试日志**：

```python
# main.py
import logging

logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s"
)
```

**使用仿真模式**：

```python
# 无需实际硬件即可调试
laser = LaserDriver("laser_01", {
    "simulation": True,  # 启用仿真模式
    "wavelength": 532,
    "max_power": 100,
})
```

**API文档调试**：

访问 http://127.0.0.1:8000/docs 使用Swagger UI进行API测试。

**断点调试**：

1. 在VS Code中打开Python文件
2. 点击行号左侧设置断点（红点）
3. 按F5启动调试
4. 选择"Python: FastAPI"配置

### 5.2 前端调试

**Vue DevTools**：

安装Vue DevTools浏览器扩展，用于：
- 组件树查看
- Pinia状态检查
- 路由信息
- 性能分析

**VS Code调试**：

1. 启动前端开发服务器：`npm run dev`
2. 按F5启动调试
3. 选择"Vue: Chrome"配置

**控制台调试**：

```javascript
// 在浏览器控制台中
// 查看Pinia状态
window.__PINIA__

// 查看Vue实例
window.__VUE_APP__
```

### 5.3 WebSocket调试

**使用浏览器开发者工具**：

```javascript
// 在控制台手动连接WebSocket
const ws = new WebSocket('ws://localhost:8000/ws/devices');

ws.onopen = () => console.log('Connected');
ws.onmessage = (e) => console.log('Message:', e.data);
ws.onerror = (e) => console.error('Error:', e);
ws.onclose = () => console.log('Closed');

// 发送消息
ws.send(JSON.stringify({ type: 'ping' }));
```

**使用Postman**：

Postman支持WebSocket测试：
1. 创建新的WebSocket请求
2. 输入URL：`ws://localhost:8000/ws/devices`
3. 点击Connect连接
4. 发送/接收消息

## 6. Git工作流

### 6.1 分支策略

```
main (生产分支)
  └── develop (开发分支)
        ├── feature/xxx (功能分支)
        ├── bugfix/xxx (修复分支)
        └── release/x.x (发布分支)
```

### 6.2 提交规范

使用Conventional Commits规范：

```
<type>(<scope>): <subject>

<body>

<footer>
```

**类型说明**：

| 类型 | 说明 | 示例 |
|------|------|------|
| feat | 新功能 | feat(stepper): 添加回零功能 |
| fix | 修复Bug | fix(api): 修复连接超时问题 |
| docs | 文档更新 | docs: 更新API文档 |
| style | 代码格式 | style: 格式化代码 |
| refactor | 重构 | refactor(core): 重构设备管理 |
| test | 测试 | test: 添加单元测试 |
| chore | 构建/工具 | chore: 更新依赖版本 |

### 6.3 常用Git命令

```powershell
# 克隆仓库
git clone https://github.com/xxx/cauc-sep.git

# 创建功能分支
git checkout -b feature/new-device

# 查看状态
git status

# 添加文件
git add .

# 提交
git commit -m "feat(device): 添加新设备支持"

# 推送分支
git push origin feature/new-device

# 拉取最新代码
git pull origin develop

# 合并分支
git checkout develop
git merge feature/new-device
```

### 6.4 Git Hooks

使用pre-commit自动检查：

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/psf/black
    rev: 23.12.1
    hooks:
      - id: black
        language_version: python3.11

  - repo: https://github.com/pycqa/isort
    rev: 5.13.2
    hooks:
      - id: isort

  - repo: https://github.com/charliermarsh/ruff-pre-commit
    rev: v0.1.9
    hooks:
      - id: ruff
        args: [--fix]
```

安装hooks：

```powershell
pip install pre-commit
pre-commit install
```

## 7. 常见问题

### 7.1 Python环境问题

**问题**: 虚拟环境激活失败

**解决方案**:

```powershell
# PowerShell执行策略问题
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 重新激活
.\.venv\Scripts\Activate.ps1
```

**问题**: pip安装超时

**解决方案**:

```powershell
# 使用国内镜像
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple package_name

# 或配置永久镜像
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 7.2 Node.js环境问题

**问题**: node-sass安装失败

**解决方案**:

```powershell
# 使用dart-sass替代
npm uninstall node-sass
npm install sass
```

**问题**: npm安装缓慢

**解决方案**:

```powershell
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 或使用pnpm
npm install -g pnpm
pnpm config set registry https://registry.npmmirror.com
```

### 7.3 VS Code问题

**问题**: Python解释器未识别

**解决方案**:

1. 按 `Ctrl+Shift+P`
2. 输入 `Python: Select Interpreter`
3. 选择正确的虚拟环境

**问题**: ESLint不生效

**解决方案**:

1. 检查ESLint扩展是否安装
2. 重新加载窗口：`Ctrl+Shift+P` -> `Reload Window`
3. 查看输出面板的ESLint日志

### 7.4 端口占用问题

**问题**: 端口被占用

**解决方案**:

```powershell
# 查找占用端口的进程
netstat -ano | findstr :8000

# 结束进程
taskkill /PID <PID> /F
```
