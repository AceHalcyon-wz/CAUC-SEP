## 2. 后端调试技巧

### 2.1 日志配置

**启用详细日志**：

```python
# main.py
import logging

# 配置根日志
logging.basicConfig(
    level=logging.DEBUG,  # 设置为DEBUG查看详细日志
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    handlers=[
        logging.StreamHandler(),  # 控制台输出
        logging.FileHandler("debug.log", encoding="utf-8"),  # 文件输出
    ]
)

# 模块特定日志级别
logging.getLogger("pymodbus").setLevel(logging.WARNING)  # 降低第三方库日志
logging.getLogger("uvicorn").setLevel(logging.INFO)
```

**结构化日志**：

```python
import structlog

logger = structlog.get_logger()

def process_data(device_id: str, data: list):
    logger.info(
        "processing_data",
        device_id=device_id,
        data_count=len(data),
        timestamp=time.time()
    )
```

### 2.2 仿真模式

所有设备驱动都支持仿真模式，无需实际硬件：

```python
# main.py
from core.laser_driver import LaserDriver
from core.stepper import StepperDriver

# 激光器仿真
laser = LaserDriver("laser_01", {
    "simulation": True,  # 启用仿真模式
    "wavelength": 532,
    "max_power": 100,
})

# 步进电机仿真
stepper = StepperDriver("stepper_01", {
    "simulation": True,
    "port": "COM3",
    "baudrate": 115200,
})

# 仿真模式下，所有操作都返回模拟数据
await laser.connect()  # 总是成功
await laser.set_power(50.0)  # 模拟设置功率
status = await laser.read_status()  # 返回模拟状态
```

**断点类型**：

| 类型 | 快捷键 | 说明 |
|------|--------|------|
| 普通断点 | F9 | 执行到此暂停 |
| 条件断点 | 右键 -> 条件断点 | 满足条件时暂停 |
| 日志点 | 右键 -> 日志点 | 输出日志不暂停 |
| 命中计数 | 右键 -> 命中计数 | 执行N次后暂停 |

**调试技巧**：

```python
# 使用条件断点
for i, item in enumerate(items):
    # 条件断点: i == 50
    process(item)

# 使用日志点
def complex_calculation(x, y):
    # 日志点: "x={x}, y={y}"
    result = x * y + x / y
    return result
```

```python
import httpx
import asyncio

async def test_api():
    async with httpx.AsyncClient(base_url="http://127.0.0.1:8000") as client:

        response = await client.post(
            "/api/laser/power",
            json={"power": 50.0}
        )
        print(f"Set Power: {response.json()}")

asyncio.run(test_api())
```

## 4. WebSocket调试

### 4.1 浏览器调试

**手动连接测试**：

```javascript
// 在浏览器控制台中
const ws = new WebSocket('ws://localhost:8000/ws/devices');

ws.onopen = () => {
  console.log('Connected');
  // 发送测试消息

};

  console.log('Closed:', e.code, e.reason);
};

// 发送消息
ws.send(JSON.stringify({ 
  type: 'subscribe', 
  channel: 'device_status' 
}));

// 关闭连接
ws.close();
```

**消息格式**：


### 4.3 Python测试脚本

```python
import asyncio
import websockets
import json

async def test_websocket():
    uri = "ws://localhost:8000/ws/devices"
    
    async with websockets.connect(uri) as ws:
        # 发送订阅消息
        await ws.send(json.dumps({
            "type": "subscribe",
            "channel": "device_status"
        }))
        
        # 接收消息
        for i in range(10):
            message = await ws.recv()
            data = json.loads(message)
            print(f"Received: {data}")
            
            # 发送心跳
            if i % 3 == 0:
                await ws.send(json.dumps({"type": "ping"}))

asyncio.run(test_websocket())
```

## 5. 性能分析

### 5.1 后端性能分析

**使用cProfile**：

```python
import cProfile
import pstats

# 分析函数
def analyze_performance():
    profiler = cProfile.Profile()
    profiler.enable()
    
    # 执行需要分析的代码
    result = expensive_operation()
    
    profiler.disable()
    stats = pstats.Stats(profiler)
    stats.sort_stats('cumulative')
    stats.print_stats(20)  # 打印前20个最耗时的函数

# 命令行分析
# python -m cProfile -s cumulative main.py
```

**使用line_profiler**：

```python
from line_profiler import LineProfiler

lp = LineProfiler()

@lp
def slow_function():
    # 每行代码的执行时间会被记录
    total = 0
    for i in range(1000000):
        total += i
    return total

slow_function()
lp.print_stats()
```

```python
import time
import logging

logger = logging.getLogger(__name__)

def measure_time(func):
    """测量函数执行时间的装饰器"""
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        logger.debug(f"{func.__name__} took {elapsed:.4f}s")
        return result
    return wrapper

@measure_time
def slow_database_query():
    # 执行查询
    pass
```

```powershell
# 1. 检查设备是否上电

# 3. 检查端口是否被占用
mode  # 查看COM端口状态

# 4. 测试串口通信
# 使用串口调试工具（如Putty、Tera Term）
```

**Python诊断代码**：

```python
import serial.tools.list_ports

# 列出所有可用串口
ports = serial.tools.list_ports.comports()
for port in ports:
    print(f"Port: {port.device}")
    print(f"  Description: {port.description}")
    print(f"  HWID: {port.hwid}")

# 尝试打开串口
try:
    ser = serial.Serial('COM3', 115200, timeout=1)
    print("Port opened successfully")
    ser.close()
except serial.SerialException as e:
    print(f"Failed to open port: {e}")
```

```python
async def websocket_endpoint(websocket: WebSocket):
```
