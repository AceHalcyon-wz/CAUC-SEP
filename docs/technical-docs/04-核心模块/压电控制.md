## 功能概述

压电控制模块（`PiezoController`）提供高精度压电陶瓷定位控制功能，支持开环/闭环控制模式及完整的校准功能。该模块是实现纳米级位移精密控制的核心组件。

### 核心特性

| 特性 | 说明 |
|------|------|
| 电压控制范围 | 0-150V |
| 电压分辨率 | 1mV (0.001V) |
| 位移范围 | 0-100μm |
| 位移分辨率 | 1nm |
| 控制模式 | 开环/闭环 |
| 校准类型 | 线性/多项式/分段线性 |

## 控制模式

### 开环控制（Open Loop）

开环控制直接设置电压值，适用于无位移传感器的场景。

**工作原理**：
- 直接控制压电陶瓷驱动电压
- 位移通过校准曲线估算
- 响应速度快，无反馈延迟

**适用场景**：
- 无位移传感器的压电系统
- 对精度要求不高的快速定位
- 成本敏感的应用

### 闭环控制（Closed Loop）

闭环控制基于位移反馈，实现精确位移控制。

**工作原理**：
- 通过位移传感器实时反馈
- 自动调整电压以达到目标位移
- 补偿磁滞效应和蠕变

**适用场景**：
- 高精度定位需求
- 需要长期稳定性的实验
- 磁滞补偿要求高的场景

## 电压/位移控制

### 电压控制

设置压电陶瓷电压，电压将被自动量化到最接近的分辨率值。

```python
from backend.core.piezo_controller import PiezoController, ControlMode

# 创建控制器实例
config = {
    "simulation": True,
    "max_voltage_v": 150.0,
    "voltage_resolution_v": 0.001
}
piezo = PiezoController("piezo_1", config)

# 连接设备
await piezo.connect()

# 开环控制：设置电压
await piezo.set_voltage(75.0)  # 设置电压为75V

# 获取当前电压
current_voltage = await piezo.get_voltage()
print(f"当前电压: {current_voltage}V")
```

### 位移控制

根据校准数据将位移转换为电压，并应用非线性补偿。

```python
# 切换到闭环模式
await piezo.set_control_mode(ControlMode.CLOSED_LOOP)

# 设置目标位移
await piezo.set_displacement(50.0)  # 设置位移为50μm

# 获取当前位移
current_displacement = await piezo.get_displacement()
print(f"当前位移: {current_displacement}μm")
```

### 步进控制

支持电压和位移的相对步进操作。

```python
# 电压步进（+5V）
await piezo.step_voltage(5.0)

# 位移步进（+1μm）
await piezo.step_displacement(1.0)

# 归零操作
await piezo.zero()

# 最大伸展
await piezo.max_extend()
```

## 校准功能

### 校准类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| LINEAR | 线性校准 | 位移范围小、线性度好 |
| POLYNOMIAL | 多项式校准（3阶） | 存在非线性、需要高精度 |
| PIECEWISE | 分段线性校准 | 非线性严重、分段特性明显 |

### 校准流程

```python
from backend.core.piezo_controller import CalibrationType

# 1. 清除旧校准数据
await piezo.clear_calibration()

# 2. 添加校准点（电压V, 位移μm）
calibration_points = [
    (0.0, 0.0),      # 零点
    (30.0, 20.0),    # 30V -> 20μm
    (60.0, 40.0),    # 60V -> 40μm
    (90.0, 60.0),    # 90V -> 60μm
    (120.0, 80.0),   # 120V -> 80μm
    (150.0, 100.0),  # 150V -> 100μm
]

for voltage, displacement in calibration_points:
    await piezo.add_calibration_point(voltage, displacement)

# 3. 执行校准拟合
success = await piezo.perform_calibration(CalibrationType.POLYNOMIAL)

if success:
    print("校准成功！")
    # 获取校准数据
    cal_data = piezo.get_calibration_data()
    print(f"校准系数: {cal_data['coefficients']}")
    print(f"校准点数: {cal_data['point_count']}")
```

### 校准算法说明

#### 线性校准

```
displacement = a * voltage + b
```

使用最小二乘法拟合直线，适用于线性度好的压电陶瓷。

#### 多项式校准

```
displacement = a₃*v³ + a₂*v² + a₁*v + a₀
```

使用3阶多项式拟合，能够描述压电陶瓷的非线性特性。

#### 分段线性校准

将校准曲线分为多个线性段，每段使用线性插值。适用于非线性严重但分段特性明显的场景。

## 磁滞补偿

压电陶瓷存在磁滞效应，电压上升和下降时的位移不同。本模块提供自动磁滞补偿功能。

### 补偿原理

```python
def _apply_hysteresis_compensation(self, target_voltage: float) -> float:
    """应用磁滞补偿。

    根据电压变化方向进行补偿：
    - 电压上升：需要额外电压补偿（+2%）
    - 电压下降：需要减少电压补偿（-2%）
    """
    if len(self._voltage_history) == 0:
        return target_voltage

    last_voltage = self._voltage_history[-1]

    if target_voltage > last_voltage:
        # 电压上升：需要额外电压补偿
        delta = target_voltage - last_voltage
        compensation = 0.02 * delta  # 2%补偿
        compensated = target_voltage + compensation
    elif target_voltage < last_voltage:
        # 电压下降：需要减少电压补偿
        delta = last_voltage - target_voltage
        compensation = 0.02 * delta
        compensated = target_voltage - compensation
    else:
        compensated = target_voltage

    return compensated
```

### 启用/禁用磁滞补偿

```python
# 配置时启用磁滞补偿
config = {
    "simulation": True,
    "hysteresis_compensation": True  # 启用磁滞补偿
}
piezo = PiezoController("piezo_1", config)
```

## 完整代码示例

### 基本使用

```python
"""
压电控制器基本使用示例

演示开环/闭环控制、校准功能的使用方法
"""
import asyncio
from backend.core.piezo_controller import (
    PiezoController,
    ControlMode,
    CalibrationType
)


async def main():
    # 1. 创建控制器实例
    config = {
        "simulation": True,
        "max_voltage_v": 150.0,
        "max_displacement_um": 100.0,
        "hysteresis_compensation": True
    }
    piezo = PiezoController("piezo_main", config)

    # 2. 连接设备
    if not await piezo.connect():
        print("连接失败！")
        return

    # 3. 开环电压控制
    print("=== 开环控制测试 ===")
    await piezo.set_control_mode(ControlMode.OPEN_LOOP)

    # 电压扫描
    for voltage in [0, 50, 100, 150, 100, 50, 0]:
        await piezo.set_voltage(voltage)
        status = await piezo.read_status()
        print(f"电压: {status['current_voltage_v']}V, "
              f"位移: {status['current_displacement_um']:.2f}μm")

    # 4. 校准流程
    print("\n=== 校准流程 ===")

    # 添加校准点
    calibration_data = [
        (0.0, 0.0),
        (37.5, 25.0),
        (75.0, 50.0),
        (112.5, 75.0),
        (150.0, 100.0),
    ]

    await piezo.clear_calibration()
    for v, d in calibration_data:
        await piezo.add_calibration_point(v, d)

    # 执行多项式校准
    if await piezo.perform_calibration(CalibrationType.POLYNOMIAL):
        cal_info = piezo.get_calibration_data()
        print(f"校准成功！系数: {cal_info['coefficients']}")

    # 5. 闭环位移控制
    print("\n=== 闭环控制测试 ===")
    await piezo.set_control_mode(ControlMode.CLOSED_LOOP)

    # 位移扫描
    for displacement in [0, 25, 50, 75, 100, 75, 50, 25, 0]:
        await piezo.set_displacement(displacement)
        status = await piezo.read_status()
        print(f"目标位移: {displacement}μm, "
              f"实际位移: {status['current_displacement_um']:.2f}μm, "
              f"电压: {status['current_voltage_v']:.2f}V")

    # 6. 断开连接
    await piezo.disconnect()
    print("\n测试完成！")


if __name__ == "__main__":
    asyncio.run(main())
```

### 高级应用：精密定位扫描

```python
"""
精密定位扫描示例

演示使用压电控制器进行精密位移扫描
"""
import asyncio
import numpy as np
from backend.core.piezo_controller import PiezoController, ControlMode


async def precision_scan():
    """执行精密位移扫描。"""
    config = {
        "simulation": True,
        "max_voltage_v": 150.0,
        "max_displacement_um": 100.0,
        "hysteresis_compensation": True
    }
    piezo = PiezoController("piezo_scan", config)

    await piezo.connect()
    await piezo.set_control_mode(ControlMode.CLOSED_LOOP)

    # 执行线性扫描
    scan_range = np.linspace(0, 100, 101)  # 0-100μm，步长1μm
    results = []

    for target in scan_range:
        await piezo.set_displacement(target)
        await asyncio.sleep(0.01)  # 10ms稳定时间

        status = await piezo.read_status()
        results.append({
            "target": target,
            "actual": status["current_displacement_um"],
            "voltage": status["current_voltage_v"]
        })

    # 分析扫描精度
    errors = [r["actual"] - r["target"] for r in results]
    print(f"最大误差: {max(abs(e) for e in errors):.3f}μm")
    print(f"平均误差: {np.mean(errors):.3f}μm")
    print(f"标准差: {np.std(errors):.3f}μm")

    await piezo.disconnect()


if __name__ == "__main__":
    asyncio.run(precision_scan())
```

## 最佳实践

### 1. 校准建议

- **校准点数量**：建议至少5个校准点，覆盖整个工作范围
- **校准频率**：首次使用前校准，环境温度变化大时重新校准
- **校准类型选择**：
  - 位移范围 < 20%最大行程：线性校准
  - 位移范围 20%-80%：多项式校准
  - 非线性严重：分段线性校准

### 2. 控制模式选择

| 场景 | 推荐模式 | 原因 |
|------|----------|------|
| 快速定位 | 开环 | 响应快，无反馈延迟 |
| 高精度测量 | 闭环 | 自动补偿误差 |
| 长时间稳定 | 闭环 | 补偿蠕变效应 |
| 成本敏感 | 开环 | 无需位移传感器 |

### 3. 磁滞补偿

- 对于往返扫描实验，建议启用磁滞补偿
- 补偿系数（默认2%）可根据实际压电陶瓷特性调整
- 单向扫描可不启用磁滞补偿

### 4. 安全注意事项

- **电压限制**：不要超过最大电压（150V）
- **温度影响**：压电陶瓷对温度敏感，注意环境温度
- **机械冲击**：避免快速大幅度电压变化，可能损坏压电陶瓷
- **断电保护**：断电前将电压归零

## 故障排除

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 位移不准确 | 未校准或校准失效 | 重新执行校准流程 |
| 磁滞效应明显 | 未启用磁滞补偿 | 启用 `hysteresis_compensation` |
| 电压无法设置 | 超出范围或设备未连接 | 检查电压范围和连接状态 |
| 闭环控制不稳定 | 校准数据异常 | 清除校准数据，重新校准 |
