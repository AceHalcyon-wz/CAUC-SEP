# 步进电机控制模块 (DM2C)

## 概述

步进电机控制模块实现了对雷赛 DM2C-RS556 驱动器的完整控制，通过 Modbus RTU 协议进行通信。该模块位于 `backend/core/dm2c_driver.py`，提供运动控制、PR路径编程、回零操作、IO配置等完整功能。

## 功能特性

- **运动控制**: 绝对定位、相对定位、JOG点动
- **PR路径编程**: 16段可编程路径配置与触发
- **回零操作**: 多种回零模式支持
- **安全保护**: 软件限位、急停、报警管理
- **IO配置**: DI/DO端口功能配置
- **通信模式**: RS485/RS232双模式支持

## 通信参数配置

### RS485模式

| 参数 | 默认值 | 可配置范围 |
|------|--------|------------|
| 波特率 | 38400 bps | 2400-115200 |
| 数据位 | 8位 | 固定 |
| 校验位 | 无校验(N) | None/Even/Odd |
| 停止位 | 1位 | 1/2位 |
| 设备地址 | 1 | 1-127 |

### RS232模式

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 波特率 | 9600 bps | 固定 |
| 从站地址 | 1 | 固定 |
| 数据位 | 8位 | 固定 |
| 校验位 | 无校验 | 固定 |
| 停止位 | 1位 | 固定 |

> **注**：通信参数可通过拨码开关 SW6-SW7 进行配置，也可通过 RS485 通讯在线修改（需在 9600 波特率下）。设备地址可通过拨码开关 SW1-SW5 设置（1-31），或通过参数 Pr5.23 软件设置（1-127）。

## 关键寄存器映射

### 核心寄存器

| 寄存器名称 | 地址 | 功能说明 |
|------------|------|----------|
| 控制字 | 0x1801 | JOG控制、复位、参数保存等操作 |
| 状态字 | 0x1003 | 读取运行状态、使能状态、故障状态 |
| 触发寄存器 | 0x6002 | 写入 0x01P 触发PR路径P，0x020 触发回零 |
| 命令位置高字 | 0x602A | 目标位置高16位 |
| 命令位置低字 | 0x602B | 目标位置低16位 |
| 实际位置高字 | 0x602C | 当前位置高16位 |
| 实际位置低字 | 0x602D | 当前位置低16位 |
| 报警代码 | 0x2203 | 过流(0x01)、过压(0x02)、EEPROM故障(0x200) |

### JOG参数寄存器

| 寄存器名称 | 地址 | 功能说明 |
|------------|------|----------|
| JOG速度 | 0x01E1 (Pr6.00) | JOG速度（步/秒） |
| JOG加速时间 | 0x01E7 (Pr6.03) | JOG加速时间（ms） |
| JOG减速时间 | 0x01E8 (Pr6.04) | JOG减速时间（ms） |

### 回零参数寄存器

| 寄存器名称 | 地址 | 功能说明 |
|------------|------|----------|
| 回零模式 | 0x0280 (Pr8.00) | 回零模式选择 |
| 回零高速 | 0x0281 (Pr8.01) | 回零速度（高速） |
| 回零低速 | 0x0282 (Pr8.02) | 回零速度（低速） |
| 回零偏移 | 0x0283 (Pr8.03) | 回零偏移量 |
| 回零方向 | 0x0284 (Pr8.04) | 回零方向 |

### IO配置寄存器

| 寄存器名称 | 地址 | 功能说明 |
|------------|------|----------|
| DI1配置 | 0x0145 (Pr4.02) | 数字输入1功能配置 |
| DI2配置 | 0x0147 (Pr4.03) | 数字输入2功能配置 |
| DI状态 | 0x0179 (Pr4.28) | 数字输入端口状态 |
| DO1配置 | 0x0157 (Pr4.11) | 数字输出1功能配置 |
| DO状态 | 0x017B (Pr4.29) | 数字输出端口状态 |

## 核心类设计

### LeadshineDM2C 类

```python
class LeadshineDM2C(AbstractStepper):
    """
    雷赛DM2C步进驱动器实现

    寄存器地址（根据DM2C手册V1.8）：
    - 0x1801: 控制字
    - 0x1003: 状态字
    - 0x6002: 触发寄存器
    - 0x602A/0x602B: 目标位置（高/低字）
    - 0x602C/0x602D: 实际位置（高/低字）
    - 0x2203: 报警代码
    - 0x6200+: PR路径配置
    """

    def __init__(self, device_id: str, config: dict[str, Any]):
        """
        初始化DM2C驱动器

        Args:
            device_id: 设备标识
            config: 配置字典
                - port: 串口号 (默认 "COM1")
                - slave_id: 从站地址 (默认 1)
                - baudrate: 波特率 (默认 38400)
                - steps_per_mm: 每毫米步数 (默认 1600)
                - serial_mode: 串口模式 ("rs485" 或 "rs232")
        """
```


## PR路径编程

DM2C 驱动器支持 16 段可编程路径（PR0-PR15），每段路径可配置独立的运动参数。

### 运动模式定义

```python
# 运动类型
PR_TYPE_NO_ACTION = 0   # 无动作
PR_TYPE_POSITION = 1    # 位置定位
PR_TYPE_VELOCITY = 2    # 速度运行
PR_TYPE_HOME = 3        # 回零

# 位置模式
PR_POS_ABSOLUTE = 0     # 绝对位置
PR_POS_RELATIVE = 1     # 相对位置
```

### 配置PR路径

```python
# 配置路径0：绝对位置定位
await dm2c.configure_pr_path(
    path_number=0,
    mode=0x0001,          # 位置定位，绝对位置
    position=10000,        # 目标位置（步数）
    velocity=500,          # 速度（rpm）
    accel_time=100,        # 加速时间（ms）
    decel_time=100,        # 减速时间（ms）
    dwell_time=0,          # 停顿时间（ms）
)

# 配置路径1：相对位置定位
await dm2c.configure_pr_path(
    path_number=1,
    mode=0x0041,          # 位置定位，相对位置 (0x01 | 0x40)
    position=-5000,        # 相对位移（步数）
    velocity=300,
    accel_time=100,
    decel_time=100,
)

# 配置路径2：速度运行
await dm2c.configure_pr_path(
    path_number=2,
    mode=0x0002,          # 速度运行
    position=0,            # 无效
    velocity=800,          # 运行速度（rpm）
    accel_time=100,
    decel_time=100,
)
```

### 触发PR路径

```python
# 触发路径0运行
await dm2c.trigger_pr_path(0)

# 读取触发状态
status = await dm2c.read_trigger_status()
print(f"状态: {status['status']}")
print(f"是否空闲: {status['is_idle']}")
```

### 连续路径运行

```python
# 配置连续路径序列
# 路径0: 移动到10000步
await dm2c.configure_pr_path(0, 0x0001, 10000, 500, 100, 100, dwell_time=0)

# 路径1: 移动到20000步
await dm2c.configure_pr_path(1, 0x0001, 20000, 500, 100, 100, dwell_time=0)

# 依次触发
await dm2c.trigger_pr_path(0)
# 等待完成...
await dm2c.trigger_pr_path(1)
```

## 报警管理

### 报警代码映射

| 代码 | 名称 | 严重程度 | 可能原因 |
|------|------|----------|----------|
| 0x01 | 过流保护 | CRITICAL | 电机绕组短路、负载过大 |
| 0x02 | 过压保护 | CRITICAL | 输入电压过高、减速过快 |
| 0x40 | 电流采样故障 | CRITICAL | 驱动器内部电路损坏 |
| 0x80 | 锁轴故障 | CRITICAL | 电机缺相、机械卡死 |
| 0x100 | 参数自整定故障 | WARNING | 电机未连接、负载过大 |
| 0x200 | EEPROM故障 | WARNING | EEPROM损坏、写入中断 |
| 0x210 | IO配置重复 | WARNING | 多个输入端子配置相同功能 |

### 读取报警信息

```python
# 读取报警代码
alarm_code = await dm2c.read_alarm_code()

# 获取详细报警信息（中文）

print(f"报警名称: {alarm_info['name']}")
print(f"报警描述: {alarm_info['description']}")
print(f"严重程度: {alarm_info['severity']}")
print(f"可能原因: {alarm_info['possible_causes']}")
print(f"解决方案: {alarm_info['solutions']}")

# 获取英文信息

```

### 清除报警

## IO端口配置

### DI功能代码

| 代码 | 功能 | 说明 |
|------|------|------|
| 0x00 | 无效输入 | 禁用端口 |
| 0x07 | 报警清除 | 触发时清除报警 |
| 0x08 | 使能 | 触发时使能驱动器 |
| 0x20 | 触发命令(CTRG) | 触发PR路径 |
| 0x21 | 回零触发(HOME) | 触发回零 |
| 0x22 | 强制急停(STP) | 紧急停止 |
| 0x23 | 正向JOG(PJOG) | 正向点动 |
| 0x24 | 反向JOG(NJOG) | 反向点动 |
| 0x25 | 正向限位(POT) | 正向限位信号 |
| 0x26 | 反向限位(NOT) | 反向限位信号 |
| 0x27 | 原点信号(ORG) | 原点信号 |

### DO功能代码

| 代码 | 功能 | 说明 |
|------|------|------|
| 0x00 | 无效输出 | 禁用端口 |
| 0x20 | 指令完成(CMD_OK) | 指令执行完成时输出 |
| 0x21 | 路径完成(MC_OK) | PR路径完成时输出 |
| 0x22 | 回零完成(HOME_OK) | 回零完成时输出 |
| 0x23 | 到位完成(INP) | 到位信号输出 |
| 0x24 | 抱闸输出(BRK) | 抱闸控制输出 |
| 0x25 | 报警输出(ALM) | 报警时输出 |

### 配置IO端口

```python
# 配置DI1为使能信号（常开）
await dm2c.configure_di(1, 0x08)

# 配置DI1为使能信号（常闭，+0x80）
await dm2c.configure_di(1, 0x88)

# 配置DI4为正向限位
await dm2c.configure_di(4, 0x25)

# 配置DO1为报警输出
await dm2c.configure_do(1, 0x25)

# 批量配置DI
results = await dm2c.configure_all_di({
    1: 0x88,  # DI1: 使能（常闭）
    2: 0x23,  # DI2: 正向JOG
    3: 0x24,  # DI3: 反向JOG
    4: 0x25,  # DI4: 正限位
    5: 0x26,  # DI5: 负限位
})
```

## 常见问题

### Q1: 通信超时怎么办？

**A**: 检查通信参数是否正确，确认波特率、从站地址与驱动器设置一致：

```python
# 检查通信配置
config = await dm2c.read_communication_config()
print(config)
```

### Q2: 运动不执行？

**A**: 检查驱动器使能状态和报警状态：

```python
status = await dm2c.read_status_word()
if not status["enabled"]:
    print("驱动器未使能")
if status["fault"]:
    alarm = await dm2c.get_alarm_details()
    print(f"存在报警: {alarm['name']}")
```

### Q3: PR路径不触发？

**A**: 确认触发寄存器状态：

```python
trigger_status = await dm2c.read_trigger_status()
if not trigger_status["is_idle"]:
    print("驱动器忙碌，等待完成")
```

### Q4: 位置读取不准确？

**A**: 检查 `steps_per_mm` 参数是否正确：

```python
# 确认步数转换
print(f"每毫米步数: {dm2c.steps_per_mm}")
# 根据丝杠导程和细分设置调整
```
