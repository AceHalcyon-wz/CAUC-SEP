# 电磁铁控制模块

## 概述

电磁铁控制模块提供恒流模式和扫描模式控制，支持电流-磁场校准管理。该模块位于 `backend/core/electromagnet_driver.py`，实现精确的电流控制和自动保护机制。

## 功能特性

- **恒流模式**: 精确设定目标电流
- **扫描模式**: 正向扫描、反向扫描、三角波扫描
- **校准管理**: 电流-磁场校准曲线
- **安全保护**: 过流保护、过温保护、急停功能
- **实时监控**: 电流、磁场、温度实时监测

## 技术规范

| 参数 | 规格 |
|------|------|
| 电流范围 | 0-10A |
| 电流精度 | ±0.1% |
| 磁场范围 | 0-2T（特斯拉） |
| 扫描速率 | 0.01-1 A/s |
| 过流保护阈值 | 10.5A |
| 过温保护阈值 | 80°C |

## 核心类设计

### ScanMode - 扫描模式枚举

```python
class ScanMode(Enum):
    """扫描模式枚举。"""

    FORWARD = "forward"      # 正向扫描（从低到高）
    REVERSE = "reverse"      # 反向扫描（从高到低）
    TRIANGULAR = "triangular"  # 三角波扫描（往返）
```

### ElectromagnetStatus - 电磁铁状态枚举

```python
class ElectromagnetStatus(Enum):
    """电磁铁状态枚举。"""

    IDLE = "idle"                      # 空闲状态
    CONSTANT_CURRENT = "constant_current"  # 恒流模式运行中
    SCANNING = "scanning"              # 扫描模式运行中
    OVERCURRENT = "overcurrent"        # 过流保护触发
    OVERTEMPERATURE = "overtemperature"  # 过温保护触发
    CALIBRATING = "calibrating"        # 校准中
```

### ElectromagnetDriver 类

```python
class ElectromagnetDriver(AbstractDevice):
    """
    电磁铁驱动器实现类。

    提供恒流控制、扫描控制和磁场校准功能。
    支持仿真模式和真实硬件模式。
    """

    def __init__(self, device_id: str, config: dict[str, Any]):
        """
        初始化电磁铁驱动器。

        Args:
            device_id: 设备唯一标识符
            config: 设备配置字典
                - port: 通信端口（默认 "COM3"）
                - baudrate: 波特率（默认 9600）
                - max_current: 最大电流限制（默认 10.0A）
                - calibration_points: 校准点列表（可选）
                - simulation: 是否仿真模式（默认 True）
        """
```

## 扫描模式控制

### 正向扫描

电流从低值增加到高值：

```python
# 正向扫描：从0A扫描到5A
success = await driver.start_scan(
    mode=ScanMode.FORWARD,
    start_current=0.0,
    end_current=5.0,
    scan_rate=0.1,  # 0.1 A/s
)

# 监控扫描进度
while driver.electromagnet_status.value == "scanning":
    print(f"进度: {driver.scan_progress * 100:.1f}%")
    print(f"当前电流: {driver.current_value:.3f}A")
    await asyncio.sleep(0.5)

# 停止扫描
await driver.stop_scan()
```

### 反向扫描

电流从高值减少到低值：

```python
# 反向扫描：从5A扫描到0A
success = await driver.start_scan(
    mode=ScanMode.REVERSE,
    start_current=5.0,
    end_current=0.0,
    scan_rate=0.1,
)
```

### 三角波扫描

往返扫描，支持多周期：

```python
# 三角波扫描：0A -> 5A -> 0A，重复3次
success = await driver.start_scan(
    mode=ScanMode.TRIANGULAR,
    start_current=0.0,
    end_current=5.0,
    scan_rate=0.1,
    cycles=3,  # 扫描3个周期
)
```

### 自定义步进间隔

```python
# 使用自定义步进间隔进行精细控制
success = await driver.start_scan(
    mode=ScanMode.FORWARD,
    start_current=0.0,
    end_current=5.0,
    scan_rate=0.1,
    step_interval_ms=50.0,  # 每50ms更新一次电流
)
```

### 快速磁场扫描

```python
# 快速启动磁场扫描（自动转换电流）
success = await driver.quick_scan(
    start_field=0.0,   # 起始磁场
    end_field=1.0,     # 目标磁场
    scan_rate=0.1      # 扫描速率（A/s）
)
```

### 参数验证

## 校准管理

### 校准点数据结构

```python
@dataclass
class CalibrationPoint:
    """校准点数据类。"""

    current: float  # 电流值（A）
    field: float    # 磁场值（T）
```

### 执行校准

```python
# 使用校准点进行校准
calibration_points = [
    {"current": 0.0, "field": 0.0},
    {"current": 2.0, "field": 0.4},
    {"current": 4.0, "field": 0.8},
    {"current": 6.0, "field": 1.2},
    {"current": 8.0, "field": 1.6},
    {"current": 10.0, "field": 2.0},
]

success = await driver.calibrate(calibration_points)
```

### 校准算法

校准使用线性拟合（最小二乘法）：

```
B = coefficient * I + intercept
```

其中：
- `coefficient`: 斜率（T/A），表示电流到磁场的转换系数
- `intercept`: 截距（T），用于修正零点偏移

### 获取校准数据

```python
# 获取校准数据
cal_data = driver.get_calibration_data()
print(f"校准系数: {cal_data['calibration_coefficient']} T/A")
print(f"截距: {cal_data['calibration_intercept']} T")
print(f"校准点数量: {cal_data['points_count']}")

# 查看校准点
for point in cal_data['calibration_points']:
    print(f"  {point['current']}A -> {point['field']}T")
```

### 清除校准

```python
# 清除校准数据，恢复默认系数（0.2 T/A）
await driver.clear_calibration()
```

## 安全保护机制

### 过流保护

当电流超过 10.5A 时自动触发：

```python
# 过流保护自动触发
# 触发后：
# 1. 电流自动归零
# 2. 状态变为 OVERCURRENT
# 3. 停止所有扫描操作

# 检查过流状态
if driver.electromagnet_status.value == "overcurrent":
    print("过流保护已触发")

# 复位过流保护
success = await driver.reset_overcurrent_protection()
```

### 过温保护

当温度超过 80°C 时自动触发：

```python
# 检查温度
print(f"当前温度: {driver.current_temperature}°C")

# 过温保护自动触发
# 触发后：
# 1. 电流自动归零
# 2. 状态变为 OVERTEMPERATURE
# 3. 停止所有操作

# 复位过温保护（需温度恢复正常）
if driver.current_temperature < 72:  # 90%阈值
    success = await driver.reset_overtemperature_protection()
```

### 急停功能

```python
# 紧急停止
await driver.emergency_stop()
# 电流立即归零，状态变为 EMERGENCY_STOP

# 复位急停
await driver.reset_emergency()
```

## 完整使用示例

### 基础控制流程

```python
import asyncio
from backend.core.electromagnet_driver import ElectromagnetDriver, ScanMode


async def main():
    # 创建驱动器
    driver = ElectromagnetDriver(
        device_id="em_1",
        config={"simulation": True, "max_current": 10.0}
    )

    try:
        # 连接
        if await driver.connect():
            print("连接成功")

            # 设置恒流
            await driver.set_current(3.0)
            print(f"电流设置为 3A，磁场约 {driver.field_value}T")

            # 等待稳定
            await asyncio.sleep(2)

            # 执行三角波扫描
            await driver.start_scan(
                mode=ScanMode.TRIANGULAR,
                start_current=0.0,
                end_current=5.0,
                scan_rate=0.5,
                cycles=2
            )

            # 等待扫描完成
            while driver.electromagnet_status.value == "scanning":
                print(f"进度: {driver.scan_progress * 100:.1f}%")
                await asyncio.sleep(0.5)

            print("扫描完成")

    finally:
        # 断开连接
        await driver.disconnect()


asyncio.run(main())
```

    await driver.connect()

    # 准备校准点（使用高斯计测量实际磁场）
    calibration_points = [

        {"current": 4.0, "field": 0.82},
        {"current": 6.0, "field": 1.21},

    await driver.disconnect()

### 保护监控

```python
async def protection_example():
    driver = ElectromagnetDriver("em_1", {"simulation": True})
    await driver.connect()

    # 设置状态回调
    def on_status(status):
        if status["electromagnet_status"] == "overcurrent":

        print(f"温度较高: {driver.current_temperature}°C")

    await driver.disconnect()
```

## 常见问题

### Q1: 扫描无法启动？

**A**: 检查设备状态和保护状态：

```python
if driver.status.value != "ready":
    print(f"设备状态异常: {driver.status.value}")

if driver.electromagnet_status.value in ["overcurrent", "overtemperature"]:
    print("保护已触发，需先复位")
```

### Q2: 电流设置不生效？

**A**: 检查电流范围和保护状态：

```python
# 检查电流限制
print(f"最大电流限制: {driver.max_current_limit}A")

# 检查过温
if driver.current_temperature > 80:
    print("温度过高，无法设置电流")
```

### Q3: 校准不准确？

**A**: 确保使用足够的校准点（至少2个），并覆盖工作范围：

```python
# 推荐：使用5个以上校准点
calibration_points = [
    {"current": 0.0, "field": 0.0},
    {"current": 2.0, "field": 0.4},
    {"current": 5.0, "field": 1.0},  # 工作点附近
    {"current": 8.0, "field": 1.6},
    {"current": 10.0, "field": 2.0},
]
```

### Q4: 扫描时间过长？

**A**: 调整扫描速率或使用更大的步进间隔：

```python
# 增大扫描速率
await driver.start_scan(
    mode=ScanMode.FORWARD,
    start_current=0.0,
    end_current=5.0,
    scan_rate=0.5,  # 更快的速率
    step_interval_ms=100.0  # 更大的步进间隔
)
```
