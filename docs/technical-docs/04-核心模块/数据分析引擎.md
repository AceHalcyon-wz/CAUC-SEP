## 功能概述

数据分析引擎（`PhysicsAnalyzer`）是CAUC-SEP平台的核心智能分析组件，提供物理实验数据的后处理与分析能力。该模块支持信号处理、曲线拟合、磁滞回线分析、多模型对比等功能。

### 核心特性

| 特性 | 说明 |
|------|------|
| 信号平滑 | Savitzky-Golay滤波、巴特沃斯低通滤波 |
| 曲线拟合 | 线性、多项式、指数、高斯、Langevin、Braunbeck |
| 磁滞分析 | 背景扣除、矫顽力、剩磁、饱和磁矩计算 |
| 多模型拟合 | 并行拟合、AIC/BIC模型选择 |
| 数据导出 | CSV、HDF5、JSON格式 |

## Savitzky-Golay滤波

### 算法原理

Savitzky-Golay滤波器通过局部多项式拟合实现信号平滑，能够有效保留信号的高频特征。

**数学表达式**：

```
y_smoothed[i] = Σ w_j * y[i+j]
```

其中权重系数 `w_j` 通过多项式最小二乘拟合确定。

### 使用方法

```python
from backend.core.analysis import PhysicsAnalyzer
import numpy as np

# 创建分析器实例
analyzer = PhysicsAnalyzer()

# 生成测试数据
x = np.linspace(0, 10, 100)
y_noisy = np.sin(x) + np.random.normal(0, 0.1, len(x))

# Savitzky-Golay滤波
y_smooth = analyzer.smooth_signal(
    y_data=y_noisy,
    method="savgol",
    window_length=11,  # 窗口长度（必须为奇数）
    polyorder=2        # 多项式阶数
)
```

### 参数选择

| 参数 | 说明 | 选择建议 |
|------|------|----------|
| window_length | 窗口长度 | 奇数，越大越平滑 |
| polyorder | 多项式阶数 | 2-4，小于窗口长度 |

**参数选择原则**：

- 窗口长度越大，平滑效果越强，但会损失细节
- 多项式阶数越高，保留的细节越多，但可能过拟合
- 建议：`window_length = 11-31`，`polyorder = 2-3`

### 巴特沃斯低通滤波

```python
# 巴特沃斯低通滤波
y_smooth = analyzer.smooth_signal(
```

## Langevin函数拟合

### 物理背景

Langevin函数描述超顺磁颗粒的磁化行为：

```
M(H) = M_s * L(μH/kT)
L(x) = coth(x) - 1/x
```

其中：
- `M_s` = 饱和磁矩
- `μ` = 磁矩
- `k` = 玻尔兹曼常数
- `T` = 温度

### 数值稳定实现

为避免数值溢出，采用分段计算：

```python
def langevin(x, Ms, alpha):
    """Langevin函数，数值稳定实现。"""
    ax = alpha * x
    result = np.zeros_like(ax, dtype=float)

    # 小参数区域：泰勒展开 L(x) ≈ x/3 - x³/45 + 2x⁵/945
    small_mask = np.abs(ax) < 0.1
    result[small_mask] = (
        ax[small_mask] / 3.0
        - (ax[small_mask] ** 3) / 45.0
        + 2 * (ax[small_mask] ** 5) / 945.0
    )

    # 大参数区域：渐近展开 L(x) ≈ 1 - 1/x
    large_mask = np.abs(ax) > 20
    result[large_mask] = 1.0 - 1.0 / ax[large_mask]

    # 中等参数区域：标准公式
    medium_mask = ~small_mask & ~large_mask
    if np.any(medium_mask):
        coth_ax = np.cosh(ax[medium_mask]) / np.sinh(ax[medium_mask])
        result[medium_mask] = coth_ax - 1.0 / ax[medium_mask]

    return Ms * result
```

### 使用方法

```python
from backend.core.analysis import PhysicsAnalyzer, FitModelType

# 创建分析器
analyzer = PhysicsAnalyzer()

# 加载实验数据
H = np.linspace(-1000, 1000, 200)  # 磁场 (Oe)
M = ...  # 磁矩数据

# Langevin拟合
result = analyzer.fit_model(H, M, FitModelType.LANGEVIN)

print(f"饱和磁矩 Ms = {result['parameters']['Ms']:.4f}")
print(f"拟合参数 alpha = {result['parameters']['alpha']:.4f}")
print(f"R² = {result['r_squared']:.4f}")
```

## 磁滞回线分析

### 分析流程

磁滞回线分析包括以下步骤：

1. **背景扣除**：去除顺磁/抗磁杂质贡献
2. **矫顽力计算**：磁矩为零时的磁场
3. **剩磁计算**：磁场为零时的磁矩
4. **饱和磁矩计算**：高场区磁矩平均值
5. **矩形比计算**：剩磁/饱和磁矩

### 背景扣除

```python
from backend.core.analysis import PhysicsAnalyzer, BackgroundMethod

analyzer = PhysicsAnalyzer()

# 线性背景扣除
x_corrected, y_corrected, params = analyzer.subtract_background(
    x_field=H,
    y_moment=M,
    method=BackgroundMethod.LINEAR,
    high_field_threshold=800.0  # 高场阈值
)

# 多项式背景扣除
x_corrected, y_corrected, params = analyzer.subtract_background(
    x_field=H,
    y_moment=M,
    method=BackgroundMethod.POLYNOMIAL,
    polynomial_order=2
)

print(f"背景拟合 R² = {params['r_squared']:.4f}")
print(f"拟合系数 = {params['coefficients']}")
```

### 完整分析

```python
# 完整磁滞回线分析
result = analyzer.analyze_hysteresis_loop(
    x_field=H,
    y_moment=M,
    subtract_background=True,
    background_method=BackgroundMethod.LINEAR,
    saturation_threshold=800.0
)

# 输出结果
print("=== 磁滞回线参数 ===")
print(f"矫顽力 Hc = {result['Hc']:.2f} Oe")
print(f"正向矫顽力 Hc+ = {result['Hc_positive']:.2f} Oe")
print(f"负向矫顽力 Hc- = {result['Hc_negative']:.2f} Oe")
print(f"剩磁 Mr = {result['Mr']:.4f} emu")
print(f"正向剩磁 Mr+ = {result['Mr_positive']:.4f} emu")
print(f"负向剩磁 Mr- = {result['Mr_negative']:.4f} emu")
print(f"饱和磁矩 Ms = {result['Ms']:.4f} emu")
print(f"矩形比 = {result['squareness']:.4f}")
```

### 参数说明

| 参数 | 说明 | 计算方法 |
|------|------|----------|
| Hc | 矫顽力 | 磁矩为零时的磁场（插值） |
| Mr | 剩磁 | 磁场为零时的磁矩（插值） |
| Ms | 饱和磁矩 | 高场区磁矩绝对值的平均 |
| squareness | 矩形比 | Mr / Ms |

## 多模型拟合

### MultiModelFitter类

支持同时使用多个模型拟合数据，并自动比较选择最佳模型。

```python
from backend.core.analysis import (
    MultiModelFitter,
    braunbeck_function,
    calculate_goodness_of_fit
)

# 创建多模型拟合器
fitter = MultiModelFitter()

# 注册Braunbeck模型
fitter.register_model(
    name="Braunbeck",
    func=braunbeck_function,
    initial_params=[1.5, 100.0, 50.0],  # Bs, Hc, S
    bounds=([0.1, 0.0, 1.0], [10.0, 1000.0, 500.0]),
    param_names=["Bs", "Hc", "S"]
)

# 注册线性模型
fitter.register_model(
    name="Linear",
    func=lambda x, a, b: a * x + b,
    initial_params=[0.001, 0.0],
    param_names=["slope", "intercept"]
)

# 注册多项式模型
def polynomial(x, a, b, c):
    return a * x**2 + b * x + c

fitter.register_model(
    name="Polynomial",
    func=polynomial,
    initial_params=[0.0001, 0.001, 0.0],
    param_names=["a", "b", "c"]
)

# 执行所有模型拟合
results = fitter.fit_all(H, M)

# 比较模型
comparison = fitter.compare_models()
print(comparison['summary'])

# 获取最佳模型
best = fitter.get_best_model(criterion="aic")
print(f"\n最佳模型: {best.model_name}")
print(f"R² = {best.r_squared:.4f}")
print(f"AIC = {best.aic:.2f}")
print(f"参数: {best.params}")
```

### 拟合优度评估

```python
# 计算拟合优度指标
metrics = calculate_goodness_of_fit(
    y_observed=M,
    y_predicted=y_fit,
    n_params=3
)

print(f"R² = {metrics['r_squared']:.4f}")
print(f"RMSE = {metrics['rmse']:.4f}")
print(f"MAE = {metrics['mae']:.4f}")
print(f"AIC = {metrics['aic']:.2f}")
print(f"BIC = {metrics['bic']:.2f}")
```

### 指标说明

| 指标 | 说明 | 判断标准 |
|------|------|----------|
| R² | 决定系数 | 越接近1越好 |
| RMSE | 均方根误差 | 越小越好 |
| MAE | 平均绝对误差 | 越小越好 |
| AIC | Akaike信息准则 | 越小越好（平衡拟合与复杂度） |
| BIC | 贝叶斯信息准则 | 越小越好（对复杂度惩罚更严） |

### AIC权重计算

```python
# AIC权重表示每个模型为最佳模型的概率
delta_aic = comparison['delta_aic']
aic_weights = comparison['aic_weights']

for model, weight in aic_weights.items():
    print(f"{model}: ΔAIC={delta_aic[model]:.2f}, 权重={weight:.3f}")
```

## Braunbeck磁滞模型

### 模型公式

Braunbeck模型用于描述磁滞回线：

```
B(H) = Bs * tanh((H - Hc) / S) + Bs * tanh((H + Hc) / S)
```

参数说明：
- **Bs**: 饱和磁感应强度
- **Hc**: 矫顽力
- **S**: 磁滞宽度参数

### 使用方法

```python
from backend.core.analysis import PhysicsAnalyzer, FitModelType

analyzer = PhysicsAnalyzer()

# Braunbeck拟合
result = analyzer.fit_model(
    x_data=H,
    y_data=B,
    model_type=FitModelType.BRAUNBECK,
    initial_params={"Bs": 1.5, "Hc": 100.0, "S": 50.0}
)

print(f"Bs = {result['parameters']['Bs']:.4f} T")
print(f"Hc = {result['parameters']['Hc']:.2f} A/m")
print(f"S = {result['parameters']['S']:.2f} A/m")
print(f"R² = {result['r_squared']:.4f}")
```

## 完整代码示例

### 磁滞回线完整分析

```python
"""
磁滞回线完整分析示例

演示信号处理、磁滞分析和多模型拟合
"""
import numpy as np
from backend.core.analysis import (
    PhysicsAnalyzer,
    BackgroundMethod,
    FitModelType,
    MultiModelFitter,
    braunbeck_function,
    generate_analysis_report
)


def analyze_hysteresis():
    """执行完整的磁滞回线分析。"""
    # 1. 加载实验数据
    H = np.linspace(-1000, 1000, 200)  # 磁场 (Oe)
    # 模拟磁滞回线数据
    Bs, Hc, S = 1.5, 100.0, 50.0
    B = braunbeck_function(H, Bs, Hc, S)
    B_noisy = B + np.random.normal(0, 0.03, len(H))

    # 2. 创建分析器
    analyzer = PhysicsAnalyzer()

    # 3. 信号平滑
    B_smooth = analyzer.smooth_signal(
        y_data=B_noisy,
        method="savgol",
        window_length=11,
        polyorder=2
    )

    # 4. 磁滞回线分析
    hyst_result = analyzer.analyze_hysteresis_loop(
        x_field=H,
        y_moment=B_smooth,
        subtract_background=True,
        background_method=BackgroundMethod.LINEAR
    )

    print("=== 磁滞回线参数 ===")
    print(f"矫顽力 Hc = {hyst_result['Hc']:.2f} Oe")
    print(f"剩磁 Mr = {hyst_result['Mr']:.4f}")
    print(f"饱和磁矩 Ms = {hyst_result['Ms']:.4f}")
    print(f"矩形比 = {hyst_result['squareness']:.4f}")

    # 5. 多模型拟合
    fitter = MultiModelFitter()

    # 注册模型
    fitter.register_model(
        name="Braunbeck",
        func=braunbeck_function,
        initial_params=[1.5, 100.0, 50.0],
        bounds=([0.1, 0.0, 1.0], [10.0, 1000.0, 500.0]),
        param_names=["Bs", "Hc", "S"]
    )

    fitter.register_model(
        name="Langevin",
        func=lambda x, Ms, alpha: Ms * (1/np.tanh(alpha*x) - 1/(alpha*x))
            if np.all(np.abs(alpha*x) > 0.1) else Ms * alpha * x / 3,
        initial_params=[1.5, 0.01],
        param_names=["Ms", "alpha"]
    )

    # 执行拟合
    fit_results = fitter.fit_all(H, B_smooth)

    # 6. 模型比较
    comparison = fitter.compare_models()
    print("\n" + comparison['summary'])

    # 7. 生成分析报告
    report = generate_analysis_report(
        h_data=H,
        b_data=B_smooth,
        fit_results=fit_results,
        experiment_id="EXP_2024_001"
    )

    print(f"\n=== 分析报告 ===")
    print(f"实验ID: {report.experiment_id}")
    print(f"时间戳: {report.timestamp}")
    print(f"最佳模型: {report.best_model}")
    print(f"推荐建议: {report.recommendations}")

    return report


if __name__ == "__main__":
    report = analyze_hysteresis()
```

### 数据导出示例

```python
"""
数据导出示例

演示CSV、HDF5、JSON格式导出
"""
import numpy as np
from backend.core.analysis import PhysicsAnalyzer, ExportFormat


def export_analysis_data():
    """导出分析数据。"""
    # 创建分析器
    analyzer = PhysicsAnalyzer()

    # 加载数据
    x = np.linspace(0, 10, 100)
    y = np.sin(x)

    # 元数据
    metadata = {
        "experiment_id": "EXP_001",
        "sample": "Fe3O4 nanoparticles",
        "temperature": 300.0,
        "operator": "张三"
    }

    # 导出为CSV
    analyzer.export_data(
        filepath="data/export.csv",
        x_data=x,
        y_data=y,
        format=ExportFormat.CSV,
        metadata=metadata,
        delimiter=",",
        precision=15
    )

    # 导出为HDF5
    analyzer.export_data(
        filepath="data/export.h5",
        x_data=x,
        y_data=y,
        format=ExportFormat.HDF5,
        metadata=metadata,
        group_path="/measurement/magnetic"
    )

    # 导出为JSON
    analyzer.export_data(
        filepath="data/export.json",
        x_data=x,
        y_data=y,
        format=ExportFormat.JSON,
        metadata=metadata,
        indent=2
    )

    print("数据导出完成！")


if __name__ == "__main__":
    export_analysis_data()
```

## 最佳实践

### 1. 信号平滑

- **先平滑后分析**：在进行拟合前先进行适当的平滑处理
- **保留信号特征**：不要过度平滑，避免丢失重要信号特征
- **参数选择**：
  - Savitzky-Golay：窗口长度11-31，多项式阶数2-3
  - 巴特沃斯：截止频率 < 采样率/10

### 2. 背景扣除

- **高场阈值选择**：建议取磁场最大值的80%
- **方法选择**：
  - 线性背景：适用于弱顺磁/抗磁背景
  - 多项式背景：适用于复杂背景

### 3. 模型选择

| 数据特征 | 推荐模型 | 说明 |
|----------|----------|------|
| 超顺磁 | Langevin | 描述超顺磁颗粒 |
| 铁磁磁滞 | Braunbeck | 描述磁滞回线 |
| 线性响应 | Linear | 弱场近似 |
| 一般拟合 | Polynomial | 多项式拟合 |

### 4. 拟合优度评估

- **R² > 0.95**：拟合良好
- **R² 0.90-0.95**：拟合可接受
- **R² < 0.90**：考虑其他模型或检查数据

### 5. 数值稳定性

- 使用数值稳定的函数实现（如分段计算）
- 设置合理的参数边界
- 提供合理的初始参数估计

## 故障排除

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 拟合不收敛 | 初始参数不当 | 调整初始参数，设置边界 |
| R²值很低 | 模型选择不当 | 尝试其他模型，使用多模型拟合 |
| 数值溢出 | 参数范围过大 | 使用数值稳定实现，限制参数范围 |
| 背景扣除异常 | 高场数据不足 | 增加高场数据点，调整阈值 |
