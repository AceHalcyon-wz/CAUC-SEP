## 功能概述

皮安表采集模块（`Picoammeter`）提供高精度微电流测量功能，支持多通道同步采集、可配置采样率、多种滤波方式和实时信噪比计算。该模块是实现pA级微弱电流信号采集的核心组件。

### 核心特性

| 特性 | 说明 |
|------|------|
| 电流测量范围 | 1pA - 1mA |
| 电流分辨率 | 1pA |
| 通道数 | 4通道同步采集 |
| 采样率 | 1Hz - 1kHz |
| 滤波类型 | 低通/移动平均/中值滤波 |
| 实时分析 | SNR计算、自动量程 |

## 多通道采集

### 通道配置

每个通道支持独立配置，包括量程、滤波类型和偏移校准。

```python
from backend.core.picoammeter import (
    Picoammeter,
    CurrentRange,
    FilterType
)

# 创建皮安表实例
config = {
    "simulation": True,
    "sample_rate": 100.0,
    "buffer_size": 1000
}
picoammeter = Picoammeter("pico_1", config)

# 连接设备
await picoammeter.connect()

# 配置通道0
picoammeter.configure_channel(
    channel=0,
    enabled=True,
    current_range=CurrentRange.RANGE_1UA,
    filter_type=FilterType.LOWPASS,
    filter_cutoff=10.0,
    offset=0.0
)

# 配置通道1
picoammeter.configure_channel(
    channel=1,
    enabled=True,
    current_range=CurrentRange.RANGE_100NA,
    filter_type=FilterType.MOVING_AVERAGE,
    filter_window=5
)
```

### 电流量程选择

| 量程 | 最大值 | 分辨率 | 适用场景 |
|------|--------|--------|----------|
| RANGE_1NA | 1nA | 1pA | 极微弱信号 |
| RANGE_10NA | 10nA | 10pA | 弱信号测量 |
| RANGE_100NA | 100nA | 100pA | 一般弱信号 |
| RANGE_1UA | 1μA | 1nA | 常用测量 |
| RANGE_10UA | 10μA | 10nA | 中等电流 |
| RANGE_100UA | 100μA | 100nA | 较大电流 |
| RANGE_1MA | 1mA | 1μA | 大电流测量 |

### 启动/停止采集

```python
# 启动多通道同步采集
await picoammeter.start_acquisition()

# 读取所有通道最新数据
all_data = await picoammeter.read_all_channels()
for i, data in enumerate(all_data):
    if data:
        print(f"通道{i}: {data.current_pa:.2f}pA, SNR: {data.snr_db:.1f}dB")

# 停止采集
await picoammeter.stop_acquisition()
```

## 数据采集参数

### 采样率配置

采样率决定了数据采集的时间分辨率，范围1Hz-1kHz。

```python
# 设置采样率为100Hz
picoammeter.set_sample_rate(100.0)

# 获取当前采样率
rate = picoammeter.sample_rate
print(f"当前采样率: {rate}Hz")
```

**采样率选择建议**：

| 信号特征 | 推荐采样率 | 说明 |
|----------|------------|------|
| 直流信号 | 1-10Hz | 低采样率减少噪声 |
| 低频变化 | 10-100Hz | 平衡精度和速度 |
| 快速变化 | 100-1000Hz | 捕捉瞬态响应 |

### 缓冲区配置

数据缓冲区用于存储历史采集数据，支持数据回溯分析。

```python
config = {
    "simulation": True,
    "sample_rate": 100.0,
    "buffer_size": 1000,      # 每通道缓冲区大小
    "snr_calc_window": 100    # SNR计算窗口
}
picoammeter = Picoammeter("pico_1", config)
```

### 读取缓冲区数据

```python
# 读取通道0的最新数据
data = await picoammeter.read_channel(0)
if data:
    print(f"电流: {data.current_pa}pA")
    print(f"时间戳: {data.timestamp}s")
    print(f"SNR: {data.snr_db}dB")
    print(f"原始电流: {data.raw_current_pa}pA")

# 读取通道0的最近100个数据点
buffer_data = await picoammeter.read_channel_buffer(0, count=100)
for data in buffer_data:
    print(f"{data.timestamp:.3f}s: {data.current_pa:.2f}pA")

# 清空缓冲区
picoammeter.clear_buffer(channel=0)  # 清空通道0
picoammeter.clear_buffer()           # 清空所有通道
```

## 滤波功能

### 滤波类型

| 滤波类型 | 说明 | 适用场景 |
|----------|------|----------|
| NONE | 无滤波 | 原始信号分析 |
| LOWPASS | 低通滤波 | 去除高频噪声 |
| MOVING_AVERAGE | 移动平均 | 平滑信号、降低随机噪声 |
| MEDIAN | 中值滤波 | 去除脉冲噪声 |

### 低通滤波

一阶IIR低通滤波器，有效去除高频噪声。

```python
# 配置低通滤波
picoammeter.configure_channel(
    channel=0,
    filter_type=FilterType.LOWPASS,
    filter_cutoff=10.0  # 截止频率10Hz
)
```

**滤波器参数**：

```
y[n] = α * x[n] + (1 - α) * y[n-1]
α = 2π*fc*dt / (2π*fc*dt + 1)
```

其中：
- `fc` = 截止频率
- `dt` = 采样周期

### 移动平均滤波

对窗口内数据取平均值，有效平滑随机噪声。

```python
# 配置移动平均滤波
picoammeter.configure_channel(
    channel=0,
    filter_type=FilterType.MOVING_AVERAGE,
    filter_window=5  # 窗口大小
)
```

### 中值滤波

对窗口内数据取中值，有效去除脉冲噪声。

```python
# 配置中值滤波
picoammeter.configure_channel(
    channel=0,
    filter_type=FilterType.MEDIAN,
    filter_window=7  # 窗口大小（建议奇数）
)
```

## SNR分析

### 信噪比计算

信噪比（SNR）用于评估信号质量，计算公式：

```
SNR = 20 * log10(信号RMS / 噪声RMS)
```

```python
# 计算通道0的信噪比
snr = picoammeter.calculate_snr(channel=0)
print(f"信噪比: {snr:.1f}dB")

# 使用自定义窗口大小
snr = picoammeter.calculate_snr(channel=0, window_size=50)
```

### SNR解读

| SNR范围 | 信号质量 | 建议 |
|---------|----------|------|
| > 40dB | 优秀 | 数据可靠 |
| 20-40dB | 良好 | 可用，注意噪声 |
| 10-20dB | 一般 | 建议滤波处理 |
| < 10dB | 较差 | 检查实验设置 |

### 噪声分析

```python
# 读取数据对象包含噪声信息
data = await picoammeter.read_channel(0)
if data:
    print(f"信号RMS: {data.signal_rms_pa:.2f}pA")
    print(f"噪声RMS: {data.noise_rms_pa:.2f}pA")
    print(f"SNR: {data.snr_db:.1f}dB")
```

## 自动量程

### 自动量程切换

根据当前测量值自动选择最佳量程，确保测量精度最优。

```python
# 单通道自动量程
selected_range = picoammeter.auto_range(channel=0)
print(f"选择的量程: {selected_range.value}")

# 所有启用的通道自动量程
selected_ranges = picoammeter.auto_range_all()
for i, rng in enumerate(selected_ranges):
    print(f"通道{i}: {rng.value}")
```

## 完整代码示例

### 基本使用

```python
"""
皮安表基本使用示例

演示多通道采集、滤波和SNR分析
"""
import asyncio
from backend.core.picoammeter import (
    Picoammeter,
    CurrentRange,
    FilterType
)


async def main():
    # 1. 创建皮安表实例
    config = {
        "simulation": True,
        "sample_rate": 100.0,
        "buffer_size": 1000,
        "snr_calc_window": 100
    }
    pico = Picoammeter("pico_main", config)

    # 2. 连接设备
    if not await pico.connect():
        print("连接失败！")
        return

    # 3. 配置通道
    # 通道0：低通滤波
    pico.configure_channel(
        channel=0,
        enabled=True,
        current_range=CurrentRange.RANGE_1UA,
        filter_type=FilterType.LOWPASS,
        filter_cutoff=10.0
    )

    # 通道1：移动平均滤波
    pico.configure_channel(
        channel=1,
        enabled=True,
        current_range=CurrentRange.RANGE_100NA,
        filter_type=FilterType.MOVING_AVERAGE,
        filter_window=5
    )

    # 通道2：中值滤波
    pico.configure_channel(
        channel=2,
        enabled=True,
        current_range=CurrentRange.RANGE_10UA,
        filter_type=FilterType.MEDIAN,
        filter_window=7
    )

    # 通道3：无滤波
    pico.configure_channel(
        channel=3,
        enabled=True,
        current_range=CurrentRange.RANGE_1UA,
        filter_type=FilterType.NONE
    )

    # 4. 启动采集
    print("启动采集...")
    await pico.start_acquisition()

    # 5. 实时数据监控
    for i in range(10):
        await asyncio.sleep(0.5)

        # 读取所有通道数据
        all_data = await pico.read_all_channels()

        print(f"\n--- 第{i+1}次读取 ---")
        for ch, data in enumerate(all_data):
            if data:
                print(f"通道{ch}: {data.current_pa:.2f}pA, "
                      f"SNR: {data.snr_db:.1f}dB")

    # 6. 计算SNR
    print("\n=== SNR分析 ===")
    for ch in range(4):
        snr = pico.calculate_snr(ch)
        print(f"通道{ch} SNR: {snr:.1f}dB")

    # 7. 自动量程
    print("\n=== 自动量程 ===")
    selected_ranges = pico.auto_range_all()
    for ch, rng in enumerate(selected_ranges):
        print(f"通道{ch}: {rng.value}")

    # 8. 停止采集并断开连接
    await pico.stop_acquisition()
    await pico.disconnect()
    print("\n测试完成！")


if __name__ == "__main__":
    asyncio.run(main())
```

### 高级应用：长时间数据采集

```python
"""
长时间数据采集示例

演示数据采集、缓冲区管理和数据导出
"""
import asyncio
import numpy as np
from datetime import datetime
from backend.core.picoammeter import Picoammeter, CurrentRange, FilterType


async def long_term_acquisition():
    """执行长时间数据采集。"""
    config = {
        "simulation": True,
        "sample_rate": 10.0,      # 10Hz采样
        "buffer_size": 10000,     # 大缓冲区
        "snr_calc_window": 100
    }
    pico = Picoammeter("pico_long", config)

    await pico.connect()

    # 配置通道
    pico.configure_channel(
        channel=0,
        enabled=True,
        current_range=CurrentRange.RANGE_1UA,
        filter_type=FilterType.LOWPASS,
        filter_cutoff=1.0  # 1Hz截止频率
    )

    # 启动采集
    await pico.start_acquisition()

    # 采集60秒
    acquisition_time = 60  # 秒
    sample_rate = 10
    total_samples = acquisition_time * sample_rate

    print(f"开始采集 {acquisition_time} 秒...")

    # 等待采集完成
    await asyncio.sleep(acquisition_time)

    # 读取缓冲区数据
    buffer_data = await pico.read_channel_buffer(0)

    # 数据分析
    currents = np.array([d.current_pa for d in buffer_data])
    timestamps = np.array([d.timestamp for d in buffer_data])

    print(f"\n=== 采集结果 ===")
    print(f"采集点数: {len(currents)}")
    print(f"时间范围: {timestamps[0]:.2f}s - {timestamps[-1]:.2f}s")
    print(f"电流范围: {currents.min():.2f}pA - {currents.max():.2f}pA")
    print(f"平均电流: {currents.mean():.2f}pA")
    print(f"标准差: {currents.std():.2f}pA")

    # SNR分析
    snr = pico.calculate_snr(0)
    print(f"信噪比: {snr:.1f}dB")

    await pico.stop_acquisition()
    await pico.disconnect()


if __name__ == "__main__":
    asyncio.run(long_term_acquisition())
```

## 最佳实践

### 1. 量程选择

- **从大量程开始**：首次测量使用较大量程，避免过载
- **逐步降低量程**：根据测量值逐步降低量程，提高精度
- **使用自动量程**：不确定信号大小时使用自动量程功能

### 2. 滤波选择

| 噪声类型 | 推荐滤波 | 参数建议 |
|----------|----------|----------|
| 高频噪声 | 低通滤波 | 截止频率 < 采样率/10 |
| 随机噪声 | 移动平均 | 窗口大小 5-15 |
| 脉冲噪声 | 中值滤波 | 窗口大小 5-11 |
| 混合噪声 | 组合使用 | 先中值后低通 |

### 3. 采样率设置

- **奈奎斯特准则**：采样率 > 2 × 信号最高频率
- **实际建议**：采样率 > 10 × 信号最高频率
- **直流测量**：使用较低采样率（1-10Hz）减少噪声

### 4. 接地和屏蔽

- 使用屏蔽电缆连接信号源
- 确保良好的接地连接
- 避免在强电磁干扰环境下测量

### 5. 安全注意事项

- **实验时必须有人值守**
- **首次使用前验证量程参数**
- **避免超过量程最大值**
- **注意静电防护**

## 故障排除

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 数据异常或无数据 | 设备未连接或通道未启用 | 检查连接状态和通道配置 |
| SNR过低 | 噪声过大或信号微弱 | 检查接地、屏蔽，启用滤波 |
| 量程溢出 | 信号超过量程范围 | 切换到更大量程或使用自动量程 |
| 数据跳变 | 接触不良或干扰 | 检查连接，使用中值滤波 |
