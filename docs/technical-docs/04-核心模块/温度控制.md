# 温度控制模块

## 概述

温度控制器模块实现 PID 闭环控制和程序控温，支持多路传感器、温度保护和温度曲线记录。该模块位于 `backend/core/temperature_controller.py`，适用于液氮釜等低温实验环境。

## 功能特性

- **PID控制**: 参数配置、自动调谐、双向控制（加热/冷却）
- **程序控温**: 多段温度程序编排
- **保护功能**: 高低温限值、温度变化率限制
- **多路传感器**: 4通道传感器支持
- **历史记录**: 温度历史数据管理

## 技术规范

| 参数 | 规格 |
|------|------|
| 温度范围 | 77K-400K（液氮温度） |
| 温度精度 | ±0.1K |
| 升降温速率 | -10 到 10 K/min |
| 高温保护 | >450K |
| 低温保护 | <70K |
| 变化率保护 | >20 K/min |
| 传感器通道 | 4通道 |

### PIDParameters - PID参数数据类

```python
@dataclass
class PIDParameters:
    """PID控制参数数据类。"""

    kp: float = 1.0              # 比例系数（0.1-100）
    ki: float = 0.1              # 积分系数（0.001-10）
    kd: float = 0.01             # 微分系数（0.001-10）
    setpoint: float = 300.0      # 目标温度（K）
    output_min: float = -100.0   # 最小输出（%），支持负值用于冷却
    output_max: float = 100.0    # 最大输出（%）
    integral_limit: float = 0.0  # 积分限幅（防止积分饱和）
```

### TemperatureProgramSegment - 程序段数据类

```python
@dataclass
class TemperatureProgramSegment:
    """温度程序段数据类。"""

    segment_id: int = 0          # 程序段ID
    tolerance: float = 0.5       # 温度跟随容差（K）

```

## PID闭环控制

### PID控制原理

控制器输出计算公式：

```
output = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt
```

其中：
- `e(t) = setpoint - current_temperature`（误差）
- 支持双向输出：正值加热，负值冷却（液氮）

### 启动PID控制

```python
# 连接设备
await controller.connect()

# 设置目标温度
await controller.set_temperature(300.0)

# 启动PID控制
success = await controller.start_pid_control()

# 监控控制过程
while controller.mode.value == "pid":
    print(f"温度: {controller.current_temperature:.2f}K")
    print(f"输出: {controller.current_output:.1f}%")
    await asyncio.sleep(1)
```

### 设置PID参数

```python
# 设置单个参数
await controller.set_pid_parameters(kp=2.0)

# 设置多个参数
await controller.set_pid_parameters(
    kp=2.0,

    kd=0.02,
    setpoint=350.0

```

### 停止PID控制

```python

```

## 程序控温

### 程序段说明

| 参数 | 说明 |
|------|------|
| target_temperature | 目标温度（K） |
| ramp_rate | 升降温速率（K/min），正值升温，负值降温，0表示立即跳转 |
| hold_time | 恒温时间（秒） |
| tolerance | 温度跟随容差（K） |
| timeout | 段执行超时时间（秒），0表示无限制 |

### 创建温度程序

```python
from backend.core.temperature_controller import TemperatureProgramSegment

# 创建温度程序
program = [
    TemperatureProgramSegment(
        target_temperature=300.0,
        ramp_rate=2.0,      # 2K/min升温
        hold_time=60.0      # 保持60秒
    ),
    TemperatureProgramSegment(
        target_temperature=350.0,
        ramp_rate=1.0,      # 1K/min升温
        hold_time=120.0     # 保持120秒
    ),
    TemperatureProgramSegment(
        target_temperature=300.0,
        ramp_rate=-2.0,     # 2K/min降温
        hold_time=0.0       # 不保持
    ),
]

# 加载程序
await controller.load_program(program)
```

### 启动程序控温

```python
# 启动程序
success = await controller.start_program()

# 监控程序执行
while controller.mode.value == "program":
    status = await controller.get_program_status()
    print(f"当前段: {status['current_segment']}/{status['total_segments']}")
    print(f"温度: {controller.current_temperature:.2f}K")
    await asyncio.sleep(1)

# 停止程序
await controller.stop_program()
```

### 获取程序状态

### 保护回调

## 完整使用示例

### 基础PID控制

```python
import asyncio
from backend.core.temperature_controller import TemperatureController


async def pid_control_example():
    # 创建控制器
    controller = TemperatureController(
        device_id="temp_1",
        config={"simulation": True}
    )

    try:
        # 连接
        if await controller.connect():
            print("连接成功")

            # 设置目标温度
            await controller.set_temperature(300.0)

            # 启动PID控制
            await controller.start_pid_control()

            # 运行30秒
            for _ in range(30):
                print(f"温度: {controller.current_temperature:.2f}K, "
                      f"输出: {controller.current_output:.1f}%")
                await asyncio.sleep(1)

            # 停止
            await controller.stop_pid_control()

    finally:
        await controller.disconnect()


asyncio.run(pid_control_example())
```

### 程序控温示例

```python
from backend.core.temperature_controller import (
    TemperatureController,
    TemperatureProgramSegment
)


async def program_control_example():
    controller = TemperatureController("temp_1", {"simulation": True})

    try:
        await controller.connect()

        # 创建温度程序
        program = [
            TemperatureProgramSegment(300.0, ramp_rate=2.0, hold_time=30.0),
            TemperatureProgramSegment(350.0, ramp_rate=1.0, hold_time=60.0),
            TemperatureProgramSegment(300.0, ramp_rate=-2.0, hold_time=0.0),
        ]

        # 加载并启动程序
        await controller.load_program(program)
        await controller.start_program()

        # 监控执行
        while controller.mode.value == "program":
            status = await controller.get_program_status()
            print(f"段 {status['current_segment']+1}/{status['total_segments']}: "
                  f"{controller.current_temperature:.2f}K")
            await asyncio.sleep(1)

        print("程序执行完成")

    finally:
        await controller.disconnect()


asyncio.run(program_control_example())
```

## 常见问题

### Q1: PID控制不稳定？

**A**: 调整PID参数，建议从保守值开始：

```python
# 保守参数
await controller.set_pid_parameters(kp=0.5, ki=0.05, kd=0.005)

# 如果响应太慢，逐步增大Kp
# 如果有稳态误差，适当增大Ki
# 如果有振荡，增大Kd
```

### Q2: 程序执行卡住？

**A**: 检查温度跟随情况和超时设置：

```python
status = await controller.get_program_status()
print(f"当前段: {status['current_segment']}")
print(f"温度偏差: {abs(controller.current_temperature - target):.2f}K")

# 增大容差或设置超时
segment.tolerance = 1.0  # 放宽容差
segment.timeout = 300.0  # 设置超时
```

### Q3: 保护频繁触发？

**A**: 检查保护阈值设置是否合理：

```python
# 读取当前保护配置
status = await controller.read_status()
print(f"高温保护: {status['protection']['high_temp_limit']}K")
print(f"低温保护: {status['protection']['low_temp_limit']}K")
print(f"变化率保护: {status['protection']['max_rate_limit']}K/min")

# 根据实际需求调整
await controller.set_protection_config(
    high_temp_limit=450.0,
    max_rate_limit=30.0  # 放宽变化率限制
)
```

### Q4: 温度读数异常？

**A**: 检查传感器状态和校准：

```python
# 读取所有传感器状态
sensors = await controller.read_all_sensors()
for s in sensors:
    if s['fault_detected']:
        print(f"传感器 {s['channel_id']} 故障: {s['fault_message']}")

# 检查校准参数
channel = controller._sensor_channels[0]
print(f"校准偏移: {channel.calibration_offset}K")
print(f"校准系数: {channel.calibration_scale}")
```
