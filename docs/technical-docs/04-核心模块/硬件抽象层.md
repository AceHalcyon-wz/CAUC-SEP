# 硬件抽象层 (Hardware Abstraction Layer)

## 概述

硬件抽象层（HAL）采用抽象基类（ABC）设计模式，为所有硬件设备定义统一接口。新设备驱动通过实现抽象接口即可无缝集成到系统中，支持热插拔式添加。

HAL 位于 `backend/core/abstract.py`，是整个硬件驱动体系的基础架构。

## 设计原则

### 1. 统一接口

所有硬件设备驱动都必须继承 `AbstractDevice` 基类，确保：
- 统一的生命周期管理（连接、断开、复位）
- 统一的状态查询接口
- 统一的错误处理机制

### 2. 状态机管理

设备状态通过 `DeviceStatus` 枚举管理，支持完整的状态转换验证。

### 3. 扩展性

通过继承机制支持设备类型扩展：
- `AbstractDevice` - 所有设备的基类
- `AbstractStepper` - 步进电机专用接口（继承自 AbstractDevice）

## 核心组件

### DeviceStatus - 设备状态枚举

```python
class DeviceStatus(Enum):
    """设备状态枚举。

    状态机说明：
        DISCONNECTED → CONNECTING → READY → BUSY → READY
        任何状态都可能转变为 ERROR 或 EMERGENCY_STOP
    """

    DISCONNECTED = "disconnected"      # 断开连接
    CONNECTING = "connecting"          # 连接中
    READY = "ready"                    # 就绪
    BUSY = "busy"                      # 忙碌（执行操作中）
    ERROR = "error"                    # 错误状态
    EMERGENCY_STOP = "emergency_stop"  # 急停状态
```

#### 状态转换规则

| 当前状态 | 可转换目标状态 |
|---------|--------------|
| DISCONNECTED | CONNECTING |
| CONNECTING | READY, ERROR, DISCONNECTED |
| READY | BUSY, ERROR, EMERGENCY_STOP, DISCONNECTED |
| BUSY | READY, ERROR, EMERGENCY_STOP |
| ERROR | DISCONNECTED, READY（复位后） |
| EMERGENCY_STOP | DISCONNECTED, READY（复位后） |

#### 状态转换验证

```python
# 检查状态转换是否合法
if DeviceStatus.READY.can_transition_to(DeviceStatus.BUSY):
    device.status = DeviceStatus.BUSY

# 获取合法转换映射
transitions = DeviceStatus.get_valid_transitions()
# 返回: {DeviceStatus.READY: {DeviceStatus.BUSY, DeviceStatus.ERROR, ...}, ...}
```

### SoftwareLimitConfig - 软件限位配置

用于定义设备的软件限位，提供安全保护功能。

```python
class SoftwareLimitConfig:
    """软件限位配置类。

    Attributes:
        positive_limit: 正向限位（单位：毫米）
        negative_limit: 负向限位（单位：毫米）
        enable: 是否启用限位检查
    """

    def __init__(
        self,
        positive_limit: float = 100.0,
        negative_limit: float = -100.0,
        enable: bool = True
    ):
        ...
```

#### 核心方法

| 方法 | 说明 |
|------|------|
| `is_within_limits(position)` | 检查位置是否在限位范围内 |
| `clamp_position(position)` | 将位置限制在有效范围内 |
| `get_range()` | 获取限位范围大小 |
| `to_dict()` | 序列化为字典 |
| `from_dict(data)` | 从字典反序列化 |

#### 使用示例

```python
# 创建限位配置
limit_config = SoftwareLimitConfig(
    positive_limit=100.0,   # 正向限位 100mm
    negative_limit=-100.0,  # 负向限位 -100mm
    enable=True
)

# 检查位置
if limit_config.is_within_limits(50.0):
    print("位置有效")

# 限制位置
clamped = limit_config.clamp_position(150.0)  # 返回 100.0
```

### AbstractDevice - 抽象设备基类

所有硬件设备驱动的基类，定义统一的生命周期和状态管理接口。

```python
class AbstractDevice(ABC):
    """硬件设备抽象基类。

    所有硬件设备驱动都必须继承此类并实现所有抽象方法。
    提供状态管理、错误处理和连接管理的基础功能。
    """

    def __init__(self, device_id: str, config: dict[str, Any]):
        self.device_id = device_id
        self.config = config
        self._status = DeviceStatus.DISCONNECTED
        self._last_error: str | None = None
```

#### 抽象方法（必须实现）

| 方法 | 说明 |
|------|------|
| `connect()` | 建立设备连接 |
| `disconnect()` | 断开设备连接 |
| `read_status()` | 读取设备状态 |

#### 属性

| 属性 | 说明 |
|------|------|
| `status` | 设备当前状态 |
| `is_connected` | 是否已连接 |
| `is_ready` | 是否就绪 |
| `is_busy` | 是否忙碌 |
| `is_error` | 是否处于错误状态 |
| `is_emergency_stop` | 是否处于急停状态 |
| `last_error` | 最后一次错误信息 |

#### 完整实现示例

```python
from backend.core.abstract import AbstractDevice, DeviceStatus
from typing import Any


class MyDevice(AbstractDevice):
    """自定义设备实现示例。"""

    def __init__(self, device_id: str, config: dict[str, Any]):
        super().__init__(device_id, config)
        # 初始化设备特定属性
        self._value = 0.0

    async def connect(self) -> bool:
        """建立设备连接。"""
        try:
            self.status = DeviceStatus.CONNECTING

            # 执行连接逻辑...
            # 例如：打开串口、建立TCP连接等

            self.status = DeviceStatus.READY
            return True

        except Exception as e:
            self.set_error(f"连接失败: {str(e)}")
            return False

    async def disconnect(self) -> bool:
        """断开设备连接。"""
        # 释放资源
        self.status = DeviceStatus.DISCONNECTED
        return True

    async def read_status(self) -> dict[str, Any]:
        """读取设备状态。"""
        return {
            "device_id": self.device_id,
            "status": self.status.value,
            "connected": self.is_connected,
            "value": self._value,
        }

    async def do_something(self) -> bool:
        """执行操作示例。"""
        if not self.is_ready:
            raise RuntimeError("设备未就绪")

        self.status = DeviceStatus.BUSY
        try:
            # 执行操作...
            self._value = 42.0
            return True
        finally:
            self.status = DeviceStatus.READY
```

### AbstractStepper - 步进电机抽象接口

继承自 `AbstractDevice`，添加步进电机专用功能。

```python
class AbstractStepper(AbstractDevice, ABC):
    """步进电机抽象接口。

    所有步进电机驱动都必须继承此类并实现所有抽象方法。
    包含基础设备功能和步进电机专用功能。
    """

    def __init__(self, device_id: str, config: dict[str, Any]):
        super().__init__(device_id, config)
        self._limit_config = SoftwareLimitConfig()
```

#### 抽象方法（必须实现）

| 方法 | 说明 |
|------|------|
| `move_abs(position, speed, accel, decel)` | 绝对位置定位 |
| `move_rel(distance, speed, accel, decel)` | 相对位置定位 |
| `jog(direction, speed)` | JOG点动模式 |
| `home(mode)` | 回零操作 |
| `read_position()` | 读取当前位置 |
| `stop(emergency)` | 停止运动 |

#### 软件限位管理

```python
# 设置软件限位
stepper.set_limits(positive=100.0, negative=-100.0, enable=True)

# 检查位置
if stepper.check_position_limit(50.0):
    print("位置在限位范围内")

# 获取限位配置
limits = stepper.limit_config
print(f"正向限位: {limits.positive_limit}mm")
```

#### 完整实现示例

```python

from typing import Any

    """自定义步进电机实现示例。"""

    async def move_abs(
        self,
        position: float,
        speed: float,
        accel: float,
        decel: float

        """绝对位置定位。"""
        # 检查软件限位
        if not self.check_position_limit(position):
            raise ValueError(f"位置 {position}mm 超出限位范围")

        if not self.is_ready:
            raise RuntimeError("设备未就绪")

        self.status = DeviceStatus.BUSY
        try:
            # 执行定位逻辑...
            # 例如：发送Modbus命令到驱动器
            return True
        finally:
            self.status = DeviceStatus.READY

    async def move_rel(
        self,
        distance: float,
        speed: float,
        accel: float,
        decel: float
    ) -> bool:
        """相对位置定位。"""
        current = await self.read_position()
        target = current["position_mm"] + distance
        return await self.move_abs(target, speed, accel, decel)

    async def jog(self, direction: int, speed: float) -> bool:
        """JOG点动模式。"""

            raise ValueError("方向必须是 1 或 -1")
        # 实现JOG逻辑...
        return True

    async def home(self, mode: str = "origin") -> bool:
        """回零操作。"""

        return True

    async def read_position(self) -> dict[str, float]:
        """读取当前位置。"""
        return {
            "position_mm": 0.0,
            "position_steps": 0
        }

    async def stop(self, emergency: bool = False) -> bool:
```

## 最佳实践

### 1. 状态管理

```python
# 推荐：使用状态属性自动验证
device.status = DeviceStatus.BUSY  # 自动记录非法转换警告

# 严格模式：非法转换抛出异常
device.set_status_strict(DeviceStatus.BUSY)
```

### 2. 错误处理

```python
# 设置错误状态
device.set_error("通信超时")

# 清除错误（不改变状态）
device.clear_error()

# 复位设备
if await device.reset():
    print("设备复位成功")
```

### 3. 软件限位

```python
# 在运动前检查限位
if not stepper.check_position_limit(target_position):
    raise ValueError(f"目标位置 {target_position}mm 超出限位范围")

# 使用clamp确保安全
safe_position = stepper.limit_config.clamp_position(target_position)
```

### 4. 异步操作

```python
# 所有设备操作都是异步的
async def control_device():
    device = MyDevice("dev1", {"port": "COM1"})

    # 连接
    if await device.connect():
        # 执行操作
        await device.do_something()

        # 读取状态
        status = await device.read_status()
        print(status)

        # 断开
        await device.disconnect()
```

## 常见问题

### Q1: 状态转换失败怎么办？

**A**: 检查状态转换规则，使用 `can_transition_to()` 方法验证：

```python
if device.status.can_transition_to(DeviceStatus.READY):
    device.status = DeviceStatus.READY
else:
    print(f"无法从 {device.status.value} 转换到 ready")
```

### Q2: 如何实现自定义设备？

**A**: 继承 `AbstractDevice` 或 `AbstractStepper`，实现所有抽象方法：

```python
class MyCustomDevice(AbstractDevice):
    async def connect(self) -> bool: ...
    async def disconnect(self) -> bool: ...
    async def read_status(self) -> dict[str, Any]: ...
```

### Q3: 软件限位不生效？

**A**: 确保 `enable=True` 并在运动方法中调用 `check_position_limit()`：

```python
# 检查配置
print(f"限位启用: {stepper.limit_config.enable}")
print(f"限位范围: [{stepper.limit_config.negative_limit}, {stepper.limit_config.positive_limit}]")
```

### Q4: 如何处理设备异常？

**A**: 使用 `set_error()` 方法记录错误，状态会自动设置为 ERROR：

```python
try:
    await device.do_operation()
except Exception as e:
    device.set_error(str(e))
    # 状态自动变为 ERROR
```
