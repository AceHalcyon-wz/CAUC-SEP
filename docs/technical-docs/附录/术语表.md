## 1. 技术术语

### 1.1 系统架构

| 术语 | 英文 | 说明 |
|------|------|------|
| 前端 | Frontend | 用户界面层，基于Vue3构建的Web应用 |
| 后端 | Backend | 服务端应用，基于FastAPI构建的RESTful API服务 |
| 中间件 | Middleware | 处理请求/响应的中间层组件，如认证、日志、限流等 |
| WebSocket | WebSocket | 全双工通信协议，用于实时数据推送 |
| RESTful API | RESTful API | 符合REST架构风格的Web API接口 |
| ORM | Object-Relational Mapping | 对象关系映射，用于数据库操作 |

### 1.2 通信协议

| 术语 | 英文 | 说明 |
|------|------|------|
| Modbus RTU | Modbus Remote Terminal Unit | 串行通信协议，用于工业设备通信 |
| 主站 | Master | Modbus网络中发起通信的设备 |
| 从站 | Slave | Modbus网络中响应请求的设备 |
| 功能码 | Function Code | Modbus协议中定义操作类型的代码 |
| 寄存器 | Register | Modbus设备中存储数据的内存单元 |
| CRC校验 | Cyclic Redundancy Check | 循环冗余校验，用于数据完整性验证 |

### 1.3 数据处理

| 术语 | 英文 | 说明 |
|------|------|------|
| 采样率 | Sampling Rate | 数据采集频率，单位Hz |
| 缓冲区 | Buffer | 临时存储数据的内存区域 |
| 滤波器 | Filter | 信号处理组件，用于去除噪声 |
| 低通滤波 | Low-pass Filter | 允许低频信号通过，抑制高频噪声 |
| 高通滤波 | High-pass Filter | 允许高频信号通过，抑制低频噪声 |
| 带通滤波 | Band-pass Filter | 允许特定频率范围信号通过 |
| 信噪比 | SNR (Signal-to-Noise Ratio) | 信号功率与噪声功率的比值 |

### 1.4 控制系统

| 术语 | 英文 | 说明 |
|------|------|------|
| PID控制 | Proportional-Integral-Derivative | 比例-积分-微分控制器 |
| 闭环控制 | Closed-loop Control | 具有反馈回路的控制系统 |
| 开环控制 | Open-loop Control | 无反馈回路的控制系统 |
| 设定点 | Setpoint | 控制系统的目标值 |
| 反馈 | Feedback | 系统输出返回输入的过程 |
| 稳态误差 | Steady-state Error | 系统稳定后输出与目标的偏差 |

### 1.5 前端技术

| 术语 | 英文 | 说明 |
|------|------|------|
| 组合式函数 | Composable | Vue3 Composition API中的可复用逻辑单元 |
| 响应式 | Reactive | 数据变化自动触发视图更新的特性 |
| 虚拟DOM | Virtual DOM | JavaScript对象表示的DOM结构 |
| 单文件组件 | SFC (Single File Component) | 包含模板、脚本、样式的Vue组件文件 |
| 状态管理 | State Management | 应用状态的集中式管理 |
| 路由 | Router | 控制页面导航的机制 |

## 2. 设备术语

### 2.1 步进电机

| 术语 | 英文 | 说明 |
|------|------|------|
| 步进电机 | Stepper Motor | 将电脉冲转换为机械位移的电机 |
| 步距角 | Step Angle | 每个脉冲电机转动的角度 |
| 微步 | Microstep | 细分步距角的驱动技术 |
| 绝对定位 | Absolute Positioning | 移动到指定坐标位置 |
| 相对定位 | Relative Positioning | 相对当前位置移动指定距离 |
| JOG模式 | Jogging Mode | 点动模式，按住按钮持续移动 |
| 回零 | Homing | 返回机械原点的操作 |
| 使能 | Enable | 激活电机驱动器 |
| 软件限位 | Software Limit | 通过软件设置的运动范围限制 |
| 硬件限位 | Hardware Limit | 通过物理开关设置的运动范围限制 |

### 2.2 电磁铁

| 术语 | 英文 | 说明 |
|------|------|------|
| 电磁铁 | Electromagnet | 通电产生磁场的装置 |
| 磁场强度 | Magnetic Field Strength | 磁场的强弱程度，单位A/m |
| 磁通量 | Magnetic Flux | 穿过面积的磁力线总数，单位Wb |
| 恒流模式 | Constant Current Mode | 保持电流恒定的工作模式 |
| 扫描模式 | Scan Mode | 按设定波形变化电流的模式 |
| 正向扫描 | Forward Scan | 电流从低到高变化 |
| 反向扫描 | Reverse Scan | 电流从高到低变化 |
| 三角波扫描 | Triangle Scan | 电流先升后降的扫描方式 |
| 过流保护 | Overcurrent Protection | 电流超过阈值时的保护机制 |
| 校准 | Calibration | 建立电流与磁场关系的测量过程 |

### 2.3 温度控制器

| 术语 | 英文 | 说明 |
|------|------|------|
| 温度控制器 | Temperature Controller | 控制温度的设备 |
| 热电偶 | Thermocouple | 温度传感器，基于塞贝克效应 |
| RTD | Resistance Temperature Detector | 电阻温度检测器 |
| 加热器 | Heater | 提供热量的装置 |
| PID参数 | PID Parameters | 比例(P)、积分(I)、微分(D)系数 |
| 程序温控 | Programmed Temperature Control | 按预设曲线自动控制温度 |
| 升温速率 | Heating Rate | 温度上升的速度，单位K/min |
| 降温速率 | Cooling Rate | 温度下降的速度，单位K/min |
| 恒温段 | Soak Segment | 保持温度恒定的时间段 |
| 保护限值 | Protection Limit | 安全保护阈值 |

### 2.4 压电控制器

| 术语 | 英文 | 说明 |
|------|------|------|
| 压电控制器 | Piezo Controller | 控制压电陶瓷的设备 |
| 压电陶瓷 | Piezoelectric Ceramic | 电致伸缩材料 |
| 位移 | Displacement | 压电陶瓷的形变量，单位um |
| 行程 | Travel Range | 压电陶瓷的最大位移范围 |
| 开环模式 | Open-loop Mode | 无位置反馈的控制模式 |
| 闭环模式 | Closed-loop Mode | 有位置反馈的控制模式 |
| 线性校准 | Linear Calibration | 假设电压-位移为线性关系 |
| 多项式校准 | Polynomial Calibration | 使用多项式拟合电压-位移关系 |
| 分段校准 | Piecewise Calibration | 分段拟合电压-位移关系 |
| 迟滞 | Hysteresis | 压电陶瓷的磁滞现象 |

## 3. API术语

### 3.1 HTTP方法

| 方法 | 说明 | 使用场景 |
|------|------|----------|
| GET | 获取资源 | 查询数据 |
| POST | 创建资源 | 提交数据、执行操作 |
| PUT | 更新资源 | 完整更新 |
| PATCH | 部分更新 | 部分字段更新 |
| DELETE | 删除资源 | 删除数据 |

### 3.2 状态码

| 状态码 | 说明 | 常见原因 |
|--------|------|----------|
| 200 | 成功 | 请求处理成功 |
| 201 | 已创建 | 资源创建成功 |
| 204 | 无内容 | 成功但无返回内容 |
| 400 | 错误请求 | 参数格式错误 |
| 401 | 未授权 | 未登录或Token过期 |
| 403 | 禁止访问 | 权限不足 |
| 404 | 未找到 | 资源不存在 |
| 422 | 无法处理 | 数据验证失败 |
| 429 | 请求过多 | 触发限流 |
| 500 | 服务器错误 | 内部错误 |

### 3.3 请求头

| 头字段 | 说明 | 示例 |
|--------|------|------|
| Content-Type | 内容类型 | application/json |
| Authorization | 认证信息 | Bearer <token> |
| Accept | 接受类型 | application/json |
| X-Request-ID | 请求ID | uuid |

### 3.4 响应格式

| 字段 | 类型 | 说明 |
|------|------|------|
| code | integer | 业务状态码 |
| message | string | 响应消息 |
| data | object | 响应数据 |
| timestamp | string | 时间戳 |

### 3.5 WebSocket消息类型

| 类型 | 说明 | 方向 |
|------|------|------|
| status | 设备状态 | 服务端 -> 客户端 |
| data | 采集数据 | 服务端 -> 客户端 |
| command | 控制命令 | 客户端 -> 服务端 |
| error | 错误信息 | 服务端 -> 客户端 |
| heartbeat | 心跳 | 双向 |

## 5. 单位说明

### 5.1 长度单位

| 单位 | 名称 | 换算关系 | 使用场景 |
|------|------|----------|----------|
| mm | 毫米 | 1 mm = 10^-3 m | 电机位移、机械尺寸 |
| um | 微米 | 1 um = 10^-6 m | 压电位移、精度要求 |
| nm | 纳米 | 1 nm = 10^-9 m | 纳米级精度测量 |

### 5.2 时间单位

| 单位 | 名称 | 换算关系 | 使用场景 |
|------|------|----------|----------|
| s | 秒 | 基本单位 | 常规时间 |
| ms | 毫秒 | 1 ms = 10^-3 s | 响应时间、采样间隔 |
| us | 微秒 | 1 us = 10^-6 s | 高速采样 |
| min | 分钟 | 1 min = 60 s | 实验时长 |

### 5.3 电学单位

| 单位 | 名称 | 换算关系 | 使用场景 |
|------|------|----------|----------|
| A | 安培 | 基本单位 | 电磁铁电流 |
| mA | 毫安 | 1 mA = 10^-3 A | 小电流测量 |
| uA | 微安 | 1 uA = 10^-6 A | 微小电流 |
| pA | 皮安 | 1 pA = 10^-12 A | 极小电流测量 |
| V | 伏特 | 基本单位 | 压电电压 |
| mV | 毫伏 | 1 mV = 10^-3 V | 信号电压 |
| W | 瓦特 | 1 W = 1 V * A | 功率 |

### 5.4 温度单位

| 单位 | 名称 | 换算关系 | 使用场景 |
|------|------|----------|----------|
| K | 开尔文 | 绝对温度 | 科学计算 |
| C | 摄氏度 | C = K - 273.15 | 常规温度显示 |
| F | 华氏度 | F = C * 9/5 + 32 | 特定地区使用 |

### 5.5 磁学单位

| 单位 | 名称 | 换算关系 | 使用场景 |
|------|------|----------|----------|
| T | 特斯拉 | 基本单位 | 磁场强度 |
| mT | 毫特 | 1 mT = 10^-3 T | 弱磁场测量 |
| G | 高斯 | 1 G = 10^-4 T | 传统单位 |
| A/m | 安培每米 | SI单位 | 磁场强度 |
| Oe | 奥斯特 | 1 Oe = 79.577 A/m | 传统单位 |

### 5.6 频率单位

| 单位 | 名称 | 换算关系 | 使用场景 |
|------|------|----------|----------|
| Hz | 赫兹 | 基本单位 | 采样率、信号频率 |
| kHz | 千赫兹 | 1 kHz = 10^3 Hz | 高频信号 |
| MHz | 兆赫兹 | 1 MHz = 10^6 Hz | 射频信号 |
