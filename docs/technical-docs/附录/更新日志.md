## 升级指南

### 从 0.2.x 升级到 0.3.x

#### 1. 备份数据

```bash
# 备份数据库
cp data/cauc_sep.db data/cauc_sep.db.bak

# 备份配置文件
cp .env .env.bak
```

#### 2. 更新代码

```bash
# 拉取最新代码
git pull origin main

# 更新后端依赖
pip install -r requirements.txt

# 更新前端依赖
cd frontend
npm install
```

#### 3. 数据库迁移

```bash
# 运行数据库迁移脚本
python scripts/migrate_db.py
```

#### 4. 配置更新

更新 `.env` 文件，添加新的配置项：

```env
# JWT认证配置
JWT_SECRET_KEY=your-secret-key
JWT_ALGORITHM=HS256
JWT_EXPIRATION_HOURS=24

# 速率限制配置
RATE_LIMIT_REQUESTS=100
RATE_LIMIT_PERIOD=60

# Prometheus配置
PROMETHEUS_ENABLED=true
PROMETHEUS_PORT=9090
```

#### 5. 重启服务

```bash
# 重启后端服务
python -m uvicorn main:app --reload

# 重启前端服务
cd frontend
npm run dev
```

### API迁移说明

由于 0.3.0 版本引入了 API 版本前缀，需要更新客户端代码：

```javascript
// 旧版本 (0.2.x)
const response = await fetch('/api/motor/status');

// 新版本 (0.3.x)
const response = await fetch('/api/v1/motor/status');
```
