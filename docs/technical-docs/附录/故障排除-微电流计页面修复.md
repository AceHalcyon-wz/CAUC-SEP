# 微电流计页面空白问题修复说明

## 问题描述

访问 `http://localhost:5173/experiment/ammeter` 时页面显示空白，浏览器控制台报错：

```
TypeError: Cannot destructure property 'render' of 'undefined' as it is undefined.
    at Object.TabNavRenderer [as type]
```

## 根本原因

**Vue 3.5.13 与 Element Plus 2.9.7 之间的兼容性 Bug**

当在 `el-tab-pane` 组件内部使用 `AmmeterWaveform` 组件（基于 ECharts 的波形显示组件）时，会触发 Element Plus 内部 `TabNavRenderer` 的渲染错误，导致整个页面崩溃。

错误堆栈显示：
- 错误发生在 Element Plus 的 Tabs 组件渲染时
- 具体位置在 `TabNavRenderer` 尝试解构 `render` 属性时
- 该属性为 `undefined`，导致解构失败

## 解决方案

### 方案选择

根据 Element Plus 发布日志：
- **Element Plus 2.13.0** (2025-12-19): `Other: upgrade to Vue 3.5 (#22096)`
- Element Plus 在 2.13.0 版本才正式升级到 Vue 3.5

因此选择**升级 Element Plus 到最新版 2.13.5**，以支持与 Vue 3.5.13 的完整兼容性。

### 版本升级

**升级前版本组合**:
- Vue: 3.5.13
- Element Plus: 2.9.7 ❌ (不支持 Vue 3.5)

**升级后版本组合**:
- Vue: 3.5.13 ✅ (保持最新)
- Element Plus: 2.13.5 ✅ (完全支持 Vue 3.5)

### 执行步骤

1. **升级 Element Plus**:
```bash
cd frontend
npm install element-plus@2.13.5 --save
```

2. **修复 AmmeterWaveform 组件空值检查**:

在 `frontend/src/components/experiment/ammeter/AmmeterWaveform.vue` 中：

```vue
<!-- 修复前 -->
<span class="stat-number">{{ formatCurrent(channel.stats.max) }}</span>

<!-- 修复后 -->
<span class="stat-number">{{ formatCurrent(channel.stats?.max ?? 0) }}</span>
```

```javascript
// 修复前
yAxis: {
  min: (value) => value.min * 0.95,
  max: (value) => value.max * 1.05
}

// 修复后
yAxis: {
  min: (value) => value?.min ? value.min * 0.95 : 0,
  max: (value) => value?.max ? value.max * 1.05 : 1
}
```

3. **恢复被注释的 Tab 页**:

在 `frontend/src/components/experiment/ammeter/AmmeterControl.vue` 中，取消注释"数据图表"Tab 页：

```vue
<!-- 数据可视化面板 -->
<el-tab-pane
  label="数据图表"
  name="chart"
>
  <div class="chart-panel">
    <AmmeterWaveform
      :data="realtimeData"
      :channel-config="channelConfigs"
      :channel-count="channelCount"
      :auto-update="autoUpdate"
      :update-interval="200"
      @zoom-change="handleZoomChange"
      @channel-toggle="handleChannelToggle"
      @display-mode-change="handleDisplayModeChange"
    />
  </div>
</el-tab-pane>
```

4. **重启前端服务**:
```bash
# 停止旧服务
Stop-Process -Id <进程 ID> -Force

# 启动新服务
npm run dev
```
