## 1. 设备概览

CAUC-SEP 平台支持多种实验设备的统一控制和管理，涵盖运动控制、磁场控制、温度控制、精密位移和微电流测量等领域。

### 1.1 设备总览表

| 序号 | 设备类型 | 型号/规格 | 通信协议 | 主要功能 | 驱动状态 |
|------|---------|----------|----------|----------|----------|
| 1 | 步进电机驱动器 | 雷赛 DM2C-RS556 | Modbus RTU | 精密位置控制、PR路径编程 | 已完成 |
| 2 | 电磁铁 | 可编程电流源 | Serial | 磁场扫描、校准管理 | 已完成 |
| 3 | 温度控制器 | PID温控系统 | Serial | 程序控温、保护限值 | 已完成 |
| 4 | 压电控制器 | 电压/位移控制 | Serial | 开闭环模式、校准 | 已完成 |
| 5 | 皮安装培计 | 微电流测量 | Serial | 多通道采集、SNR分析 | 已完成 |

## 2. 步进电机驱动器

### 2.1 设备信息

| 属性 | 值 |
|------|-----|
| **设备名称** | 雷赛 DM2C-RS556 驱控一体型步进驱动器 |
| **制造商** | 雷赛智能 (Leadshine) |
| **通信协议** | Modbus RTU |
| **物理接口** | RS-485 |
| **驱动文件** | [dm2c_driver.py](../../../backend/core/dm2c_driver.py) |

### 2.2 技术规格

| 参数 | 规格 |
|------|------|
| 供电电压 | 24-48 VDC |
| 输出电流 | 0.1-5.6 A (峰值) |
| 细分范围 | 2-256 |
| 通信接口 | RS-485 (Modbus RTU) |
| 控制模式 | PR (位置) 模式 |
| 位置表 | 16段可编程 |

### 2.3 支持功能

#### 2.3.1 运动控制功能

| 功能 | 说明 | API 端点 |
|------|------|----------|
| 绝对定位 | 移动到指定绝对位置 | `POST /api/v1/motor/move` |
| 相对定位 | 相对当前位置移动 | `POST /api/v1/motor/move_relative` |
| JOG 点动 | 持续运动控制 | `POST /api/v1/motor/jog` |
| 回零操作 | 执行回零/归零 | `POST /api/v1/motor/home` |
| 急停 | 立即停止运动 | `POST /api/v1/motor/emergency_stop` |

#### 2.3.2 PR 路径编程

| 功能 | 说明 | API 端点 |
|------|------|----------|
| 配置路径 | 设置 PR 路径参数 | `POST /api/v1/motor/pr/config` |
| 触发路径 | 执行预设路径 | `POST /api/v1/motor/pr/trigger` |
| 查询路径 | 获取路径配置 | `GET /api/v1/motor/pr/{path_id}` |

#### 2.3.3 IO 端口配置

| 功能 | 说明 | API 端点 |
|------|------|----------|
| DI 配置 | 配置数字输入端口 | `POST /api/v1/device/{id}/io/di/configure` |
| DO 配置 | 配置数字输出端口 | `POST /api/v1/device/{id}/io/do/configure` |
| IO 状态 | 读取端口状态 | `GET /api/v1/device/{id}/io/di/status` |

#### 2.3.4 安全功能

| 功能 | 说明 | API 端点 |
|------|------|----------|
| 软件限位 | 设置位置限位 | `POST /api/v1/motor/limits` |
| 报警复位 | 清除报警状态 | `POST /api/v1/motor/reset_alarm` |
| 参数保存 | 保存到 EEPROM | `POST /api/v1/motor/save_params` |
| 恢复出厂 | 重置为默认设置 | `POST /api/v1/motor/factory_reset` |

### 2.4 Modbus 寄存器映射

| 寄存器地址 | 功能 | 读/写 | 数据类型 |
|-----------|------|-------|----------|
| 0x0000 | 目标位置 | R/W | INT32 |
| 0x0002 | 运行速度 | R/W | UINT32 |
| 0x0004 | 当前位置 | R | INT32 |
| 0x0006 | 状态字 | R | UINT16 |
| 0x0007 | 报警代码 | R | UINT16 |
| 0x0010 | 加速时间 | R/W | UINT16 |
| 0x0011 | 减速时间 | R/W | UINT16 |

### 2.5 回零模式

| 模式编号 | 模式名称 | 说明 |
|---------|---------|------|
| 1 | 单次正向限位回零 | 正向限位触发后回零 |
| 2 | 单次负向限位回零 | 负向限位触发后回零 |
| 3 | 单次正向限位反向回零 | 正向限位触发后反向回零 |
| 4 | 单次负向限位反向回零 | 负向限位触发后反向回零 |
| 5 | 正向限位回零 | 持续正向限位回零 |
| 6 | 负向限位回零 | 持续负向限位回零 |
| 7 | 正向限位反向回零 | 正向限位反向回零 |
| 8 | 负向限位反向回零 | 负向限位反向回零 |
| 17 | 单次Z脉冲回零 | Z脉冲触发回零 |
| 18 | 单次Z脉冲反向回零 | Z脉冲反向回零 |
| 33 | 单次正向限位Z脉冲回零 | 正向限位+Z脉冲回零 |

## 3. 电磁铁控制系统

### 3.1 设备信息

| 属性 | 值 |
|------|-----|
| **设备名称** | 可编程电磁铁电流源 |
| **通信协议** | Serial (自定义协议) |
| **物理接口** | RS-232 / RS-485 |
| **驱动文件** | [electromagnet_driver.py](../../../backend/core/electromagnet_driver.py) |

### 3.2 技术规格

| 参数 | 规格 |
|------|------|
| 输出电流范围 | 0-10 A (可配置) |
| 电流分辨率 | 1 mA |
| 磁场范围 | 取决于电磁铁规格 |
| 稳定性 | < 0.1% / 小时 |

### 3.3 支持功能

| 功能 | 说明 | API 端点 |
|------|------|----------|
| 恒流模式 | 设置恒定电流 | `POST /api/electromagnet/current` |
| 正向扫描 | 电流正向扫描 | `POST /api/electromagnet/scan` |
| 反向扫描 | 电流反向扫描 | `POST /api/electromagnet/scan` |
| 三角波扫描 | 双向扫描 | `POST /api/electromagnet/scan` |
| 校准管理 | 电流-磁场校准 | `POST /api/electromagnet/calibrate` |
| 急停 | 立即停止输出 | `POST /api/electromagnet/emergency_stop` |

### 3.4 扫描参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 起始电流 | 扫描起始点 | 0 A |
| 终止电流 | 扫描终点 | 5 A |
| 步长 | 电流步进值 | 0.1 A |
| 停留时间 | 每步停留时间 | 100 ms |

## 4. 温度控制器

### 4.1 设备信息

| 属性 | 值 |
|------|-----|
| **设备名称** | PID 温度控制器 |
| **通信协议** | Serial (自定义协议) |
| **物理接口** | RS-232 / RS-485 |
| **驱动文件** | [temperature_controller.py](../../../backend/core/temperature_controller.py) |

### 4.2 技术规格

| 参数 | 规格 |
|------|------|
| 温度范围 | -196°C ~ +400°C (取决于传感器) |
| 温度分辨率 | 0.1°C |
| 控制精度 | ±0.5°C |
| 采样周期 | 100 ms |

### 4.3 支持功能

| 功能 | 说明 | API 端点 |
|------|------|----------|
| PID 控制 | 设置目标温度 | `POST /api/temperature/setpoint` |
| PID 参数 | 配置 Kp/Ki/Kd | `POST /api/temperature/pid` |
| 自动调谐 | 自动优化 PID 参数 | `POST /api/temperature/autotune` |
| 程序控温 | 多段温度程序 | `POST /api/temperature/program` |
| 保护设置 | 温度限值保护 | `POST /api/temperature/protection` |
| 历史数据 | 温度历史记录 | `GET /api/temperature/history` |

### 4.4 程序控温参数

| 参数 | 说明 | 单位 |
|------|------|------|
| 目标温度 | 该段目标温度 | °C |
| 升温速率 | 升温速度 | °C/min |
| 降温速率 | 降温速度 | °C/min |
| 保持时间 | 恒温保持时间 | min |

### 4.5 保护功能

| 保护类型 | 说明 |
|---------|------|
| 最高温度限值 | 超过限值自动停止加热 |
| 最低温度限值 | 超过限值自动报警 |
| 最大升温速率 | 防止温度冲击 |
| 最大降温速率 | 防止温度冲击 |
| 传感器断线检测 | 传感器故障保护 |

## 7. 设备集成架构

### 7.1 设备抽象层

平台采用统一的设备抽象层，实现对不同设备的统一管理：

```
┌─────────────────────────────────────────────────────────────────┐
│                      设备抽象层架构                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    API 层                                │   │
│  │  motor.py | electromagnet.py | temperature.py | ...    │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                 设备管理器 (DeviceManager)               │   │
│  │  - 设备注册与发现                                        │   │
│  │  - 连接状态管理                                          │   │
│  │  - 统一错误处理                                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                 设备抽象基类 (BaseDevice)                │   │
│  │  connect() | disconnect() | get_status() | ...         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│        ┌─────────────────────┼─────────────────────┐           │
│        ▼                     ▼                     ▼           │
│  ┌───────────┐         ┌───────────┐         ┌───────────┐    │
│  │ DM2C      │         │Electromagnet│        │Temperature│    │
│  │ Driver    │         │ Driver     │         │ Driver    │    │
│  └───────────┘         └───────────┘         └───────────┘    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 7.2 设备注册表

| 设备类型 | 设备ID | 驱动类 | 状态 |
|---------|--------|--------|------|
| stepper | dm2c_rs556 | DM2CDriver | 已注册 |
| electromagnet | electromagnet_001 | ElectromagnetDriver | 已注册 |
| temperature | temp_controller_001 | TemperatureController | 已注册 |
| piezo | piezo_001 | PiezoController | 已注册 |
| ammeter | picoammeter_001 | Picoammeter | 已注册 |

### 7.3 实时数据推送

所有设备支持通过 WebSocket 进行实时数据推送：

| 设备 | WebSocket 端点 | 推送内容 | 默认频率 |
|------|---------------|----------|----------|
| 步进电机 | `/ws/motor` | 位置、速度、状态 | 10 Hz |
| 电磁铁 | `/ws/electromagnet` | 电流、磁场、状态 | 5 Hz |
| 温度控制器 | `/ws/temperature` | 温度、设定值、状态 | 1 Hz |
| 压电控制器 | `/ws/piezo` | 电压、位移、状态 | 10 Hz |
| 皮安表 | `/ws/ammeter` | 电流数据、SNR | 可配置 |
