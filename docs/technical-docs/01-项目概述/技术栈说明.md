#### FastAPI 核心特性

```python
# 示例：FastAPI 路由定义
from fastapi import APIRouter, Depends
from pydantic import BaseModel

class MotorMoveRequest(BaseModel):
    """电机移动请求模型。"""
    position: int
    speed: int = 1000

@router.post("/motor/move")
async def move_motor(
    request: MotorMoveRequest,
    motor: MotorDriver = Depends(get_motor_driver)
) -> dict:
    """
    执行电机绝对定位。
    
    Args:
        request: 移动请求参数
        motor: 电机驱动实例（依赖注入）
    
    Returns:
        操作结果
    """
    await motor.move_to(request.position, request.speed)
    return {"status": "success", "position": request.position}
```

#### Vue 3 Composition API 示例

```typescript
// 示例：组合式函数
import { ref, computed, onMounted } from 'vue';
import { useMotorStore } from '@/stores/motor';

/**
 * 电机控制组合式函数。
 */
export function useMotorControl(deviceId: string) {
    const store = useMotorStore();
    const isLoading = ref(false);
    
    // 计算属性：当前位置
    const currentPosition = computed(() => {
        return store.devices[deviceId]?.position ?? 0;
    });
    
    // 方法：移动到目标位置
    async function moveTo(position: number, speed: number): Promise<void> {
        isLoading.value = true;
        try {
            await store.moveMotor(deviceId, { position, speed });
        } finally {
            isLoading.value = false;
        }
    }
    
    return {
        currentPosition,
        isLoading,
        moveTo
    };
}
```

## 5. 通信协议

### 5.1 协议概览

```
┌─────────────────────────────────────────────────────────────────┐
│                       通信协议架构                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────┐     REST API      ┌─────────────┐            │
│  │   前端      │ ◄───────────────► │   后端      │            │
│  │  Vue 3      │                   │  FastAPI    │            │
│  └─────────────┘                   └─────────────┘            │
│        │                                  │                    │
│        │ WebSocket                        │ Modbus RTU         │
│        │ (实时数据)                       │ (硬件通信)          │
│        ▼                                  ▼                    │
│  ┌─────────────┐                   ┌─────────────┐            │
│  │  数据推送   │                   │  硬件设备   │            │
│  │ MessagePack │                   │ RS-485      │            │
│  └─────────────┘                   └─────────────┘            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 协议详细说明

| 协议 | 用途 | 传输层 | 数据格式 | 特点 |
|------|------|--------|----------|------|
| **Modbus RTU** | 硬件设备通信 | RS-485 串口 | 二进制 | 工业标准、可靠稳定 |
| **WebSocket** | 实时数据推送 | TCP | JSON/MessagePack | 双向通信、低延迟 |
| **REST API** | 前后端通信 | HTTP | JSON | 无状态、易缓存 |
| **MessagePack** | 二进制序列化 | - | 二进制 | 高效、体积小 |

### 5.3 Modbus RTU 配置

| 参数 | 默认值 | 说明 |
|------|-------|------|
| 波特率 | 9600 | 数据传输速率 |
| 数据位 | 8 | 每帧数据位数 |
| 停止位 | 1 | 帧结束标志 |
| 校验位 | 无 (N) | 奇偶校验 |
| 从站地址 | 1 | 设备地址 |

### 5.4 WebSocket 端点

| 端点 | 说明 | 推送频率 |
|------|------|----------|
| `/ws/motor` | 电机实时数据 | 10 Hz |
| `/ws/electromagnet` | 电磁铁实时数据 | 5 Hz |
| `/ws/temperature` | 温度实时数据 | 1 Hz |
| `/ws/piezo` | 压电实时数据 | 10 Hz |
| `/ws/ammeter` | 皮安表实时数据 | 可配置 |
| `/ws/devices` | 所有设备状态 | 1 Hz |

## 6. 技术选型理由

### 6.1 后端技术选型

| 技术 | 选型理由 |
|------|----------|
| **FastAPI** | 高性能异步框架，自动生成 API 文档，类型提示支持完善 |
| **PyModbus** | 成熟的 Modbus 实现，支持 RTU/TCP，社区活跃 |
| **NumPy/SciPy** | 科学计算标准库，算法丰富，性能优异 |

| **h5py** | 科学数据标准格式，支持大数据存储和快速读取 |

### 6.2 前端技术选型

| 技术 | 选型理由 |
|------|----------|
| **Vue 3** | Composition API 提供更好的代码组织，性能优于 Vue 2 |
| **TypeScript** | 类型安全，IDE 支持完善，减少运行时错误，提升代码质量 |

### 6.3 通信协议选型

| 协议 | 选型理由 |
|------|----------|
| **Modbus RTU** | 工业标准协议，DM2C 驱动器原生支持，稳定可靠 |

| **REST API** | 标准化接口设计，易于调试和扩展 |
