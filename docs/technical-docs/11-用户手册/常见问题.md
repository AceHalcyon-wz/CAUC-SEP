## 1. 登录问题

### 1.1 无法打开登录页面

#### 问题现象

- 双击程序图标后浏览器未打开
- 浏览器打开但显示"无法访问此网站"
- 页面一直显示加载中

#### 可能原因

| 原因 | 检查方法 |
|------|----------|
| 后端服务未启动 | 查看任务管理器中是否有后端进程 |
| 端口被占用 | 检查 8000 端口是否被其他程序占用 |
| 防火墙拦截 | 检查防火墙设置 |
| 浏览器问题 | 尝试使用其他浏览器 |

#### 解决方法

**方法一：等待后端启动**

1. 双击程序后等待 5-10 秒
2. 后端服务启动需要时间
3. 如果仍未打开，尝试手动打开浏览器
4. 访问地址: `http://localhost:8000`

**方法二：检查端口占用**

1. 打开命令提示符（CMD）
2. 输入命令: `netstat -ano | findstr :8000`
3. 如果显示其他程序占用，关闭该程序
4. 重启系统

**方法三：使用快速登录**

如果后端服务异常，可使用快速登录模式：

1. 登录页面会自动检测后端状态
2. 如果后端不可用，系统提示使用快速登录
3. 点击账号卡片即可登录
4. 快速登录不依赖后端服务

---

### 1.2 登录失败

#### 问题现象

- 点击登录按钮无反应
- 提示"用户名或密码错误"
- 提示"后端服务不可用"

#### 解决方法

**账号密码错误**:

1. 确认用户名和密码输入正确
2. 注意区分大小写
3. 默认账号密码:
   - 管理员: admin / admin123
   - 实验员: user / 123456

**后端服务不可用**:

1. 使用快速登录模式
2. 快速登录无需后端验证
3. 点击账号卡片直接登录

**浏览器缓存问题**:

1. 按 `Ctrl + Shift + Delete` 清除缓存
2. 或使用无痕模式打开
3. 重新尝试登录

---

### 1.3 登录后立即退出

#### 问题现象

- 登录成功后立即返回登录页面
- 页面显示"登录已过期"
- 无法进入系统主界面

#### 可能原因

1. 浏览器禁用了 localStorage
2. 令牌验证失败
3. 系统时间不正确

#### 解决方法

**检查浏览器设置**:

1. 确保浏览器未禁用 Cookie 和 localStorage
2. Chrome: 设置 → 隐私和安全 → Cookie
3. 允许网站保存和读取 Cookie 数据

**检查系统时间**:

1. 确保系统时间正确
2. 令牌验证依赖时间戳
3. 时间偏差过大会导致验证失败

**清除登录状态**:

1. 按 `F12` 打开开发者工具
2. 切换到"Application"标签
3. 清除 localStorage
4. 重新登录

---

### 1.4 访客模式无法使用

#### 问题现象

- 访客模式选项不可点击
- 提示"访客模式已禁用"
- 点击后无反应

#### 解决方法

1. 访客模式可能被管理员禁用
2. 联系系统管理员启用访客模式
3. 或使用其他账号登录

## 2. 设备连接问题

### 2.1 设备无法连接

#### 问题现象

- 点击"连接"按钮后提示连接失败
- 状态一直显示"未连接"
- 设备列表中找不到设备

#### 可能原因

| 原因 | 检查方法 |
|------|----------|
| 设备未上电 | 检查设备电源指示灯 |
| 串口线未连接 | 检查串口线两端连接 |
| 串口号错误 | 在设备管理器中确认串口号 |
| 串口被占用 | 关闭其他可能占用串口的程序 |
| 驱动未安装 | 检查 USB-RS485 驱动 |

#### 解决方法

**步骤一：检查硬件连接**

1. 确认设备已上电，指示灯亮起
2. 检查串口线两端是否插紧
3. 尝试重新插拔串口线

**步骤二：确认串口号**

1. 右键"此电脑" → 管理 → 设备管理器
2. 展开"端口 (COM 和 LPT)"
3. 查看 USB-RS485 转换器的串口号
4. 如显示"USB-SERIAL CH340 (COM3)"，则串口号为 COM3

**步骤三：配置正确串口号**

1. 进入系统设置页面
2. 找到设备配置选项
3. 选择正确的串口号
4. 保存设置后重新连接

**步骤四：关闭占用程序**

可能占用串口的程序：
- 其他串口调试工具
- 旧版本的系统程序
- Arduino IDE 等开发工具

关闭这些程序后重试。

---

### 2.2 设备连接后无响应

#### 问题现象

- 连接显示成功但设备无响应
- 发送命令后无返回
- 数据一直显示为 0 或固定值

#### 可能原因

| 原因 | 说明 |
|------|------|
| 波特率错误 | 通信波特率不匹配 |
| 设备地址错误 | Modbus 地址配置错误 |
| 通信协议不匹配 | 设备协议与系统不兼容 |
| 线路故障 | 通信线缆损坏或接触不良 |

#### 解决方法

**检查波特率**:

1. 查看设备说明书确认波特率
2. 常见波特率: 9600, 19200, 38400, 115200
3. 在系统设置中配置正确波特率
4. 默认波特率: 115200

**检查设备地址**:

1. 查看设备上的地址拨码或设置
2. 在系统设置中配置正确地址
3. 默认地址: 1

**检查通信线**:

1. 确认 A/B 线连接正确
2. 尝试更换通信线
3. 检查是否有断路或短路

---

### 2.3 设备频繁断开

#### 问题现象

- 设备连接后不久自动断开
- 操作过程中突然断开连接
- 断开后需要重新连接

#### 可能原因

1. USB 供电不足
2. USB 线缆质量问题
3. 电脑 USB 接口故障
4. 设备固件问题

#### 解决方法

**改善供电**:

1. 使用带外部供电的 USB Hub
2. 避免使用 USB 延长线
3. 直接连接电脑主板 USB 接口

**更换线缆**:

1. 使用质量好的 USB 线缆
2. 避免使用过长线缆（建议 < 2米）
3. 尝试屏蔽线缆减少干扰

**检查 USB 接口**:

1. 尝试其他 USB 接口
2. 避免使用前置 USB 接口
3. 检查设备管理器中是否有异常

---

### 2.4 多设备连接冲突

#### 问题现象

- 连接一个设备后另一个断开
- 设备之间互相干扰
- 无法同时连接多个设备

#### 解决方法

1. 确保每个设备使用不同串口
2. 检查串口号配置是否重复
3. 避免使用 USB Hub 连接多个设备
4. 分别连接设备，确认每个都能正常工作

## 3. 数据采集问题

### 3.1 数据采集无数据

#### 问题现象

- 点击开始采集后无数据显示
- 数据值一直为 0
- 波形图无变化

#### 可能原因

| 原因 | 检查方法 |
|------|----------|
| 传感器未连接 | 检查传感器连接 |
| 量程设置过大 | 数据太小显示为 0 |
| 信号线断路 | 检查信号线连接 |
| 设备未正确配置 | 检查设备参数设置 |

#### 解决方法

**检查传感器**:

1. 确认传感器已正确连接
2. 检查传感器供电是否正常
3. 尝试已知正常的传感器

**调整量程**:

1. 如果信号很小，降低量程
2. 例如: 信号约 1nA，选择 10nA 量程
3. 避免量程过大导致分辨率不足

**检查信号线**:

1. 确认信号线连接正确
2. 检查是否有断路或接触不良
3. 尝试更换信号线

---

### 3.2 数据采集噪声大

#### 问题现象

- 数据波动剧烈
- 波形图显示杂乱
- 无法读取稳定值

#### 可能原因

1. 电磁干扰
2. 接地不良
3. 信号线屏蔽不好
4. 采样频率过高

#### 解决方法

**减少干扰**:

1. 远离强电磁干扰源
2. 使用屏蔽信号线
3. 确保良好接地
4. 信号线与电源线分开走线

**调整采样参数**:

1. 降低采样频率
2. 启用低通滤波
3. 增加平均次数

**使用滤波功能**:

1. 在采集设置中启用滤波
2. 选择合适的滤波参数
3. 平衡响应速度和噪声抑制

---

### 3.3 数据采集中断

#### 问题现象

- 采集过程中突然停止
- 提示"采集失败"
- 数据丢失

#### 可能原因

1. 设备连接断开
2. 缓冲区溢出
3. 系统资源不足
4. 程序异常

#### 解决方法

**检查设备连接**:

1. 确认设备连接稳定
2. 参考"设备频繁断开"解决方案

**优化系统资源**:

1. 关闭不必要的程序
2. 降低采样频率
3. 减少同时运行的设备数量

**调整缓冲区**:

1. 在设置中增加缓冲区大小
2. 或降低采样频率减少数据量

---

### 3.4 数据保存失败

#### 问题现象

- 点击保存后提示失败
- 文件未生成
- 文件损坏无法打开

#### 可能原因

1. 磁盘空间不足
2. 文件路径权限问题
3. 文件名包含非法字符
4. 数据格式错误

#### 解决方法

**检查磁盘空间**:

1. 确认磁盘有足够空间
2. 清理不需要的文件
3. 更换保存位置

**检查文件路径**:

1. 避免使用特殊字符命名
2. 确认有写入权限
3. 尝试保存到其他位置

**更换保存格式**:

1. 尝试其他导出格式
2. JSON 或 CSV 格式互换
3. 检查数据是否完整

## 4. 系统故障问题

### 4.1 系统响应缓慢

#### 问题现象

- 界面操作卡顿
- 按钮响应延迟
- 数据加载缓慢

#### 可能原因

| 原因 | 说明 |
|------|------|
| CPU 使用率高 | 后台程序占用过多资源 |
| 内存不足 | 可用内存过低 |
| 磁盘读写慢 | 磁盘性能问题 |
| 数据量过大 | 历史数据过多 |

#### 解决方法

**查看系统状态**:

1. 查看状态栏的系统资源使用率
2. 正常范围: CPU < 70%, 内存 < 70%
3. 如果超过警告阈值，需要优化

**关闭后台程序**:

1. 打开任务管理器
2. 关闭不必要的后台程序
3. 释放系统资源

**清理历史数据**:

1. 导出重要的历史数据
2. 删除不需要的历史记录
3. 定期清理保持系统轻量

**重启系统**:

1. 保存当前工作
2. 重启应用程序
3. 释放累积的资源占用

---

### 4.2 界面显示异常

#### 问题现象

- 界面元素错位
- 文字显示不全
- 图表显示异常

#### 可能原因

1. 浏览器缩放比例不正确
2. 浏览器兼容性问题
3. 缓存问题
4. 分辨率不匹配

#### 解决方法

**调整缩放比例**:

1. 按 `Ctrl + 0` 重置缩放
2. 或设置缩放为 100%
3. 确保界面正常显示

**清除缓存**:

1. 按 `Ctrl + Shift + Delete`
2. 清除浏览器缓存
3. 刷新页面（F5）

**更换浏览器**:

推荐使用以下浏览器：
- Google Chrome（推荐）
- Microsoft Edge
- Firefox

---

### 4.3 数据分析失败

#### 问题现象

- 拟合计算失败
- 提示"数据格式错误"
- 结果显示异常

#### 可能原因

1. 数据质量差
2. 数据格式不正确
3. 模型参数设置不当
4. 计算资源不足

#### 解决方法

**检查数据质量**:

1. 确保数据完整无缺失
2. 移除异常数据点
3. 确保数据覆盖完整范围

**验证数据格式**:

1. 确认数据列正确对应
2. 检查数据单位是否正确
3. 确保无非法字符

**调整拟合参数**:

1. 尝试不同的初始参数
2. 选择更适合的模型
3. 使用多模型对比

---

### 4.4 报告生成失败

#### 问题现象

- 点击生成报告无反应
- 提示"生成失败"
- 报告内容不完整

#### 解决方法

**检查数据完整性**:

1. 确保已完成数据分析
2. 数据拟合结果正常
3. 无缺失的必要参数

**检查系统资源**:

1. 确保有足够内存
2. 关闭其他程序
3. 重试生成报告

**检查存储空间**:

1. 确认磁盘空间充足
2. 清理临时文件
3. 更换保存位置

---

### 4.5 系统崩溃

#### 问题现象

- 程序无响应
- 界面卡死
- 自动关闭

#### 解决方法

**强制关闭**:

1. 按 `Ctrl + Alt + Delete`
2. 打开任务管理器
3. 结束相关进程

**重启系统**:

1. 重新启动应用程序
2. 检查是否恢复正常

**检查日志**:

1. 查看系统日志文件
2. 位置: `%APPDATA%\cauc-sep\logs\`
3. 找到错误信息

**联系技术支持**:

如果问题持续存在：
1. 记录错误现象和操作步骤
2. 保存日志文件
3. 联系技术支持团队

## 5. 错误代码参考

| E1003 | 设备通信超时 | 检查通信线路 |

| E1005 | 设备忙 | 等待设备空闲 |

## 6. 预防措施

### 6.1 日常维护

1. **定期检查设备**
   - 检查设备连接状态
   - 清洁设备接口
   - 检查线缆是否损坏

2. **定期清理数据**
   - 导出重要数据
   - 删除过期历史记录
   - 清理临时文件

3. **定期重启系统**
   - 每周重启一次系统
   - 释放累积资源
   - 保持系统稳定

### 6.2 安全操作

1. **遵守操作规程**
   - 按照手册操作
   - 不超范围使用
   - 注意安全警告

2. **做好数据备份**
   - 定期导出数据
   - 多处备份重要数据
   - 记录实验信息

3. **及时更新系统**
   - 关注系统更新
   - 及时安装补丁
   - 阅读更新说明

### 6.3 故障记录

遇到问题时记录以下信息：

1. 问题发生时间
2. 操作步骤
3. 错误提示信息
4. 错误代码
5. 已尝试的解决方法

这些信息有助于快速定位和解决问题。
