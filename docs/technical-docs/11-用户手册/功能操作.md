## 1. 设备控制操作

### 1.1 步进电机控制

#### 功能说明

步进电机用于控制样品台的精确移动，可实现毫米级定位精度。

#### 操作界面

```
┌─────────────────────────────────────────┐
│  步进电机控制                            │
├─────────────────────────────────────────┤
│  当前位置:  125.50 mm                    │
│  状态:      已连接 ●                     │
├─────────────────────────────────────────┤
│  目标位置:  [________] mm                │
│  移动速度:  [========●===] 50 mm/s       │
├─────────────────────────────────────────┤
│  [← 后退]  [归零]  [前进 →]             │
│  [连接]    [断开]  [紧急停止]            │
└─────────────────────────────────────────┘
```

#### 操作步骤

**连接设备**:

1. 确认步进电机已上电
2. 点击"连接"按钮
3. 等待状态显示"已连接"（绿色指示灯）

**移动操作**:

| 操作方式 | 说明 | 使用场景 |
|----------|------|----------|
| 输入目标位置 | 直接输入目标位置数值 | 精确定位 |
| 前进/后退按钮 | 按固定步长移动 | 粗调位置 |
| 归零按钮 | 移动到零点位置 | 初始化或校准 |

**参数设置**:

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 目标位置 | 0-300 mm | 0 | 样品台位置 |
| 移动速度 | 1-100 mm/s | 50 mm/s | 移动速度 |
| 加速度 | 10-500 mm/s² | 100 mm/s² | 启停加速度 |

**安全限位**:

- 最小位置: 0 mm
- 最大位置: 300 mm
- 超出限位时系统会自动停止并报警

### 1.2 电磁铁控制

#### 功能说明

电磁铁用于产生可控磁场，支持磁场扫描和定点磁场输出。

#### 操作界面

```
┌─────────────────────────────────────────┐
│  电磁铁控制                              │
├─────────────────────────────────────────┤
│  当前电流:  2.50 A                       │
│  当前磁场:  125.3 mT                     │
│  状态:      已连接 ●                     │
├─────────────────────────────────────────┤
│  目标电流:  [________] A                 │
│  扫描范围:  [-5.00] ~ [+5.00] A          │
│  扫描步长:  [________] A                 │
├─────────────────────────────────────────┤
│  [设置电流]  [开始扫描]  [停止]          │
│  [连接]      [断开]      [归零]          │
└─────────────────────────────────────────┘
```

#### 操作步骤

**设置固定电流**:

1. 输入目标电流值（范围: -5A ~ +5A）
2. 点击"设置电流"按钮
3. 观察电流和磁场实时变化
4. 等待稳定后进行测量

**执行磁场扫描**:

1. 设置扫描范围（起始电流和终止电流）
2. 设置扫描步长（建议 0.1A）
3. 点击"开始扫描"
4. 系统自动记录每个点的数据
5. 扫描完成后自动停止

**参数设置**:

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 目标电流 | -5 ~ +5 A | 0 A | 输出电流 |
| 扫描范围 | -5 ~ +5 A | -5 ~ +5 A | 磁场扫描范围 |
| 扫描步长 | 0.01 ~ 1 A | 0.1 A | 电流变化步长 |
| 稳定时间 | 0.1 ~ 10 s | 1 s | 每点稳定时间 |

**注意事项**:

- 电流变化时会产生热量，注意散热
- 长时间使用建议间歇运行
- 超过最大电流会自动保护

### 1.3 温度控制

#### 功能说明

温度控制器用于精确控制样品温度，支持升降温控制和恒温保持。

#### 操作界面

```
┌─────────────────────────────────────────┐
│  温度控制                                │
├─────────────────────────────────────────┤
│  当前温度:  25.3 °C                      │
│  目标温度:  100.0 °C                     │
│  状态:      加热中 ▲                     │
├─────────────────────────────────────────┤
│  目标温度:  [________] °C                │
│  升温速率:  [========●===] 5 °C/min      │
├─────────────────────────────────────────┤
│  [开始加热]  [停止]  [恒温保持]          │
│  [连接]      [断开]  [降温]              │
└─────────────────────────────────────────┘
```

#### 操作步骤

**设置目标温度**:

1. 输入目标温度值（范围: 室温 ~ 400°C）
2. 设置升温速率
3. 点击"开始加热"
4. 观察温度实时变化曲线

**恒温保持**:

1. 达到目标温度后
2. 点击"恒温保持"
3. 系统自动维持温度稳定
4. 可设置保持时长

**降温操作**:

1. 点击"停止"停止加热
2. 点击"降温"启动主动降温
3. 或等待自然冷却

**参数设置**:

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 目标温度 | 室温 ~ 400°C | 25°C | 目标温度 |
| 升温速率 | 0.1 ~ 20 °C/min | 5 °C/min | 升温速度 |
| 恒温时长 | 1 ~ 1440 min | 60 min | 恒温保持时间 |
| 温度容差 | 0.1 ~ 5 °C | 0.5 °C | 允许的温度波动 |

**安全提示**:

- 高温操作时注意防护
- 超过 300°C 需要特殊保护气体
- 温度异常时系统会自动报警

#### 功能说明

压电陶瓷用于实现纳米级精度的微小位移控制。

#### 操作界面

├─────────────────────────────────────────┤

- 选择合适量程避免过载

- 注意屏蔽外界干扰

## 2. 实验流程操作

### 2.1 磁滞回线测量实验

#### 实验目的

测量磁性材料的磁滞回线，获取矫顽力、剩磁、饱和磁矩等参数。

#### 实验准备

1. **设备检查**
   - 电磁铁已连接并正常工作
   - 皮安表已连接并校准
   - 样品已正确安装在样品台上

2. **参数预设**
   - 磁场扫描范围: -5A ~ +5A
   - 扫描步长: 0.1A
   - 每点稳定时间: 1秒

#### 操作步骤

**步骤一：设备初始化**

1. 连接电磁铁，点击"归零"使电流归零
2. 连接皮安表，选择合适量程
3. 确认样品位置正确

**步骤二：设置扫描参数**

1. 在电磁铁控制面板设置扫描范围
   - 起始电流: -5A
   - 终止电流: +5A
   - 扫描步长: 0.1A

2. 设置稳定时间: 1秒

**步骤三：开始测量**

1. 点击皮安表"开始采集"
2. 点击电磁铁"开始扫描"
3. 系统自动执行磁场扫描并记录数据
4. 观察实时数据曲线

**步骤四：完成测量**

1. 扫描完成后自动停止
2. 点击"保存数据"保存原始数据
3. 切换到数据分析页面进行处理

#### 数据质量检查

| 检查项 | 标准 | 说明 |
|--------|------|------|
| 曲线完整性 | 完整闭合 | 磁滞回线应形成闭合曲线 |
| 数据点数 | > 50 点 | 数据点越多拟合越准确 |
| 信噪比 | > 10 dB | 信号清晰无明显噪声 |
| 饱和区 | 明显 | 高场区应显示饱和趋势 |

---

### 2.2 温度扫描实验

#### 实验目的

研究材料特性随温度的变化规律。

#### 操作步骤

**步骤一：设置温度参数**

1. 连接温度控制器
2. 设置起始温度（如室温）
3. 设置终止温度（如 200°C）
4. 设置升温速率（如 5°C/min）

**步骤二：开始升温**

1. 点击"开始加热"
2. 同时启动数据采集
3. 观察温度和信号变化

**步骤三：数据记录**

1. 系统自动记录温度-信号曲线
2. 可手动标记特殊温度点
3. 到达目标温度后自动停止或恒温

---

### 2.3 多设备联动实验

#### 实验场景

需要多个设备协同工作的复杂实验，如变温磁滞回线测量。

#### 操作流程

```
┌─────────────┐
│ 设置温度 T1 │
└──────┬──────┘
       │
       v
┌─────────────┐
│ 等待稳定    │
└──────┬──────┘
       │
       v
┌─────────────┐
│ 测量磁滞回线│
└──────┬──────┘
       │
       v
┌─────────────┐
│ 保存数据    │
└──────┬──────┘
       │
       v
┌─────────────┐
│ 改变温度 T2 │
└──────┬──────┘
       │
       └─────> 循环执行
```

#### 操作要点

1. 按顺序启动各设备
2. 等待每个设备稳定后再进行下一步
3. 注意设备间的相互影响
4. 做好数据标记和记录

## 3. 数据分析操作

### 3.1 数据导入

#### 导入历史数据

1. 切换到"数据分析"页面
2. 点击"导入数据"按钮
3. 选择历史记录中的实验数据
4. 数据自动加载到分析界面

#### 导入外部数据

1. 点击"导入文件"
2. 选择 CSV 或 JSON 格式文件
3. 确认数据格式正确
4. 数据加载完成

---

### 3.2 数据预处理

#### 数据筛选

1. 选择数据范围
2. 移除异常点
3. 应用滤波器

#### 背景扣除

1. 点击"背景扣除"
2. 选择背景数据或输入背景值
3. 系统自动扣除背景信号

#### 数据归一化

1. 选择归一化方式
   - 最大值归一化
   - 面积归一化
   - 自定义归一化
2. 点击"应用"

---

### 3.3 多模型拟合

#### 选择拟合模型

系统支持以下四种模型：

| 模型名称 | 适用场景 | 特点 |
|----------|----------|------|
| 双曲正切 | 简单磁滞回线 | 计算快速 |
| 反正切 | 中等非线性材料 | 平滑过渡 |
| Braunbeck | 完整磁滞回线 | 拟合精度高 |
| Langevin | 超顺磁颗粒 | 纳米颗粒分析 |

#### 执行拟合

1. 在分析页面找到"多模型拟合"区域
2. 勾选需要对比的模型（建议全选）
3. 点击"开始拟合"
4. 等待计算完成（通常 1-5 秒）

#### 查看结果

**拟合优度指标**:

| 指标 | 说明 | 判断标准 |
|------|------|----------|
| R² | 决定系数 | > 0.95 为优秀 |
| RMSE | 均方根误差 | 越小越好 |
| AIC | 信息准则 | 用于模型比较 |

**结果解读**:

- 系统自动推荐最佳模型
- 显示各模型的拟合参数
- 提供拟合曲线对比图

---

### 3.4 参数提取

#### 磁滞回线参数

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 矫顽力 | Hc | A/m | 磁矩为零时的磁场强度 |
| 剩磁 | Mr | - | 磁场为零时的磁矩 |
| 饱和磁矩 | Ms | - | 高场下的饱和磁矩 |
| 矩形比 | Sq | - | Mr/Ms 的比值 |

#### 参数验证

1. 检查参数是否在物理合理范围内
2. 与文献值或理论值对比
3. 多次测量取平均值

## 4. 报告导出操作

### 4.1 生成分析报告

#### 操作步骤

1. 完成数据分析后
2. 点击"生成报告"按钮
3. 输入实验编号（可选）
4. 等待报告生成（3-10 秒）

#### 报告内容

报告包含以下信息：

**实验信息**:
- 实验编号
- 实验时间
- 操作人员

**磁滞参数**:
- 矫顽力（正向/负向）
- 剩磁
- 饱和磁矩
- 矩形比

**拟合结果**:
- 最佳模型
- 拟合参数
- 拟合优度

**质量指标**:
- 数据点数
- 磁场范围
- 信噪比

**分析建议**:
- 系统自动生成的分析建议

---

### 4.2 导出报告

#### 选择导出格式

| 格式 | 文件扩展名 | 适用场景 |
|------|------------|----------|
| JSON | .json | 数据交换、程序处理 |
| CSV | .csv | Excel 打开、人工查看 |

#### 导出步骤

1. 在报告页面点击"导出报告"
2. 选择导出格式
3. 选择是否包含原始数据
   - 包含原始数据：文件较大，适合完整记录
   - 不含原始数据：文件较小，适合快速查看
4. 点击"确认导出"
5. 选择保存位置
6. 点击"保存"

#### JSON 格式示例

```json
{
  "experiment_id": "exp_20260315_001",
  "timestamp": "2026-03-15T10:30:00.000Z",
  "hysteresis_params": {
    "Hc": 125.3,
    "Mr": 0.85,
    "Ms": 1.52,
    "squareness": 0.56
  },
  "best_model": "braunbeck",
  "fit_quality": {
    "R2": 0.987,
    "RMSE": 0.023
  }
}
```

#### CSV 格式说明

CSV 文件包含三个部分：

1. **参数汇总**: 关键参数列表
2. **原始数据**: 测量数据点（可选）
3. **拟合数据**: 拟合曲线数据点

---

### 4.3 批量导出

#### 导出多个实验

1. 在历史记录页面
2. 勾选需要导出的多个实验
3. 点击"批量导出"
4. 选择导出格式
5. 系统自动打包下载

## 5. 操作技巧

### 5.1 提高效率

1. **使用参数预设**: 保存常用参数组合，快速加载
2. **批量操作**: 多个相似实验可批量设置
3. **快捷键**: 熟练使用快捷键提高操作速度

### 5.2 保证数据质量

1. **预热设备**: 实验前预热设备至稳定状态
2. **多次测量**: 重要实验进行多次测量取平均
3. **及时保存**: 实验完成后及时保存数据
4. **标注清晰**: 为实验数据添加清晰的标注

### 5.3 安全操作

1. **遵守限位**: 不超出设备安全限位
2. **紧急停止**: 发现异常立即使用紧急停止
3. **防护措施**: 高温、高压实验做好防护
4. **定期检查**: 定期检查设备状态
