## 1. 系统启动

### 1.1 启动步骤

1. **启动应用程序**
   - 双击桌面上的 `SpintronicPlatform.exe` 图标
   - 或从开始菜单中找到 "CAUC-SEP 自旋电子器件实验平台" 并点击

2. **等待系统加载**
   - 系统将自动启动后端服务
   - 自动打开浏览器界面
   - 等待约 3-5 秒，界面加载完成

3. **确认启动成功**
   - 浏览器自动打开登录页面
   - 页面显示登录界面即表示启动成功

### 1.2 首次启动注意事项

- 确保所有实验设备已正确连接
- 确认 USB-RS485 转换器已插入电脑
- 检查设备管理器中串口号是否正确

## 2. 登录流程

系统提供三种登录模式，您可以根据实际情况选择最适合的方式。

### 2.1 快速登录模式（推荐）

**适用场景**: 日常实验操作，快速进入系统

**操作步骤**:

1. 在登录页面，默认显示"快速登录"模式
2. 点击预设的账号卡片（如"管理员"、"实验员"等）
3. 系统自动生成临时令牌并登录
4. 自动跳转到系统首页

**特点**:
- 无需输入密码
- 不依赖后端服务
- 令牌有效期 24 小时
- 适合离线使用

### 2.2 账号密码登录模式

**适用场景**: 需要完整权限验证的场景

**操作步骤**:

1. 在登录页面，点击"账号密码"标签切换模式
2. 输入用户名和密码
3. 点击"登录"按钮
4. 系统验证后跳转到首页

**默认账号**:

| 用户名 | 密码 | 角色 | 权限 |
|--------|------|------|------|
| admin | admin123 | 管理员 | 全部权限 |
| user | 123456 | 实验员 | 基本操作权限 |

### 2.3 访客模式

**适用场景**: 临时查看、演示展示

**操作步骤**:

1. 在登录页面，点击"访客模式"标签
2. 点击"以访客身份进入"按钮
3. 系统生成访客令牌并登录

**权限限制**:
- 仅可查看数据
- 无法操作设备
- 无法修改设置
- 无法导出数据
- 有效期 2 小时

### 2.4 登录问题排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 点击账号无反应 | 浏览器缓存问题 | 清除浏览器缓存后重试 |
| 提示"后端服务不可用" | 后端服务未启动 | 等待服务启动或使用快速登录 |
| 账号密码错误 | 输入错误或密码已修改 | 确认密码或联系管理员 |
| 访客模式无法进入 | 系统配置禁用 | 联系管理员启用访客模式 |

### 3.2 各区域功能说明

#### 顶部工具栏

| 区域 | 功能说明 |
|------|----------|
| 系统标题 | 显示系统名称和版本号 |
| 用户信息 | 显示当前登录用户名和角色 |
| 通知图标 | 显示系统通知和警告信息 |
| 设置按钮 | 进入系统设置页面 |
| 退出按钮 | 退出登录返回登录页面 |

#### 侧边栏导航

侧边栏包含以下功能模块：

| 图标 | 模块名称 | 功能说明 |
|------|----------|----------|
| 电机 | 步进电机控制 | 控制样品台位置移动 |
| 电磁铁 | 电磁铁控制 | 控制磁场强度和方向 |
| 温度 | 温度控制 | 控制样品温度 |
| 压电 | 压电陶瓷控制 | 控制微小位移 |
| 皮安表 | 皮安表采集 | 采集微弱电流信号 |
| 分析 | 数据分析 | 数据拟合和报告生成 |
| 设置 | 系统设置 | 系统参数配置 |

#### 主工作区

主工作区根据选择的功能模块显示相应内容：

- **设备控制页面**: 参数设置、实时数据显示、操作按钮
- **数据分析页面**: 数据图表、拟合工具、报告生成
- **系统设置页面**: 系统配置、设备管理、用户管理

#### 状态栏

状态栏显示系统实时状态：

| 指标 | 说明 | 正常状态 |
|------|------|----------|
| 系统状态 | 系统运行状态指示灯 | 绿色 |
| 设备连接数 | 已连接的设备数量 | 根据实际设备 |
| CPU 使用率 | 处理器占用百分比 | < 70% |
| 内存使用率 | 内存占用百分比 | < 70% |

## 4. 基本操作流程

### 4.1 标准实验流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  1. 连接设备 │ -> │  2. 设置参数 │ -> │  3. 执行实验 │
└─────────────┘    └─────────────┘    └─────────────┘
                                            │
                                            v
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  6. 导出报告 │ <- │  5. 生成报告 │ <- │  4. 数据分析 │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 4.2 详细操作步骤

#### 步骤一：连接设备

1. 点击侧边栏对应的设备模块（如"电机"）
2. 在设备控制面板找到"连接"按钮
3. 点击"连接"，等待连接成功提示
4. 确认状态栏显示设备已连接

**注意事项**:
- 确保设备已上电
- 确认串口线缆连接正确
- 首次使用需在设置中配置串口号

#### 步骤二：设置参数

根据实验需求设置各项参数：

| 设备类型 | 常用参数 | 设置方式 |
|----------|----------|----------|
| 步进电机 | 目标位置、移动速度 | 输入框或滑块 |
| 电磁铁 | 电流值、扫描范围 | 输入框 |
| 温度控制器 | 目标温度、升温速率 | 输入框 |
| 皮安表 | 采样频率、量程 | 下拉选择 |

#### 步骤三：执行实验

1. 确认所有参数设置正确
2. 点击"开始"按钮执行实验
3. 观察实时数据曲线
4. 实验完成后自动停止或手动点击"停止"

**安全提示**:
- 实验过程中请勿断开设备连接
- 发现异常立即点击"紧急停止"按钮
- 超出安全范围时系统会自动停止

#### 步骤四：数据分析

1. 切换到"数据分析"页面
2. 选择需要分析的实验数据
3. 选择拟合模型（建议使用多模型对比）
4. 点击"开始拟合"
5. 查看拟合结果和参数

#### 步骤五：生成报告

1. 在数据分析页面点击"生成报告"
2. 输入实验编号（可选）
3. 等待报告生成完成
4. 查看报告内容

#### 步骤六：导出报告

1. 在报告页面点击"导出报告"
2. 选择导出格式（JSON 或 CSV）
3. 选择是否包含原始数据
4. 选择保存位置并保存文件

### 4.3 快捷操作

#### 快捷键

| 快捷键 | 功能 | 适用场景 |
|--------|------|----------|
| F5 | 刷新页面 | 页面显示异常时 |
| Ctrl+S | 保存当前设置 | 参数设置完成后 |
| Ctrl+E | 紧急停止 | 紧急情况 |
| Esc | 取消当前操作 | 操作失误时 |

#### 常用操作技巧

1. **快速切换设备**: 使用侧边栏图标快速切换不同设备
2. **参数预设**: 在设置中保存常用参数组合
3. **数据对比**: 在分析页面可同时打开多个数据集对比
4. **历史记录**: 点击历史记录快速加载之前的实验数据
