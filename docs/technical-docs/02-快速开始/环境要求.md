# 环境要求

## 概述

本文档详细说明 CAUC-SEP 自旋电子器件实验平台的运行环境要求，包括操作系统、软件依赖和硬件配置。

---

## 1. 操作系统要求

### 1.1 支持的操作系统

| 操作系统 | 版本要求 | 架构 | 推荐程度 |
|---------|---------|------|---------|
| Windows | 10/11 64位 | x64 | **强烈推荐** |
| Windows | 10 1903+ | x64 | 推荐 |
| Linux | Ubuntu 20.04+ | x64 | 支持 |
| macOS | 12.0+ | x64/ARM | 支持 |

### 1.2 操作系统配置建议

- **Windows 用户**：
  - 确保已安装最新 Windows 更新
  - 启用开发者模式（可选，用于符号链接支持）
  - 关闭杀毒软件对项目目录的实时扫描（提升性能）

- **Linux 用户**：
  - 确保具有 sudo 权限
  - 安装必要的系统依赖：`sudo apt-get install build-essential python3-dev`

## 3. 硬件要求

### 3.1 计算机硬件配置

| 组件 | 最低配置 | 推荐配置 |
|-----|---------|---------|
| CPU | 双核 2.0GHz | 四核 3.0GHz+ |
| 内存 | 8GB | 16GB+ |
| 硬盘 | 20GB 可用空间 | SSD 50GB+ |
| 显卡 | 集成显卡 | 独立显卡（可选） |
| 网络 | 有线/无线网卡 | 千兆以太网 |

### 3.2 实验设备硬件

#### 必需设备

| 设备 | 型号/规格 | 接口 | 用途 |
|-----|----------|------|-----|
| USB-RS485 转换器 | 任意兼容型号 | USB | 设备通信桥接 |
| 步进电机驱动器 | 雷赛 DM2C 系列 | RS485 | 精密位移控制 |
| 电磁铁电源 | 可编程电源 | RS485/串口 | 磁场控制 |

#### 可选设备

| 设备 | 型号/规格 | 接口 | 用途 |
|-----|----------|------|-----|
| 温度控制器 | RS556 系列 | RS485 | 温度控制 |
| 压电陶瓷驱动器 | 压电控制器 | USB/串口 | 微位移调节 |
| 电流表 | Keithley 2400 | GPIB/USB | 电流测量 |
| 万用表 | Agilent 34401A | GPIB/USB | 电压测量 |

### 3.3 硬件连接要求

#### 串口通信

```
计算机 USB 端口
    ↓
USB-RS485 转换器
    ↓
RS485 总线（A+、B-）
    ↓
设备链（最多 32 个设备）
```

#### 接线规范

- **RS485 总线**：使用双绞屏蔽线，长度不超过 1200 米
- **终端电阻**：总线两端加装 120Ω 终端电阻
- **接地**：确保所有设备共地，避免地环路干扰

## 6. 环境检查脚本

使用以下脚本快速检查环境配置：

### Windows (PowerShell)

```powershell
# 保存为 check_environment.ps1
Write-Host "=== CAUC-SEP 环境检查 ===" -ForegroundColor Cyan

# Python 检查
Write-Host "`n[Python]" -ForegroundColor Yellow
try {
    $pythonVersion = python --version 2>&1
    Write-Host "  版本: $pythonVersion" -ForegroundColor Green
} catch {
    Write-Host "  未安装 Python" -ForegroundColor Red
}

# Node.js 检查
Write-Host "`n[Node.js]" -ForegroundColor Yellow
try {
    $nodeVersion = node --version 2>&1
    Write-Host "  版本: $nodeVersion" -ForegroundColor Green
} catch {
    Write-Host "  未安装 Node.js" -ForegroundColor Red
}

# Git 检查
Write-Host "`n[Git]" -ForegroundColor Yellow
try {
    $gitVersion = git --version 2>&1
    Write-Host "  版本: $gitVersion" -ForegroundColor Green
} catch {
    Write-Host "  未安装 Git" -ForegroundColor Red
}

# 端口检查
Write-Host "`n[端口占用]" -ForegroundColor Yellow
$ports = @(8000, 5173)
foreach ($port in $ports) {
    $connection = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue
    if ($connection) {
        Write-Host "  端口 $port : 已占用" -ForegroundColor Red
    } else {
        Write-Host "  端口 $port : 可用" -ForegroundColor Green
    }
}

Write-Host "`n=== 检查完成 ===" -ForegroundColor Cyan
```

### Linux/macOS (Bash)

## 7. 常见问题

### 7.1 Python 版本不兼容

**问题**：系统 Python 版本低于 3.10

**解决方案**：
1. 使用 pyenv 安装多版本 Python：
   ```bash
   # 安装 pyenv-win (Windows)
   pip install pyenv-win --target $HOME\.pyenv
   
   # 安装 Python 3.10
   pyenv install 3.10.11
   
   # 设置为全局版本
   pyenv global 3.10.11
   ```

2. 或使用 Anaconda 创建虚拟环境：
   ```bash
   conda create -n cauc-sep python=3.10
   conda activate cauc-sep
   ```

### 7.2 Node.js 版本不兼容

**问题**：系统 Node.js 版本低于 18

**解决方案**：
1. 使用 nvm 管理多版本 Node.js：
   ```bash
   # 安装 nvm-windows (Windows)
   # 下载: https://github.com/coreybutler/nvm-windows/releases
   
   # 安装 Node.js 18
   nvm install 18
   nvm use 18
   ```

### 7.3 串口权限问题（Linux）

**问题**：无法访问串口设备

**解决方案**：
```bash
# 将当前用户添加到 dialout 组
sudo usermod -a -G dialout $USER

# 注销并重新登录生效
```

### 7.4 端口被占用

**问题**：端口 8000 或 5173 已被占用

**解决方案**：
```powershell
# Windows: 查找占用进程
netstat -ano | findstr :8000

# 结束进程（替换 PID）
taskkill /PID <进程ID> /F
```
