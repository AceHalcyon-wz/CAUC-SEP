# 安装配置

## 概述

本文档提供 CAUC-SEP 自旋电子器件实验平台的详细安装和配置指南，包括代码获取、依赖安装、硬件配置和环境变量设置。

---

## 1. 获取代码

### 1.1 克隆仓库

```bash
# 克隆主仓库
git clone <repository-url> cauc-sep

# 进入项目目录
cd cauc-sep
```

```bash
tree -L 2 -I "node_modules|__pycache__|*.pyc|.git"
```

## 2. 后端安装

### 2.1 创建 Python 虚拟环境

**推荐方式：使用 venv**

```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows (PowerShell)
.\venv\Scripts\Activate.ps1

# Windows (CMD)
.\venv\Scripts\activate.bat

# Linux/macOS
source venv/bin/activate
```

**替代方式：使用 Conda**

```bash
# 创建 Conda 环境
conda create -n cauc-sep python=3.10

# 激活环境
conda activate cauc-sep
```

### 2.2 安装 Python 依赖

```bash
# 升级 pip
python -m pip install --upgrade pip

# 安装项目依赖
pip install -r requirements.txt

# 验证安装
pip list

# 验证核心包
python -c "import fastapi; print(f'FastAPI: {fastapi.__version__}')"
python -c "import pydantic_settings; print('pydantic-settings: OK')"
python -c "import structlog; print('structlog: OK')"
```

### 2.3 依赖锁定文件

项目使用 `requirements.lock` 确保依赖版本一致性：

```bash
# 使用锁定文件安装（推荐）
pip install -r requirements.lock

# 更新依赖并生成新的锁定文件
pip freeze > requirements.lock
```

### 2.3 验证后端依赖

```bash
# 验证核心包
python -c "import fastapi; print(f'FastAPI: {fastapi.__version__}')"
python -c "import pymodbus; print(f'PyModbus: {pymodbus.__version__}')"
```

## 4. 硬件配置

### 4.1 设备配置文件

编辑 `backend/main.py` 中的设备配置：

```python
# ============================================================================
# 设备配置示例
# ============================================================================

from devices.stepper import LeadshineDM2C
from devices.electromagnet import ElectromagnetDriver
from devices.temperature import RS556Controller
from devices.piezo import PiezoController
from devices.ammeter import Keithley2400

# --------------------
# 步进电机配置
# --------------------
dm2c = LeadshineDM2C("stepper_01", {
    "port": "COM3",          # 串口号（Windows）
    # "port": "/dev/ttyUSB0", # 串口号（Linux）
    "slave_id": 1,           # Modbus 从站地址
    "steps_per_mm": 1600,    # 每毫米步数（根据丝杆导程计算）
    "max_speed": 1000,       # 最大速度（步/秒）
    "acceleration": 500,     # 加速度（步/秒²）
})

# --------------------
# 电磁铁配置
# --------------------
electromagnet_driver = ElectromagnetDriver("electromagnet_01", {
    "simulation": True,      # 仿真模式（无硬件时设为 True）
    "port": "COM4",          # 串口号
    "baudrate": 9600,        # 波特率
    "max_current": 10.0,     # 最大电流（A）
    "ramp_rate": 0.5,        # 电流变化速率（A/s）
})

# --------------------
# 温度控制器配置
# --------------------
temperature_controller = RS556Controller("temp_01", {
    "simulation": True,
    "port": "COM5",
    "slave_id": 2,
    "temp_range": [0, 400],  # 温度范围（℃）
    "pid": {                 # PID 参数
        "kp": 1.0,
        "ki": 0.1,
        "kd": 0.01,
    }
})

# --------------------
# 压电陶瓷配置
# --------------------
piezo_controller = PiezoController("piezo_01", {
    "simulation": True,
    "port": "COM6",
    "voltage_range": [0, 150],  # 电压范围（V）
    "resolution": 0.001,        # 分辨率（V）
})

# --------------------
# 电流表配置
# --------------------
ammeter = Keithley2400("ammeter_01", {
    "simulation": True,
    "port": "GPIB0::24::INSTR",  # GPIB 地址
    # "port": "COM7",             # 或串口地址
    "current_range": [0, 1],     # 电流范围（A）
    "nplc": 1,                   # 积分周期
})
```

### 4.2 查找串口号

**Windows**：

```powershell
# 使用 PowerShell 查看串口
Get-WMIObject Win32_SerialPort | Select-Object DeviceID, Description

# 或使用 mode 命令
mode
```

**Linux**：

```bash
# 查看串口设备
ls -l /dev/ttyUSB* /dev/ttyACM*

# 查看串口详细信息
dmesg | grep tty
```

### 4.3 仿真模式

当没有实际硬件时，启用仿真模式：

```python
# 所有设备都支持仿真模式
device_config = {
    "simulation": True,  # 启用仿真
    # ... 其他配置
}
```

仿真模式下，设备会模拟真实响应，便于开发和测试。

## 6. 配置文件详解

### 6.1 后端配置文件

#### main.py - 主入口配置

```python
"""
文件名: main.py
路径: backend/main.py
功能: FastAPI 应用入口，配置中间件、路由和启动事件
"""

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from contextlib import asynccontextmanager

from core.config import get_settings
from routers import devices, experiments, auth, data
from devices.manager import DeviceManager

settings = get_settings()

# 生命周期管理
@asynccontextmanager
async def lifespan(app: FastAPI):
    """应用生命周期管理"""
    # 启动时初始化
    device_manager = DeviceManager()
    await device_manager.initialize()
    app.state.device_manager = device_manager
    
    yield  # 运行中
    
    # 关闭时清理
    await device_manager.shutdown()

# 创建应用
app = FastAPI(
    title=settings.app_name,
    version=settings.app_version,
    lifespan=lifespan,
)

# CORS 中间件
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# 注册路由
app.include_router(auth.router, prefix="/api/auth", tags=["认证"])
app.include_router(devices.router, prefix="/api/devices", tags=["设备"])
app.include_router(experiments.router, prefix="/api/experiments", tags=["实验"])
app.include_router(data.router, prefix="/api/data", tags=["数据"])
```

#### config.py - 配置管理

```python
"""
文件名: config.py
路径: backend/core/config.py
功能: 集中管理应用配置，支持环境变量和配置文件
"""

from pydantic_settings import BaseSettings
from typing import List

class Settings(BaseSettings):
    """应用配置类"""
    
    # 应用信息
    app_name: str = "CAUC-SEP"
    app_version: str = "3.5.0"
    debug: bool = False
    
    # 服务器配置
    host: str = "0.0.0.0"
    port: int = 8000
    workers: int = 1
    
    # 数据库配置
    database_url: str = "sqlite:///./cauc_sep.db"
    
    # Redis 配置
    redis_url: str = "redis://localhost:6379/0"
    redis_enabled: bool = False
    
    # 安全配置
    secret_key: str
    algorithm: str = "HS256"
    access_token_expire_minutes: int = 30
    
    # CORS 配置
    cors_origins: List[str] = ["http://localhost:5173"]
    cors_allow_credentials: bool = True
    
    # 日志配置
    log_level: str = "INFO"
    log_file: str = "logs/app.log"
    
    # 设备配置
    device_simulation: bool = False
    device_timeout: int = 5000
    device_retry_count: int = 3
    
    class Config:
        env_file = ".env"
        case_sensitive = False

# 全局配置实例
settings = Settings()
```

## 8. 常见安装问题

### 8.1 Python 依赖安装失败

**问题 1**：`pip install` 速度慢或超时

**解决方案**：使用国内镜像源

```bash
# 临时使用
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

**问题 2**：`numpy` 或 `scipy` 编译失败

**解决方案**：使用预编译包

```bash
# 使用 conda 安装科学计算包
conda install numpy scipy matplotlib -c conda-forge
```

**问题 3**：`pydantic` 版本冲突

**解决方案**：

```bash
# 清除缓存重新安装
pip cache purge
pip install --no-cache-dir -r requirements.txt
```

### 8.2 Node.js 依赖安装失败

**问题 1**：`npm install` 速度慢

**解决方案**：使用国内镜像源

```bash
# 使用 cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install

# 或配置 npm 镜像
npm config set registry https://registry.npmmirror.com
npm install
```

**问题 2**：`node-gyp` 编译失败

**解决方案**：安装构建工具

```bash
# Windows - 安装 windows-build-tools
npm install -g windows-build-tools

# Linux - 安装构建依赖
sudo apt-get install build-essential python3-dev
```

**问题 3**：依赖版本冲突

**解决方案**：

```bash
# 清除缓存重新安装
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```

### 8.3 串口无法打开

**问题 1**：`Permission denied`（Linux）

**解决方案**：

```bash
# 添加用户到 dialout 组
sudo usermod -a -G dialout $USER

# 注销并重新登录
```

**问题 2**：串口被占用

**解决方案**：

```bash
# Linux - 查找占用进程
lsof /dev/ttyUSB0

# 结束进程
kill -9 <PID>
```

```powershell
# Windows - 查找占用进程
mode

# 或使用 Process Explorer 工具
```

**问题 3**：串口号不正确

**解决方案**：

```bash
# Linux - 查看可用串口
ls -l /dev/ttyUSB* /dev/ttyACM*

# Windows - 设备管理器查看
# 或使用 PowerShell
Get-WMIObject Win32_SerialPort
```

### 8.4 数据库连接失败

**问题**：SQLite 数据库锁定

**解决方案**：

```python
# 检查数据库文件权限
import os
db_path = "cauc_sep.db"
if os.path.exists(db_path):
    os.chmod(db_path, 0o666)
```

### 8.5 环境变量未生效

**问题**：`.env` 文件未被加载

**解决方案**：

```python
# 确保使用 python-dotenv 或 pydantic-settings
from dotenv import load_dotenv

# 显式加载 .env 文件
load_dotenv()

# 或指定路径
load_dotenv(dotenv_path="../.env")
```
