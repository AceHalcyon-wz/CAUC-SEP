### 4.4 WebSocket 连接测试

#### 使用 JavaScript 测试

```javascript
// 在浏览器控制台执行
const ws = new WebSocket('ws://127.0.0.1:8000/ws')

ws.onopen = () => {
  console.log('WebSocket 连接成功')
  ws.send(JSON.stringify({ type: 'subscribe', channel: 'device_status' }))
}

ws.onmessage = (event) => {
  console.log('收到消息:', JSON.parse(event.data))
}

ws.onerror = (error) => {
  console.error('WebSocket 错误:', error)
}

ws.onclose = () => {
  console.log('WebSocket 连接关闭')
}
```

#### 使用 Python 测试

```python
import asyncio
import websockets
import json

async def test_websocket():
    """测试 WebSocket 连接"""
    uri = "ws://127.0.0.1:8000/ws"
    
    async with websockets.connect(uri) as websocket:
        # 发送订阅消息
        await websocket.send(json.dumps({
            "type": "subscribe",
            "channel": "device_status"
        }))
        
        # 接收消息
        while True:
            message = await websocket.recv()
            data = json.loads(message)
            print(f"收到消息: {data}")
            
            if data.get("type") == "connected":
                print("WebSocket 连接成功")
                break

# 运行测试
asyncio.run(test_websocket())
```

### 6.2 数据库性能测试

```python
import time
from sqlalchemy import create_engine, text

def test_database_performance():
    """测试数据库性能"""
    engine = create_engine('sqlite:///./cauc_sep.db')
    
    # 测试写入性能
    start = time.time()
    with engine.connect() as conn:
        for i in range(1000):
            conn.execute(text(
                "INSERT INTO experiments (name, status) VALUES (:name, :status)"
            ), {"name": f"test_{i}", "status": "pending"})
        conn.commit()
    write_time = time.time() - start
    print(f"写入 1000 条记录耗时: {write_time:.2f}s")
    
    # 测试读取性能
    start = time.time()
    with engine.connect() as conn:
        result = conn.execute(text("SELECT * FROM experiments"))
        rows = result.fetchall()
    read_time = time.time() - start
    print(f"读取 {len(rows)} 条记录耗时: {read_time:.2f}s")
```

## 7. 常见问题排查

### 7.1 后端无法启动

**问题**：`ModuleNotFoundError: No module named 'xxx'`

**解决方案**：

```bash
# 检查虚拟环境是否激活
which python  # Linux/macOS
where python  # Windows

# 重新安装依赖
pip install -r requirements.txt
```

**问题**：`Address already in use`

**解决方案**：

```bash
# 查找占用端口的进程
# Windows
netstat -ano | findstr :8000
taskkill /PID <PID> /F

# Linux/macOS
lsof -i :8000
kill -9 <PID>

# 或更换端口
uvicorn main:app --port 8001
```

### 7.2 前端无法启动

**问题**：`EADDRINUSE: address already in use :::5173`

**解决方案**：

```bash
# 更换端口
npm run dev -- --port 5174

# 或结束占用进程
# Windows
netstat -ano | findstr :5173
taskkill /PID <PID> /F

# Linux/macOS
lsof -i :5173
kill -9 <PID>
```

**问题**：`Failed to resolve import`

**解决方案**：

```bash
# 清除缓存重新安装
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```

### 7.3 设备连接失败

**问题**：`SerialException: could not open port`

**解决方案**：

1. 检查串口是否被其他程序占用
2. 检查串口号是否正确
3. 检查权限（Linux 需要加入 dialout 组）
4. 启用仿真模式测试

```python
# 启用仿真模式
device_config = {
    "simulation": True,
    # ...
}
```

### 7.4 WebSocket 连接失败

**问题**：`WebSocket connection failed`

**解决方案**：

1. 检查后端服务是否运行
2. 检查 WebSocket 路径是否正确
3. 检查防火墙设置
4. 检查 CORS 配置

```python
# 检查 CORS 配置
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 7.5 数据库错误

**问题**：`Database is locked`

**解决方案**：

```python
# SQLite 并发限制，使用连接池
from sqlalchemy import create_engine

engine = create_engine(
    'sqlite:///./cauc_sep.db',
    connect_args={'check_same_thread': False},
    pool_size=10,
    max_overflow=20
)
```

## 附录：快速验证脚本

### 完整验证脚本（Windows PowerShell）

```powershell
# 保存为 verify_installation.ps1

Write-Host "=== CAUC-SEP 安装验证 ===" -ForegroundColor Cyan

# 1. 检查后端服务
Write-Host "`n[1] 检查后端服务..." -ForegroundColor Yellow
try {
    $response = Invoke-WebRequest -Uri "http://127.0.0.1:8000" -UseBasicParsing
    $data = $response.Content | ConvertFrom-Json
    Write-Host "  服务状态: $($data.status)" -ForegroundColor Green
    Write-Host "  版本: $($data.version)" -ForegroundColor Green
} catch {
    Write-Host "  后端服务未启动或无法访问" -ForegroundColor Red
    exit 1
}

# 2. 检查前端服务
Write-Host "`n[2] 检查前端服务..." -ForegroundColor Yellow
try {
    $response = Invoke-WebRequest -Uri "http://localhost:5173" -UseBasicParsing
    Write-Host "  前端服务运行正常" -ForegroundColor Green
} catch {
    Write-Host "  前端服务未启动或无法访问" -ForegroundColor Red
}

# 3. 检查 API 文档
Write-Host "`n[3] 检查 API 文档..." -ForegroundColor Yellow
try {
    $response = Invoke-WebRequest -Uri "http://127.0.0.1:8000/docs" -UseBasicParsing
    Write-Host "  API 文档可访问: http://127.0.0.1:8000/docs" -ForegroundColor Green
} catch {
    Write-Host "  API 文档无法访问" -ForegroundColor Red
}

# 4. 检查健康状态
Write-Host "`n[4] 检查健康状态..." -ForegroundColor Yellow
try {
    $response = Invoke-WebRequest -Uri "http://127.0.0.1:8000/api/health" -UseBasicParsing
    $health = $response.Content | ConvertFrom-Json
    Write-Host "  健康状态: $($health.status)" -ForegroundColor Green
} catch {
    Write-Host "  健康检查失败" -ForegroundColor Red
}

Write-Host "`n=== 验证完成 ===" -ForegroundColor Cyan
Write-Host "前端应用: http://localhost:5173" -ForegroundColor White
Write-Host "API 文档: http://127.0.0.1:8000/docs" -ForegroundColor White
```

运行验证：

```powershell
# 执行验证脚本
.\verify_installation.ps1
```
