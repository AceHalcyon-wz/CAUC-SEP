## 测试执行

### 运行命令

```bash
# 运行所有E2E测试
npm run test:e2e

# 运行特定测试文件
npx playwright test tests/e2e/app-launch.spec.js

# 运行Electron项目测试
npx playwright test --project=electron

# 以UI模式运行测试
npm run test:e2e:ui
```

### 测试前置条件

1. **环境变量设置**:
   ```bash
   export ELECTRON_TEST=true
   ```

2. **依赖安装**:
   ```bash
   npm install
   ```

3. **后端服务运行**（可选）:
   ```bash
   cd ../backend
   python main.py
   ```

4. **前端构建**（生产环境测试）:
   ```bash
   npm run build
   ```
